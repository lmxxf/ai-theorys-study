【DLSS5】A 卡跑 DLSS 5，0.20 版安装教程：不用开发人员模式了

━━━━━━━━━━━━━━━━━━━━

◆ 这是什么

━━━━━━━━━━━━━━━━━━━━

把 DLSS 5 的神经网络搬到 AMD RX 9070 XT 上跑，装在 Magpie（一个窗口缩放器）里。任何能开窗口的游戏都能用，不要求游戏自己支持 DLSS 或 FSR。

0.20 和 0.13 那篇教程最大的区别：推理后端从 DirectX 12 的 Shader Model 6.10 换成了 AMD HIP。网络的 24 个内核以显卡原生二进制随包提供，由驱动自带的 HIP 运行时执行。所以之前那两条最烦人的要求——预览驱动的实验性着色器模型、Windows 开发人员模式——都不需要了。输出和 DX12 版逐位相同（同样的输入、种子、历史帧，40 帧输出的哈希完全一致），只是更快：独立测试台 1600×900 一帧 15.5 毫秒，比 DX12 版的 16.8 快 8%；《剑星》游戏内钩子版 900p 从 47 帧到 52 帧。

这篇只讲怎么装、怎么用。HIP 移植和优化的过程在后面几期。

━━━━━━━━━━━━━━━━━━━━

◆ 你需要什么

━━━━━━━━━━━━━━━━━━━━

两个硬条件：

1. 显卡：RX 9070 或 9070 XT。内核只编了 RDNA4（gfx1201），用了这代才有的 FP8 矩阵指令，RX 7000 不行。

2. 驱动带 HIP 7 运行时：看 C:\Windows\System32 里有没有 amdhip64_7.dll。有就行。

我验证过的是 AMD 32.0.31007.2048 这个预览驱动（就是 0.13 那篇要求装的那个，装过的不用动）。正式版驱动只要 System32 里有这个文件，理论上一样能用，但我手里只有一台机器、只装着预览驱动，没实测过正式版。装了正式版驱动、System32 里有这个文件、跑不起来的，把 DLSS5-AMD\logs\native-game-oneshot.txt 发给我。

不需要开发人员模式，不需要装 HIP SDK、编译器或任何 SDK。0.13 那篇让你开的开发人员模式，现在可以关掉了。

━━━━━━━━━━━━━━━━━━━━

◆ 安装

━━━━━━━━━━━━━━━━━━━━

1. 下载 Magpie-DLSS5-AMD-0.20.zip（355MB）：https://pan.quark.cn/s/3c8b5329353c

2. 解压到任意目录。路径不要带中文。

3. 运行解压出来的 Magpie.exe。配置已经预设好，效果组选 "DLSS5-AMD"。

包里含了 Magpie 本体、插件、权重、HIP 内核和运行参数，解压即用。不写注册表，不碰系统目录，不想用了整个文件夹删掉就行。

从 0.13/0.15 升级的：直接换整个目录。旧包里的 DLSS5-D3D12-721 文件夹和 enable-game-sdk721.txt 在 0.20 里没有了，正常，HIP 版不用它们。

━━━━━━━━━━━━━━━━━━━━

◆ 使用

━━━━━━━━━━━━━━━━━━━━

1. 游戏设成窗口模式，建议 1600×900。本包固定按 1600×900 计算网络，然后由 FSR4 放大到你的屏幕（2K、4K 都行），最后 XeSS 帧生成插一帧。窗口宽不超过 1920、高不超过 1080 都能用：比 900p 小的会自动适配，比它大的（比如 1080p）会先缩到 1600×900 喂给网络，算完再放回窗口尺寸——能用，但网络看到的还是 900p，多出来的像素只是多了一次缩放，没有画质收益。所以直接开 900 窗口最省。超过 1920×1080 的窗口会拒绝，左上角报 INPUT MAX 1920X1080。

2. 进游戏后按 Alt+Shift+A（Magpie 默认的缩放热键）。

3. 等 3～5 秒。这段时间是网络初始化，左上角写着 INITIALIZING。字变成 "DLSS5-AMD xx FPS" 就是 DLSS 5 接管了——那是网络自己的帧率，屏幕上实际显示的是帧生成插过之后的数，按 Alt+Shift+P 打开 Magpie 效能分析器能同时看到两个。

4. 再按一次 Alt+Shift+A 停止缩放，回到游戏原画面。来回按几次对比效果。

F6 是插件自己的开关：不停 Magpie，只在 DLSS 5 和 Magpie 的 FSR3 之间切换。对比画面用这个更方便。

效果组里那一项叫 FSR3_SR 的，就是本插件接入 DLSS5 的位置；界面上的名字还是 FSR3，不用另外添加什么 DLSS5 滤镜。自己调效果组的话：FSR3 的缩放选"相对于输入尺寸、水平/垂直均 1 倍"，FSR4 选"充满屏幕"；不需要插帧就把最后的 XeSS_FrameGeneration_x2_ZeroMV 删掉。

◆ 没出来画面怎么查

━━━━━━━━━━━━━━━━━━━━

先看画面左上角：

- "INPUT MAX 1920X1080 (NOW WxH)"：游戏窗口超过 1920×1080 了，减小窗口，并确认效果组第一站 FSR3 没有提前放大。
- "INITIALIZING..."：正在初始化，等几秒。
- "INIT FAILED - SEE DLSS5-AMD\LOGS"：初始化失败。

初始化失败打开解压目录下的 DLSS5-AMD\logs\native-game-oneshot.txt，找 "initialization_failed" 这一行，后面就是原因：

- 带 hipError 字样：HIP 运行时的问题。先确认 System32 里有 amdhip64_7.dll；有的话把这一行发给我。
- 带 .hsaco 文件名和 FileNotFound：内核文件没找到，一般是解压不完整或者自己挪过 DLSS5-AMD 目录。24 个 .hsaco 必须在 DLSS5-AMD\native-game-tiled-assets\HIP\ 里。

正常情况这个文件最后一行是 "ready"。

0.13 那篇让你查的 "sdk721_before_device"、"experimental=" 这些行，0.20 里不会有了——那是 DX12 实验性着色器模型的开关，HIP 版不走那条路。

◆ 可调的几个参数

━━━━━━━━━━━━━━━━━━━━

都在 DLSS5-AMD\native-game-flags.txt 里，改完完全退出并重启 Magpie 生效。

计算档位：DLSS5_NETWORK_HEIGHT=900 是默认。可以改 720 或 1080。900 是我实玩下来画质和帧率的平衡点；1080 更清楚但配合帧生成不太稳；720 更快但画面软。

强度：加一行 DLSS5_STRENGTH=细节,颜色。两个数各 0 到 1，默认 1,1 是网络结果全用。写 0.5,1 就是细节一半用原图一半用网络，颜色修正全用。对应 NVIDIA 面板里"强度"那个滑杆。

跳块：DLSS5_SKIP_BLOCKS=42,43,46 是默认值，跳过三个对画面影响最小的层，换约 1 毫秒。想要画质全开就把这一行删掉，帧率掉一两帧。不建议再多跳：我试过跳九块，帧率多 5%，误差能量涨 3.5 倍，不值。

风格预设（Natural、Faithful 那几个）没有，本包只有捕获时那一套权重。

◆ 已知的事

━━━━━━━━━━━━━━━━━━━━

- 网络本身 900p 一帧 15.5 毫秒，也就是它自己最多 64 帧；实际帧率看游戏抢走多少显卡。《剑星》游戏内钩子版实测 52 帧。
- 显存要 16GB，网络自己占约 3GB。游戏贴图质量别开最高，显存一旦被挤到系统内存帧率会掉到 20 多且不恢复。
- 运动向量来自 Magpie 的光流估计，平坦暗部会出垃圾向量。插件把超过 64 像素的向量当静止处理，所以快速转视角时暗部偶尔会有一点拖影，正常。
- 停止缩放再激活，插件会重新初始化，再等几秒。
- 输入是 8 位 sRGB 的显示画面，不是游戏引擎里的线性 HDR 场景色。所以和游戏内钩子那版（只支持《剑星》）风格略有不同，更亮一点。
- 正式版驱动没测过，见上面"你需要什么"。
