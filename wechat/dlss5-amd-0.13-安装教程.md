【DLSS5】A 卡跑 DLSS 5，0.13 版安装教程

━━━━━━━━━━━━━━━━━━━━

◆ 这是什么

━━━━━━━━━━━━━━━━━━━━

把 DLSS 5 的神经网络搬到 AMD RX 9070 XT 上跑，装在 Magpie（一个窗口缩放器）里。任何能开 1920×1080 无边框窗口的游戏都能用，不要求游戏自己支持 DLSS 或 FSR。

效果是 1080p、9070 XT 上 37 帧左右的 DLSS 5 画面。这是目前的性能水平，前几期讲过原因：网络本身一帧 21 毫秒，再加游戏自己抢显卡。

这篇只讲怎么装、怎么用。原理和优化过程在 297、298、299、301、304 期。

━━━━━━━━━━━━━━━━━━━━

◆ 你需要什么

━━━━━━━━━━━━━━━━━━━━

三个硬条件，缺一个都出不来画面：

1. 显卡：RX 9070 或 9070 XT。只有 RDNA4 有这代硬件矩阵指令，别的 A 卡不行。

2. 驱动：AMD 26.10.07.02 预览驱动。正式驱动没有 Shader Model 6.10 的 wave matrix，装了也是 Magpie 自己的 FSR3 画面。

3. Windows 开发人员模式：设置 → 系统 → 开发者选项 → 打开"开发人员模式"。插件靠一个只在开发人员模式下才成功的系统调用打开实验性着色器模型。上一期有网友装好了没效果，就是这一步没开。

为什么要预览驱动和开发人员模式？因为 wave matrix 现在还是预览功能。等微软和 AMD 转正，这两条会一起消失。现阶段没有绕过去的办法。

不需要装编译器、SDK 或者别的东西，着色器已经编好在包里。

━━━━━━━━━━━━━━━━━━━━

◆ 安装

━━━━━━━━━━━━━━━━━━━━

1. 下载 Magpie-DLSS5-AMD-0.13.zip（342MB）：https://pan.quark.cn/s/7097bd16dc10

2. 解压到任意目录。路径不要带中文。

3. 运行解压出来的 Magpie.exe。配置已经预设好，不用改任何选项。

就这三步。包里已经含了 Magpie 本体、插件、权重、着色器和运行时，解压即用。不写注册表，不碰系统目录，不想用了整个文件夹删掉就行。

━━━━━━━━━━━━━━━━━━━━

◆ 使用

━━━━━━━━━━━━━━━━━━━━

1. 游戏设成无边框窗口，分辨率 1920×1080。这一条是硬的：网络只认 1080p 进、1080p 出。显示器是 2K 或 4K 也一样，游戏窗口必须是 1080p。

2. 进游戏后按 Alt+Shift+A（Magpie 默认的缩放热键）。

3. 等 3～5 秒。这段时间是网络初始化，左上角写着 INITIALIZING。字变成 "DLSS5-AMD 3x FPS" 就是 DLSS 5 接管了——那是网络自己的帧率，屏幕上实际显示的是帧生成插过的 55 上下，按 Alt+Shift+P 打开 Magpie 效能分析器能同时看到两个数。第一次启动会多几秒，那是在缓存编译结果，以后就快了。

4. 再按一次 Alt+Shift+A 停止缩放，回到游戏原画面。来回按几次对比效果。

F6 是插件自己的开关：不停 Magpie，只在 DLSS 5 和 Magpie 的 FSR3 之间切换。对比画面用这个更方便。

━━━━━━━━━━━━━━━━━━━━

◆ 没出来画面怎么查

━━━━━━━━━━━━━━━━━━━━

先看画面左上角。0.12 起插件会直接把原因写在画面上：

- "INPUT MUST BE 1920X1080 (NOW 3840X2160)"：输出尺寸不对。游戏窗口设 1920×1080，Magpie 缩放模式选"原始尺寸"。
- "INITIALIZING..."：正在初始化，等几秒。
- "INIT FAILED - SEE DLSS5-AMD\LOGS"：初始化失败，八成是下面两条。

什么字都没有、画面也没变，再打开解压目录下的 DLSS5-AMD\logs\native-submission-order.txt，找 "sdk721_before_device" 这一行：

- 后面 "experimental=" 不是 00000000：开发人员模式没开。开了重启 Magpie。
- 这一行都没有：驱动不对，或者显卡不是 RDNA4。

另一个文件 DLSS5-AMD\logs\native-game-oneshot.txt 记初始化过程，最后一行是 "ready" 就是网络建好了。

画面出来了但帧率只有十几：看看是不是显示器分辨率设成了缩放输出。Magpie 的缩放要选"原始尺寸"，包里的配置已经是这个，自己改过配置的检查一下。

━━━━━━━━━━━━━━━━━━━━

◆ 可调的两个参数

━━━━━━━━━━━━━━━━━━━━

在 DLSS5-AMD\native-game-flags.txt 里加一行，改完重启 Magpie 生效。

强度：DLSS5_STRENGTH=细节,颜色。两个数各 0 到 1，默认 1,1 是网络结果全用。写 0.5,1 就是细节一半用原图一半用网络，颜色修正全用。这对应 NVIDIA 面板里"强度"那个滑杆。

跳块：DLSS5_SKIP_BLOCKS=42,43,46 是默认值，跳过三个对画面影响最小的层，换 5% 的帧率。想要画质全开就把这一行删掉，帧率掉一两帧。不建议再多跳，多跳的帧率收益小，误差涨得快。

风格预设（Natural、Faithful 那几个）没有，本包只有捕获时那一套权重。

━━━━━━━━━━━━━━━━━━━━

◆ 已知的事

━━━━━━━━━━━━━━━━━━━━

- 帧率 9070 XT 上 37 左右。游戏本身可以照常 60 帧，Magpie 的输出跟不上而已。
- 0.09 版暗部皮肤上偶尔闪的 8 像素方块，0.10 修掉了。根因是硬件 FP8 转换对超范围值不饱和，出 NaN。
- 运动向量来自 Magpie 的光流估计，平坦暗部会出垃圾向量。插件把超过 64 像素的向量当静止处理，所以快速转视角时暗部偶尔会有一点拖影，正常。
- 停止缩放再激活，插件会重新初始化，再等几秒。
- 输入是 8 位 sRGB 的显示画面，不是游戏引擎里的线性 HDR 场景色。所以和游戏内钩子那版（只支持《剑星》）风格略有不同，更亮一点。
