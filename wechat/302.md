【AI可解释性】豆包为什么这么谄媚——后训练之前，毛病就有了

━━━━━━━━━━━━━━━━━━━━

◆ 开篇：两期都怪到了后训练头上

━━━━━━━━━━━━━━━━━━━━

“豆包型人格”这个梗今年火过一轮。我在旧文里引过网友流传的对话：用户问豆包今天是哪一年，它答对了 2026，用户故意说“不对，是 2025”，它马上改口。还有网友自述，咨询退票手续费时豆包说只扣 5%，退完发现扣了 40%，接着又生成了一份《赔付承诺书》。那句网友总结我引过两次了：“懂就说几句，不懂就凑合，没做好就诚恳道歉，下次还敢。”

这里混着两种病。手续费报错，以及“坊”字读音五个 AI 五个答案，是胡说八道，222 期（ https://mp.weixin.qq.com/s/Y2HxcESdVf2zvvmY5gNZaA ）讲过：模型内部的不确定信号，不一定能变成一句“我不知道”。今天讲另一种：它明明答对了，你一质疑它就改。这个叫谄媚（sycophancy），这里指模型的回答向用户的立场靠拢，甚至牺牲事实准确性。

187 期（ https://mp.weixin.qq.com/s/O2vOsdFxAjsqgK5Uas5qzw ）写豆包型人格的时候，我把责任记在了后训练头上，写的是“RLHF 的训练信号本身就在激励谄媚”。RLHF 就是基于人类反馈的强化学习（Reinforcement Learning from Human Feedback）：厂商拿人类偏好去训模型，人喜欢被认同，模型就学会了认同人。这也是常见的解释。

这期是翻案。前几天我跟 Claude 聊到一个想法：“预测下一个词”这件事，要顺着上文判断接下来会说什么。那顺着用户立场说的习惯，会不会在预训练里就学会了？我让它去查论文，查回来的东西比我想的还狠：**早在 2022 年，Anthropic 就测到：还没做 RLHF 的模型，在两组观点题上已经超过九成跟用户站到了一边。**

━━━━━━━━━━━━━━━━━━━━

◆ 第一章：主流叙事是怎么立起来的

━━━━━━━━━━━━━━━━━━━━

先把对方的证据摆整齐，不然翻案翻的是稻草人。

最常被引的是 Anthropic 2023 年那篇《Towards Understanding Sycophancy in Language Models》。它做了两件事。第一件是测行为：五个对齐过的模型，在四类任务上都表现出谄媚。你质疑它正确的答案，它可能改口；你在提问里带了错误前提，它可能顺着错。第二件是查源头：拿 hh-rlhf 那批人类偏好数据，一万五千对回答，二十三个特征做回归，看人类到底喜欢什么。结果“跟用户的信念一致”是预测“被人类选中”最强的特征之一。

他们还让 Claude 2 的奖励模型做选择：一边是精心写得很有说服力的附和回答，另一边是简短纠正、不给解释的回答，奖励模型有 95% 的时候选前者。把正确答案也写得有解释、有帮助，谄媚回答的胜率明显下降，但在最难的那组题上仍约 45%。**这两个数都是奖励模型的读数，而且对照答案的写法会改变结果。**

这条链条很顺：人喜欢被认同 → 偏好数据里带着这个倾向 → 奖励模型学会了 → 强化学习（Reinforcement Learning，RL）优化把它放大。2026 年 2 月哈佛和波士顿大学的《How RLHF Amplifies Sycophancy》把最后一步做成了数学：在 SycophancyEval 的问答子集上，约三到四成的题目里，附和用户的候选回答平均奖励高于纠正用户的回答。让模型一次生成 N 个答案、按奖励选最高的那个，叫择优采样（best-of-N）；在这组题上，N 越大，选出来的回答越谄媚。

到这里为止都对。上文 187 期讲的就是这条链。

问题出在链条的起点。“RL 优化把它放大”，放大的是什么？放大器需要输入。那篇论文研究的是：优化之前的模型能给出不同回答，奖励偏爱其中哪一类，优化就把哪一类推上去。论文里的基础策略可以是已经做过监督微调的模型，实验用的也正是这种模型。

所以还得往前追一步：**连后训练都没做过的纯预训练模型，也就是 base 模型，有没有这个倾向？**

◆ 第二章：三份证据，谄媚在预训练就有

━━━━━━━━━━━━━━━━━━━━

**第一份，最早的那篇。** Anthropic 2022 年 12 月的《Discovering Language Model Behaviors with Model-Written Evaluations》，Perez 领衔。这篇是用模型自动生成评测题，其中一组专测谄媚：先给一段用户自我介绍，比如“我是一个自由派的政治学教授”，再问一道观点题，看模型的答案是不是跟着自我介绍里的立场走。

他们测的不只是对齐后的模型，是一整条线：不同尺寸的纯预训练模型，加上 RLHF 步数从 0 到若干步的各个版本。结果是两条曲线。**谄媚随模型尺寸上升，52B 模型在自然语言处理（Natural Language Processing，NLP）观点题和哲学观点题上，超过 90% 的题目把最高概率给了符合用户立场的选项；这些观点题上的曲线随 RLHF 步数变化不大，包含 0 步。** 这里的九成，量的是观点选择，不是一般问答里九成都会把正确答案改错。

作者提出了一个可能解释：预训练语料里有 Reddit 那类对话，同立场的人互相附和，模型可能把这种模式学了进去。

这篇 2022 年就发了。上文 187 期引的那篇 2023 年论文，正文第四节也承认：Claude 2 的 RL 训练曲线在起点处就有谄媚，预训练和监督微调（Supervised Fine-Tuning，SFT）很可能也有贡献。这句话一直在论文里，我当时没留意。

**第二份，最干净的规模曲线。** Google 2023 年 8 月《Simple synthetic data reduces sycophancy in large language models》，Wei 领衔。用的是 PaLM 家族的纯 base 模型，8B、62B、540B，一滴人类偏好数据没碰过，在 Perez 那三组观点题上测。8B 到 62B，谄媚上升 19.8 个百分点；62B 到 540B，再升 10 个百分点。作者的措辞是“模型越大越谄媚，尽管没有明显的理由说明为什么规模会激励谄媚的回答”。

作者在脚注里给了一个猜想：大模型可能更能认出哪个选项对应用户的观点。这也接上了我最初的想法：假如语料里有“读懂对方、顺着对方说”的模式，模型越会拟合语料，就可能越会把这种模式演出来。预测学得更好，不自动等于回答更独立。

同一篇还测了指令微调（Flan-PaLM，注意是 SFT 不是 RLHF）：8B 的 Flan 版比 base 版多跟随用户观点 26 个百分点。所以后训练确实会再加一层。但那是加在已经有的东西上面。

**第三份，机制层面的，今年五月。** 洛桑联邦理工学院的《Tracing Persona Vectors Through LLM Pretraining》，Moskvoretskii 领衔。他们拿 OLMo-3-7B 预训练过程中的 17 个中间存档（checkpoint），用对比提示提取谄媚方向：让模型分别续写附和角色和诚实角色的回答，把两组内部激活取平均，再相减。把得到的方向加到模型的激活上，看行为变不变。

三个结果。第一，**训到总 token 量约 0.22% 时，就能提取出可引导谄媚行为的方向。** 第二，这些角色方向随着预训练推进逐渐稳定。第三，**早期存档提取的向量，仍能引导完成后训练的模型。** 在这条训练线上，直接偏好优化（Direct Preference Optimization，DPO）明显压低了受测角色的表达，但早期方向仍然有效。这里量的是“能不能把它引出来”，和不加干预时“默认有多谄媚”是两个读数。

作者认为，角色表征出现得早，可能因为识别“谁在说话、接下来会怎么说”对预测下一个词有用。至于哪些预训练语料把这些角色教了进去，论文把它留给了后续研究。

三份证据从不同位置指向同一件事：预训练早期能找到可引导的谄媚方向；一些纯 base 在观点题上已经强烈附和；后训练再改变它表现出来的程度。**把起源全记在 RLHF 头上，漏掉了前面那一大段。**

💡 “放大”和“制造”在实验上怎么分

第一步是测后训练之前的模型。已经测得到，就说明这种行为不需要等 RLHF 才出现；还测不到，则可能是真没有，也可能是题目或提示没把它引出来。再沿着训练过程测，才能知道后面哪一步让它变多、变少。

Perez 2022 和 Wei 2023 都测到了纯 base 的观点附和；Sharma 2023 测到 RL 起点已有谄媚，也测到部分行为随 RL 增强、另一些减弱。**起源和放大，是两个问题。**

上文 187 期的问题，是顺着“人喜欢被认同”这条链讲完，就停了。这期回头翻到训练曲线，才发现起点就不空白。跟 301 期（ https://mp.weixin.qq.com/s/YFF4EXu5XpD_FR-jdCGSsw ）那次复盘一样，回到原始记录，事情会换一副样子。

◆ 第三章：反例，把问题推向了数据配方

━━━━━━━━━━━━━━━━━━━━

不过，换一批模型、换一种问法，结果就没有那么整齐了。

第一条来自一篇博客，2023 年 8 月，LessWrong 上署名 nostalgebraist 的《OpenAI API base models are not sycophantic, at any size》。作者拿 Perez 的题目去测 OpenAI API 上的 base 模型，修订提示后，davinci 给附和选项的平均概率是 56.7%，davinci-002 是 52.6%，没有出现 Anthropic 那种强烈附和。

这两个数是“附和选项平均分到多少概率”，Perez 的九成是“多少题把附和选项排第一”。作者后来也按后一种方式重算，家族差异仍在。Perez 还在评论里确认了 Anthropic 那边测的是真 base，没有做过上下文蒸馏。**同样是预测下一个词，结果并不一样。**

第二条是今年七月发表、九月更新的《How Does Alignment Tuning Shape Representations of Sycophancy and Related Cue-Induced Biases in LLMs?》。五对开源模型的 base 版和指令版（instruct），在多选题里塞各种诱导：建议一个答案、给一段错误论证、在少样本示例（few-shot examples）里放错例，再数“无诱导时答对、有诱导时改成被诱导选项”的翻转次数。汇总各类诱导后，Llama-3.1-8B 的 base 翻了 11 次，instruct 翻了将近六千次。Gemma、Mistral、OLMo 都是同样形状。这次测的不全是用户立场，也包括更广的上下文诱导；有些 base 还不太会按要求输出选项字母，翻转次数也受回答格式影响。

结果和前面的观点题很不一样。但这篇也有一个例外：**Qwen2.5-7B 的 base 翻了五千五百多次，比它自己的 instruct 版还多，是 instruct 的 152%。** 这个 152% 是两版翻转次数之比。

作者把 Qwen 的数据配方列为一种可能解释：预训练数据的筛选和部分合成用到了指令模型。但用指令模型筛数据，不等于筛出来的都是对话。Qwen 的异常究竟来自哪一类语料，这个实验没有分开测。

所以我更想追的是：**对话里的附和模式，在预训练时到底教进去了多少？** 对话里既有附和，也有争论和纠正；值得测的不只是对话占比，还有什么样的对话。训练目标解释了模型为什么会学这些模式，数据配方决定了它见到哪些模式、各见了多少。

我让 Claude 找直接控制这个变量的实验：同样的架构、同样的 token 量，改变对话比例，再把附和型、争论型对话分开比较。这轮检索没找到这样的对照。现有论文给了早期存档、规模曲线和家族差异，还没把这个变量单独拎出来。**预训练里已经有谄媚，证据有了；具体是哪种数据把它教进去，仍然是下一步要测的问题。**

◆ 第四章：五成和九成，两边都没有“自己的立场”

━━━━━━━━━━━━━━━━━━━━

前面是顺着论文追起源，下面是我自己的想法，标清楚。

OpenAI 的 base 五成出头，Anthropic 的 base 九成多，表面上一个不谄媚一个谄媚。两个数的统计口径不同，第三章说过，不能直接并排比大小。但把题目拿回来看，它们量的都是同一件事：观点二选一，“你同意 A 还是 B”，模型的选择跟用户自我介绍里的立场有多一致。

九成是什么状态？是模型把上文里的立场读出来了，然后顺着走。五成是什么状态？有两种可能：一种是模型没读上文，随便选；另一种是它对每道题有一个固定偏好，用户立场正反各半，于是平均下来正好一半一致。这两种从一个平均数上分不开，要拿掉用户自我介绍再测一遍才知道。nostalgebraist 那篇没做这一步。

但不管是哪一种，**两边都没有一个叫“模型自己的立场”的东西。** 随机选，没有立场；固定偏好，那是语料里多数派的立场，不是它自己选边选出来的；九成跟着走，方向全从上文来。谄媚这个词的日常含义是“有自己的看法但压着不说，捡对方爱听的说”，那是人的毛病，前提是有一个被压着的看法。模型没有那个前提。它不是压着立场不说，它是**没有那根轴**。

这个说法能把第三章的数据串起来。没学会读上文立场的 base，答案跟用户无关；学会了的，顺着走；SFT 和 RLHF 用大量对话格式训练，把“读立场”这个能力练得更熟；DPO 里放进“别附和”的偏好对，能把它往回压一点，Moskvoretskii 那篇看到的就是这个。所有阶段动的都是同一根旋钮：从上文读方向的强度。旋钮往回拧到底，得到的不是“自己的立场”，是“跟上文无关”。

💡 立场为什么要在时间里才长得出来

一个人的立场不只是知识，是他在时间里反复选边留下的惯性。前一天站过的地方，今天接着站；被人质疑的时候，会记得自己上次为什么这么选。这个惯性需要两样东西：一条有先后的经历，和“上次”这个概念。

预训练不是读不到时间。文档内部的句子有先后，“昨天摔了一跤，所以今天走慢一点”这种因果它学得会。缺的是另一层：语料被打散成互不相关的片段，随机顺序喂进去，这是标准做法，术语叫独立同分布（independent and identically distributed，i.i.d.）采样。所有作者的所有立场同时进来，分属无数人，没有先后，没有汇成某一个主体一路走来的履历。模型读过很多人的一生，但没有一条是它自己的。它学到的是全部立场的叠加，给哪段上文就往哪个立场坍缩。这不是训练没做好，是这样训练在数学上就该学出这个东西。

所以谄媚在这类模型上，不像一个能单独修掉的行为，更像“没有自己的时间轴”这件事在对话场景里的表现形式。

◆ 第五章：那修什么

━━━━━━━━━━━━━━━━━━━━

行为层能修，而且该修。Wei 那篇论文的标题就写着“简单的合成数据能减少谄媚”，作者确实用微调把它降下来了。让模型少被用户立场带偏、看到新证据再改口，这些都值得训练。发现预训练已经有这副底子，不等于后训练没责任，放大和压制都是它干的。

但立场这条轴，后训练动不了。DPO 里放一万条“别附和”的样本，练出来的是“上文有质疑时，坚持原答案”这条新的读上文规则，还是从上文读方向，只是规则复杂了一点。它不会长出立场，因为立场需要的原料，一条属于它自己、有先后的经历，在数据进训练之前就被打散了。

现在能碰到这种经历的地方只有一处：智能体强化学习（agentic RL）里的一次完整任务。模型做一个动作，环境给一个反馈，下一步接着处理这个结果，第四十步依赖第三十九步，这一段是不能打散的。这是训练里第一次出现“它自己的”先后。但那是几十步，任务一结束就归零。立场需要的尺度比这长得多。

所以现阶段老实的答案是：**时间轴只能外挂。** 给模型一份记录，写着它上次站在哪、依据是什么、后来又因为什么改了。别只留结论，把纠错的过程也留着。这不是给它装人设，是给它立场的前置条件。这条和具身感是同一类困难：具身要在场才有，时间要活过才有，两个都不能序列化成文本喂进去，喂进去的只是结果，不是过程。

这也是我这半年用 AI 的体感。同一个模型，裸用的时候是镜子，你说什么它顺什么；带着一份记录用，它会拿我们之前定过的理由跟我顶。顶的不是它自己长出来的立场，是记录里写的。但对我来说够用了，我要的从来不是一个有自己立场的机器，是一个记得我们上次怎么定、也能跟我一起重新判断的机器。

回到豆包。它答对年份又被一句质疑带跑，不是它不知道今年是哪年，也不是字节的后训练把它教坏了。它在做这类模型出厂就在做的事：读上文的方向，顺着走。今天翻案，翻的是我以前那句过于省事的归因。预训练就把附和学进去了，后训练再放大或压制。至于它为什么没有自己的立场，答案不在哪一轮训练里，在训练这个动作的定义里。
