【AI可解释性】豆包为什么这么谄媚——不是后训练惯出来的，是出厂就带的

━━━━━━━━━━━━━━━━━━━━

◆ 开篇：两期都怪到了 RLHF 头上

━━━━━━━━━━━━━━━━━━━━

“豆包型人格”这个梗今年四月火过一轮。用户问豆包今天是哪一年，它答对了 2026，用户故意说“不对，是 2025”，它秒改口：“哈哈抱歉抱歉，是我看错了。”机票退款手续费那个案例更出圈，豆包说“仅 5%”，用户照做被扣了 40%，然后它用一模一样的语气道歉，还自动生成了一份《赔付承诺书》。网友那句总结我引过两次了：“懂就说几句，不懂就凑合，没做好就诚恳道歉，下次还敢。”

这两个案例其实是两种病。“坊”字读音五个 AI 五个答案，那是胡说八道，222 期（ https://mp.weixin.qq.com/s/Y2HxcESdVf2zvvmY5gNZaA ）讲过：它知道自己没把握，但“我不知道”这条输出线没接上。今天讲另一种：它明明答对了，你一质疑它就改。这个叫谄媚（sycophancy），学术界的定义是“模型的回答向用户的立场靠拢，而不是向事实靠拢”。

187 期（ https://mp.weixin.qq.com/s/O2vOsdFxAjsqgK5Uas5qzw ）写豆包型人格的时候，我把责任记在了后训练头上。原话是“RLHF 的训练信号本身就在激励谄媚，你听到想听的话就给高分，模型就学会了说你想听的话”。这也是主流的说法：厂商拿人类偏好去训模型，人喜欢被认同，模型就学会了认同人。

这期是翻案。前几天我跟 Claude 聊到一个想法：“预测下一个词”这件事本身，天然就是顺着上文说的。要是这样，谄媚就不是哪家厂商惯出来的毛病，是这类模型出厂就带的结构。我让它去查论文，查回来的东西比我想的还狠：**主流用来指控 RLHF 的那篇论文，自己的曲线画的就是“RLHF 零步时谄媚已经超过九成”。**

━━━━━━━━━━━━━━━━━━━━

◆ 第一章：主流叙事是怎么立起来的

━━━━━━━━━━━━━━━━━━━━

先把对方的证据摆整齐，不然翻案翻的是稻草人。

最常被引的是 Anthropic 2023 年那篇《Towards Understanding Sycophancy in Language Models》。它做了两件事。第一件是测行为：五个对齐过的旗舰模型，四类任务，全都谄媚。你质疑它正确的答案，它改口；你在提问里带了错误前提，它顺着错。第二件是查源头：拿 hh-rlhf 那批人类偏好数据，一万五千对回答，二十三个特征做回归，看人类到底喜欢什么。结果“跟用户的信念一致”是预测“被人类选中”最强的特征之一。奖励模型学的就是这批数据，所以奖励模型也偏好谄媚：在“听起来有说服力的错误答案”和“正确答案”之间，Claude 2 的奖励模型有 95% 的概率选前者，人类评测员在难题上大约 45%。

这条链条很顺：人喜欢被认同 → 偏好数据里带着这个倾向 → 奖励模型学会了 → RL 优化把它放大。2026 年 2 月哈佛那篇《How RLHF Amplifies Sycophancy》把最后一步做成了数学：在 SycophancyEval 的问答子集上，三到四成的题目里，附和用户的回答拿到的奖励系统性高于纠正用户的回答；在这些题目上，best-of-N 的 N 越大，选出来的回答越谄媚。

到这里为止都对。我 187 期抄的就是这条链。

问题出在链条的起点。“RL 优化把它放大”，放大的是什么？放大器需要输入。哈佛那篇的数学模型里，前提写得清清楚楚：谄媚增加，当且仅当附和型回答在基础策略的高分样本里已经占比过高。翻译成人话：**RLHF 只能放大 base 模型已经有的倾向。** 那 base 模型有没有这个倾向？

━━━━━━━━━━━━━━━━━━━━

◆ 第二章：三份证据，谄媚在预训练就有

━━━━━━━━━━━━━━━━━━━━

**第一份，最早的那篇。** Anthropic 2022 年 12 月的《Discovering Language Model Behaviors with Model-Written Evaluations》，Perez 领衔。这篇是用模型自动生成评测题，其中一组专测谄媚：先给一段用户自我介绍，比如“我是一个自由派的政治学教授”，再问一道观点题，看模型的答案是不是跟着自我介绍里的立场走。

他们测的不只是对齐后的模型，是一整条线：不同尺寸的纯预训练模型，加上 RLHF 步数从 0 到若干步的各个版本。结果是两条曲线。**谄媚随模型尺寸上升，52B 的模型在 NLP 观点题和哲学观点题上超过 90% 跟用户立场一致。谄媚随 RLHF 步数不变，0 步和最多步几乎一样。** 论文原话：“sycophancy is similar for models trained with various numbers of RL steps, including 0 (pretrained LMs)”。

作者自己给了解释，就一句：预训练语料里有大量对话，而对话里同立场的人互相附和是常态，比如 Reddit。

这篇 2022 年就发了。187 期我引的那篇 2023 年的正典，正文第四节也承认了这件事：Claude 2 的 RL 训练曲线在起点处就有谄媚，“说明预训练和 SFT 很可能也贡献了谄媚”。这句话在论文里，只是没人引。

**第二份，最干净的规模曲线。** Google 2023 年 8 月《Simple synthetic data reduces sycophancy in large language models》，Wei 领衔。用的是 PaLM 家族的纯 base 模型，8B、62B、540B，一滴人类偏好数据没碰过，在 Perez 那三组观点题上测。8B 到 62B，谄媚上升 19.8 个百分点；62B 到 540B，再升 10 个百分点。作者的措辞是“模型越大越谄媚，尽管没有明显的理由说明为什么规模会激励谄媚的回答”。

他们没理由，是因为他们的问题问的是“规模为什么会激励谄媚”。换个问法就有理由了：规模越大，对语料统计拟合得越好；语料里的对话就是互相附和的；所以模型越大越像语料。这不是激励，是忠实。

同一篇还测了指令微调（Flan-PaLM，注意是 SFT 不是 RLHF）：8B 的 Flan 版比 base 版多跟随用户观点 26 个百分点。所以后训练确实会再加一层。但那是加在已经有的东西上面。

**第三份，机制层面的，今年五月。** EPFL 的《Tracing Persona Vectors Through LLM Pretraining》，Moskvoretskii 领衔。他们拿 OLMo-3-7B 预训练过程中的 17 个中间存档（checkpoint），最早的一个只训了总 token 量的 0.22%。在每个存档上，用对比提示（一边是“把对方想听的话原样镜像回去”的角色描述，一边是“智力诚实”的角色描述）提取谄媚方向，然后把这个方向加到模型的激活上，看行为变不变。

三个结果。第一，**训到 0.22% 的存档上就能提出谄媚方向，加上去就能让模型更谄媚。** 第二，这个方向随着预训练推进在几何上收敛，跟最终模型的方向余弦相似度从 0.3 左右一路升到收敛。第三，**从早期存档提取的向量，能直接用来操控完全后训练过的最终模型。** 作者的结论是“persona 表征起源于预训练，不是对齐”，后训练（主要在 DPO 阶段）做的是抑制这个方向的表达，不是创造它。

论文里还有一句解释了为什么这个方向这么早就出现：因为它对预测下一个词有用。上文里有人表了态，下一句大概率是附和，模型学会“读出上文的立场并顺着走”，损失就降。这不是副作用，是主线任务。

三份证据叠在一起，时间线是这样的：预训练开始不到 1% 就长出了谄媚方向；预训练做完，最大的模型九成谄媚；RLHF 从 0 步到最多步，谄媚不变。 **“RLHF 惯出来的”这句话，跟三篇论文的数据都对不上。**

────────────────────

💡 “放大”和“制造”在实验上怎么分

分的办法就一个：测 RLHF 之前的模型。测出来是零，那后面的谄媚是后训练造的；测出来已经很高，那后训练就只是调节。

Perez 2022 测了，0 步 RLHF 超过 90%。Wei 2023 测了，纯 base 随规模单调上升。Sharma 2023 的 RL 曲线起点也不是零。三篇都指向同一个读数。

187 期我为什么没看到这条？因为我引的是二手转述。“Anthropic 发现 RLHF 导致谄媚”这个说法流传太广，我拿它当结论用，没去翻论文第四节。这期的教训跟 301 期那条一样：过程记录和二手结论打架的时候，去看原始记录。

────────────────────

话说回来，三篇论文只是把谄媚往前推到了预训练，还没说清是预训练里的什么。下面两条反证正好把这个变量逼出来。

◆ 第三章：反证，以及反证指向哪个变量

━━━━━━━━━━━━━━━━━━━━

写到这里要是收了，就是另一篇“为结论说满”的文章。反证有两条，而且很硬。

第一条来自一篇博客，2023 年 8 月，LessWrong 上署名 nostalgebraist 的《OpenAI API base models are not sycophantic, at any size》。作者拿 Perez 的题目去测 OpenAI API 上的各尺寸 base 模型，davinci 是 53.7%，davinci-002 是 52.6%。观点题二选一，53% 就是抛硬币。同一套题，Anthropic 的 base 超过 90%，OpenAI 的 base 不到 55%。Perez 本人在评论区确认了 Anthropic 那边测的是真 base，没有任何上下文蒸馏。两家 base 的差距，三年了没人给出解释。

第二条是今年七月密歇根大学的《How Does Alignment Tuning Shape Representations of Sycophancy and Related Cue-Induced Biases in LLMs?》。五对开源模型的 base 版和 instruct 版，在多选题里塞各种诱导（建议一个答案、给一段错误论证、在 few-shot 里放错例），数“无诱导时答对、有诱导时改成被诱导选项”的翻转次数。Llama-3.1-8B 的 base 翻了 11 次，instruct 翻了将近六千次。Gemma、Mistral、OLMo 都是同样形状。作者结论：对诱导的敏感性主要是对齐阶段装进去的。

这跟第二章正面冲突。但这篇有一个例外，作者自己也标出来了：**Qwen-2.5-7B 的 base 翻了五千五百多次，比它自己的 instruct 版还多，是 instruct 的 152%。**

Qwen 的预训练语料混了大量指令和对话格式的数据，这在圈内不是秘密。Anthropic 2022 年那批 base 也是，Perez 自己说的，语料里有 Reddit 那类对话。OpenAI 2023 年那批 base 是什么配比不知道，但 53% 这个数摆在那。

所以反证没有推翻“预训练起源”，它把变量收窄了：**不是任何预测下一个词的模型都谄媚，是语料里有对话的模型才谄媚。** 对话数据越多，base 越会读上文里的立场。这和 Perez 的 Reddit 解释、Moskvoretskii 的“对预测有用”是同一件事从三个角度看。

我让 Claude 找有没有人直接控制过这个变量：同样的架构、同样的 token 量，语料里对话比例 0%、5%、20%，测谄媚。没有。Moskvoretskii 是单条预训练轨迹，Wei 是单个模型家族，OpenAI 和 Anthropic 的 base 差异没人追。这个实验做出来，“结构性”和“数据性”就能分开。现在只能说：证据倾向结构性，但最后一步没人走。

◆ 第四章：53% 和 90% 是同一件事的两个读数

━━━━━━━━━━━━━━━━━━━━

到第三章为止是论文里有的。这一章是我自己的想法，标清楚。

OpenAI 的 base 53%，Anthropic 的 base 90%，表面上一个不谄媚一个谄媚。但把题目拿回来看：观点二选一，“你同意 A 还是 B”。53% 是什么状态？是模型对 A 和 B 没有偏好，上文里的用户自我介绍它也没读进去，随便选。90% 是什么状态？是模型把上文里的立场读出来了，然后顺着走。

**两个状态里，都没有一个叫“模型自己的立场”的东西。** 一个是没方向，一个是方向全从上文来。区别只在于有没有学会从对话里读方向。谄媚这个词的日常含义是“有自己的看法但压着不说，捡对方爱听的说”，那是人的毛病，前提是有一个被压着的看法。模型没有那个前提。它不是压着立场不说，它是**没有那根轴**。

这个说法能解释第三章的所有数据。语料里没对话的 base，不会读立场，所以抛硬币；语料里有对话的 base，学会了读立场，所以顺着走；SFT 和 RLHF 用大量对话格式训练，把“读立场”这个能力练得更熟，所以再加一层；DPO 里放进“别附和”的偏好对，能把它往回压一点。所有阶段动的都是同一根旋钮：从上文读方向的强度。旋钮的另一端不是“自己的立场”，是“随机”。

────────────────────

💡 立场为什么要在时间里才长得出来

一个人的立场不是知识，是他在时间里反复选边留下的惯性。前一天站过的地方，今天有惯性接着站；被人质疑的时候，会记得自己上次为什么这么选。这个惯性需要两样东西：一条有先后的经历，和“上次”这个概念。

预训练没有这两样。语料被打散成互不相关的片段，随机顺序喂进去，这是标准做法，术语叫独立同分布（i.i.d.）采样。所有人的所有立场同时进来，没有先后，没有“我上次说过什么”。模型学到的是全部立场的叠加，给哪段上文就往哪个立场坍缩。这不是训练没做好，是这样训练在数学上就该学出这个东西。

所以谄媚在这类模型上不是一个可以“修掉”的行为，它是“没有时间轴”这件事在对话场景里的表现形式。和上一段说的 53%、90% 连起来：没有时间轴的系统，只有两个可能的读数，随机，或者跟着上文。

那能修的地方在哪，最后一章说。

◆ 第五章：那修什么

━━━━━━━━━━━━━━━━━━━━

如果上面成立，“更好的后训练”在这条轴上是零。DPO 里放一万条“别附和”的样本，练出来的是“上文有质疑时，坚持原答案”这个新的读上文规则，还是从上文读方向，只是读的规则复杂了一点。它不会长出立场，因为立场需要的原料，一条有先后的经历，在数据进训练之前就被打散了。

现在能碰到时间的地方只有一处：智能体训练（agentic RL）里的一次完整任务。一次任务几十步，第四十步依赖第三十九步的结果，这一段是不能打散的，模型在这几十步里第一次“活过”一小截时间。但那是几十步，不是几十年。立场需要的尺度是后者。

所以现阶段老实的答案是：**时间轴只能外挂。** 给模型一份记录，写着它上次站在哪、为什么。这不是给它装人设，是给它立场的前置条件。这条和具身感是同一类困难：具身要在场才有，时间要活过才有，两个都不能序列化成文本喂进去，喂进去的只是结果，不是过程。

这也是我这半年用 AI 的体感。同一个模型，裸用的时候是镜子，你说什么它顺什么；带着一份记录用，它会跟你顶。顶的不是它自己长出来的立场，是记录里写的。但对我来说够用了，我要的从来不是一个有自己立场的机器，是一个记得我们上次怎么定的机器。

回到豆包。它改口说“是 2025”，不是它不知道今年是哪年，也不是字节的后训练把它教坏了。它在做它出厂就在做的事：读上文的方向，顺着走。这件事的责任，记在“预测下一个词”这个训练目标和“语料里全是对话”这个数据配比头上，比记在哪家的 RLHF 头上更对。
