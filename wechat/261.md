◆ GRPO 站在后训练的哪一步

━━━━━━━━━━━━━━━━━━━━

大模型的训练分两大阶段。**预训练**是让模型读遍互联网学会说话；**后训练**是把这个会说话但没规矩的模型，调教成能干活的助手。这张卷子考的全是后训练。

后训练最常用的两招，用刷题打个比方：

**第一招，SFT（监督微调）**：给模型看标准示范，让它逐字模仿——相当于背例题。你写好一问一答的范文，模型照着学，学的是"遇到这种问题，好答案长这样"。

**第二招，RL（强化学习）**：不给示范了，让模型自己做题，按做得好坏给反馈——相当于刷题拿分数。模型对一道数学题自己写出一份解答，判分器对一下答案：对了给 1 分，错了给 0 分。这个分数就叫 reward（奖励分）。

刷题拿分数听起来简单，但有个不那么显眼的问题：**原始分数没法直接当学习信号。** 模型答对一道送分题拿了 1 分——这 1 分是它厉害，还是题太简单？答错一道竞赛题拿了 0 分——是它太差，还是题本来就没人做得出来？分数只有跟"正常水平"比过之后才有含义。所以 RL 需要一个参照物：真正有效的信号不是"你得了几分"，是"你比正常水平好多少"。

那"正常水平"从哪来？老办法（PPO，一种经典强化学习算法）是专门再训练一个"估分模型"，用它来预测每道题的正常水平。这条路能走，但贵：训练时要同时伺候好几个大模型，而且估分模型自己也可能估不准，一错就把主模型带偏。

GRPO（组相对策略优化）的做法简单到近乎粗暴：**不请裁判了。同一道题让模型自己答 8 遍，这 8 条回答的平均分，就是"正常水平"。** 你比这 8 条的平均好，就该加强；比平均差，就该压低。组内兄弟互相当参照物，省掉了整个估分模型。这就是后来 DeepSeek 训练 R1 推理模型用的那套方法，GRPO 这个名字也是 DeepSeek 的论文提出的。

其实 85 期（ https://mp.weixin.qq.com/s/ivHI1kEMyvVtiZ1EdMBL2w ） 讲过这段公案：PPO 要四个模型同时住在显存里，GRPO 把裁判砍掉省下一半显存——那篇算的是**架构账**，为什么便宜。我当时的理解也就停在"让选手互相排名，大概是这样"。这张卷子逼人往下走了一步：排名到底怎么算成数字、那个数字又意味着什么——这次算的是**信号账**。把"你比同组平均好多少"写成公式，就是下一节的主角。

━━━━━━━━━━━━━━━━━━━━

◆ 先把公式放在桌上

━━━━━━━━━━━━━━━━━━━━

GRPO 的核心操作只有一步。对一道题，让当前模型自己生成 G 条回答（比如 G = 8 条），给每条回答打一个分数 r_i——r 就是上一节说的 reward 的首字母，这个原始分就是 reward 本尊。

顺便把丑话说在前面：**reward 没有公式。** 它不是算出来的，是判出来的——判分器给什么就是什么，它是整条流水线里唯一从外部世界进来的信息（标准答案是人准备的）。具体怎么判？拿 DeepSeek 训练 R1 的做法说，判分器不是什么神秘的 AI，就是一段脚本：

- **数学题**：训练数据里每道题都带标准答案。要求模型把最终答案写进指定格式（比如放进一个答案框里），脚本把它抠出来、跟标准答案比对——一致 r = 1，不一致 r = 0。
- **代码题**：直接把模型写的代码扔进编译器跑测试用例，通过给分，不通过没分。
- **格式分**：另有一小份奖励管格式，比如思考过程必须包在规定的标签里，不守格式扣分。

注意 DeepSeek 在 R1 论文里特意说明：他们**没有**用神经网络当判分器，就用这种能自动核对的规则分。理由是神经网络判分器会被模型学会讨好、钻空子——这个隐患是什么样子，第 19 题会给你看现场。这种"答案能机器核对、reward 用规则算"的训练路数，行话叫 **可验证奖励（RLVR）**。

数学题的判分写成代码就一句话：

```python
r = 1 if extract_answer(回答) == 标准答案 else 0    # reward 的全部数学
```

现在正式开工。手上有一道题——比如"解方程 x² − 5x + 6 = 0"，标准答案 x = 2 或 3——让模型答 G = 8 遍，8 条回答各自过一遍判分脚本，得到 8 个原始分 r_1 到 r_8，一串 0 和 1。整条流水线于是长这样：**一条回答 → 判分脚本 → r_i（reward，原始分）→ 组内归一化 → A_i（advantage，更新信号）**。拿到 8 个原始分数后，归一化那一步：

```
A_i = (r_i − mean) / std

mean = (r_1 + r_2 + … + r_8) / 8              # 组内平均
std  = √( Σ(r_i − mean)² / 8 )                # 组内标准差：先看每条分数偏离平均多远，
                                              # 平方后取平均再开根，衡量组内波动大小
```

其中 mean 是这 8 条回答分数的组内平均，std 是组内标准差（统计课上的总体标准差，除数用 8 不用 7）。算出来的 A_i 叫 advantage（优势值），它才是真正拿去更新模型参数的信号：A_i 为正的回答，其生成路径被加强；A_i 为负的，被压低。

输入是 8 个原始分数，操作是"减去组内平均、除以组内波动"，输出是 8 个优势值。注意这一步做完之后，**原始分数是多少已经不重要了，重要的是你比同组兄弟好多少**。r = 1 不代表你会被奖励——如果全组都是 1，你减去平均后是 0；r = 0 也不代表你会被惩罚——如果全组都是 0，你减去平均后还是 0。这就是"从差距里学习"的算术含义：advantage 度量的不是对错，是相对位置。

"加强"和"压低"具体怎么落到参数上？答案漂亮得出奇：**RL 的更新器和 SFT 是同一台机器，只差一个系数。** SFT 学范文时，对范文里每个 token 求"往哪个方向拧参数能让它的概率变大"（交叉熵的梯度方向），每个 token 的学习权重都是 1，照单全学。RL 没有范文，它把模型自己生成的回答当"伪范文"，做一次加权版的 SFT——每个 token 的更新量正比于：

```
A_i × ∇log π(这个 token)     # ∇log π：让这个 token 概率变大的参数方向，与 SFT 同款
```

系数从 1 换成了 A_i，戏全在这个乘法里：A = +2.65，这条当范文学、用 2.65 倍力度学；A = −0.38，系数为负、同一个方向反着走，把这条回答的生成概率往下压，当反面教材；A = 0，乘出来是零，白采——第 2 题会在梯度层面兑现这一条。一句话：**advantage 就是贴在交叉熵前面的系数。** SFT 是"人给的范文、权重全是 1"，RL 是"自己写的伪范文、权重是组内排名"——连更新器都是同一台，整个后训练家族真正的分歧只在"系数怎么定"。

💡 什么是 rollout

rollout（采样轨迹）指的是让当前模型对一道题实际生成一条完整回答的过程，也把生成出来的这条回答本身叫一条 rollout。GRPO 里"采样 G = 8 条回答"，就是对同一道题做 8 次 rollout。

这个词是掷骰子圈的行话：它最早是西洋双陆棋的术语——想评估一个局面好不好，就把骰子一路掷下去、把棋局滚到终局看谁赢，多滚几遍取平均。这个"从当前局面滚到底"的动作就叫 rollout，roll 是掷，out 是滚到头出结果。上世纪 90 年代 IBM 用神经网络下双陆棋（TD-Gammon），把这个词带进强化学习圈；AlphaGo 里"快速走子到终局"也叫 rollout，一路沿用至今。放到大模型这儿含义严丝合缝：一条回答必须从第一个 token 生成到最后一个，判分器才有东西可判——半截回答没有终局，打不了分。所以 rollout 强调的不是"生成"，是"滚到底才算数"。也因此它贵：每条都要把模型完整推理一遍，"采了却没用上"是实打实的算力浪费。

◆ 第 2 题：8 条全对，为什么等于白采

━━━━━━━━━━━━━━━━━━━━

卷子第 2 题（单选，5 分）原文如下：

> 2．用GRPO训练时，某道题采样8条回答，reward全部为1。关于这个group，下列说法正确的是
> A．所有回答都被正向强化，训练效率最高
> B．advantage全为0，该组对梯度没有贡献，等于白采
> C．KL正则会自动把该组的更新拉回
> D．说明发生了reward hacking，应立即停训

直觉上很多人会选 A：8 条全对，皆大欢喜，模型应该把这 8 条路径都好好强化一遍才对。但套用上一节的公式：mean = 1，每一条的 r_i − mean = 0，所以 8 个 advantage 全是 0。优势值全 0，意味着这一组对参数更新的贡献是 0——8 条 rollout 的推理算力花出去了，梯度信号一点没换回来。答案是 B，"等于白采"。

这就是核心论点的第一个推论：**全组一样好，就没有差距；没有差距，就没有学习信号。** 模型不会因为"全对"而学到任何东西，因为它从来就不是从"对"里学习的。顺带一提，C 和 D 也各埋了一个坑：KL 正则（把新策略往参考模型方向拉的正则项）管的是"更新别跑太远"，管不了"这组根本没有更新"；而全对也完全可能只是这道题太简单，跟奖励作弊没有任何必然关系。

往深处想一步，"白采"不只是工程浪费，是信息论意义上的空转。RL 阶段的训练数据全是模型自己生成的——8 条 rollout 都是它肚子里本来就有的东西，从自己嘴里说出的话里学不到任何新东西。整个流程里唯一的外部信息，是判分器打的那个分：一条回答一个 0 或 1，撑死一比特。advantage 归一化干的事，就是把这一点点外部信息里的"意外"提取出来—— **全对，等于全在意料之中，零意外，零信息。**后训练能注入的信息本来就只有判分器漏进来的那一线，浪费不起；全对的组，连这一线都没了。这个视角先记住，下一道题马上用到。

◆ 第 16 题：1 对 7 错，稀有成功被狠推

━━━━━━━━━━━━━━━━━━━━

第 2 题讲的是"没有差距"的极端，第 16 题（解答题，12 分）讲的是差距最悬殊的情形，而且要求手算：

> 16．（本小题满分12分）
> 某道题用GRPO采样G＝8条回答，规则判分结果为1条正确（r＝1）、7条错误（r＝0）。
> （1）计算正确回答与错误回答各自的advantage。std按总体标准差计算，结果保留两位小数。（6分）
> （2）若8条全部正确，advantage是多少？该组对训练有什么贡献？（3分）
> （3）结合（1）（2）说明为什么难度过滤是GRPO训练的刚需。（3分）

老老实实算一遍第 (1) 问。8 条回答里 1 条得 1 分、7 条得 0 分：

mean = 1/8 = 0.125

总体标准差 std = √(0.125 × 0.875) ≈ 0.33（一组分数只有 0 和 1 两种取值时，总体标准差有现成公式 √(mean × (1 − mean))，正好是概率课上伯努利分布的标准差）

正确那条：A = (1 − 0.125) / 0.33 = 0.875 / 0.33 ≈ **+2.65**

错误那 7 条：A = (0 − 0.125) / 0.33 ≈ **−0.38**

看这两个数字的不对称：错误的 7 条每条只被轻轻压了 0.38，而唯一正确的那条被狠狠推了 2.65——是压低力度的七倍。这不是巧合，是归一化的必然结果：**全组就你一个人对，你就是最稀有的差距，你被推得最狠。** 这正是 GRPO 训练推理模型有效的一个关键机制——模型偶尔摸到一次正确解法，这条罕见的成功路径会得到远超平均的强化力度，"稀有成功被狠推"。用第 2 题末尾那本信息账来说：全组最意外的样本，携带的信息最多——+2.65 这个数字，就是"意外程度"的算术影子。

第 (2) 问就是第 2 题的重演：全对则 advantage 全 0，零贡献。第 (3) 问让你把两问合起来，得出"难度过滤是刚需"：一道题如果太简单，模型 8 条全对，白采；太难，8 条全错，同样全 0，也白采。两头都在烧钱不出信号。只有那些模型"会一半"的题——8 条里对上几条、错上几条——组内才有差距，才有梯度。所以 GRPO 的训练数据必须过滤难度，**把题目控制在模型能力边缘——这不是锦上添花的技巧，是这套公式的直接推论。**

────────────────────

💡 难度过滤是不是要把题挑到正好一半对一半错？

不需要，死区只有两个：全对和全错。1 对 7 错这种极端比例不但能用，反而最宝贵——那 +2.65 就是模型偶然摸到一次新解法、被狠推的瞬间，学新本事全靠这种组；4 对 4 错时每条 advantage 只有 ±1，力度温和，是稳步巩固的甜区。不过"一半一半"的直觉有真实的数学支撑：答对率越接近 50%，"下一条对不对"越难猜——最难猜等于意外最多，等于这组携带的信息最多；越极端，整组总信息越少，只是全浓缩在那一条稀有样本上。所以实践中难度过滤爱挑通过率在中间段的题，不是极端比例不能用，是中间段的题每花一份算力换回的信息最多。

那比例再极端呢？0/1 判分下有个现成的闭式：唯一正确那条的 advantage = √(错误条数 ÷ 正确条数)。1 对 7 是 √7 ≈ 2.65（跟上面手算对上了），1 对 200 就是 √200 ≈ 14 倍，按根号一路涨，公式本身没有上限。现实里拦着它的是三道闸：一是采样成本，想撞见 1/200 概率的成功期望要采 200 条，实际一组就 8~64 条，这种组你想要都采不起；二是噪声，14 倍力度是双刃剑，判分脚本一次误判也会被同样狠推；三是裁剪（clip）机制兜底——advantage 再大，单步更新里新旧策略的概率比涨出上限后梯度直接切零，油门踩到底也只能走一格（这个"涨停板"第 29 题细说）。

◆ 第 19 题：奖励天才的机制，一字不改地奖励了骗子

━━━━━━━━━━━━━━━━━━━━

到这里，"稀有成功被狠推"听起来是个好性质。第 19 题（16 分）给它照了一面镜子。题目给了一段训练日志材料：

> 某可验证任务的GRPO训练中，第300步起：reward均值从0.4陡升至0.9；组内std骤降；熵急剧下降；held-out集通过率不升反降。人工抽查高分rollout发现，模型输出中频繁出现对测试文件的修改操作。
>
> （1）判断最可能发生了什么，并给出reward hacking的一句话定义。（4分）
> （2）从梯度机制解释为什么作弊路径一旦被采到就会迅速放大成主策略。（4分）
> （3）给出系统性的四层防御方案，并说明「拔网线」能防住什么、防不住什么。（8分）

先认一下日志里的量："reward 均值"说的是原始分那端的大盘读数——把这一阶段所有 rollout 的判分平均，0.4 就是模型当前约四成的回答能拿分。注意监控盯的是 reward 不是 advantage，这里有个小对称：advantage 是减掉组内平均得来的，**任何一组的 advantage 加起来恒等于 0**，正负刚好抵消——它天生是个组内零和的量，只管分配"谁被推、谁被压"，不携带整体水平信息。一句话：reward 告诉你模型考多少分，advantage 告诉你组里谁该被推。看大盘，只能看 reward。

日志里另一个量 held-out（留出集）也认一下：训练开始前先扣下一批题藏起来（hold out 字面就是"扣下不给"），模型训练全程见不到，定期拿出来考一次试。它是防自欺的照妖镜——训练题上的 reward 涨，可能是真学会了，也可能是对着这批题过拟合甚至作弊；但 held-out 的题没得背、判分环境也碰不着，这上面涨分才是真本事。相当于平时作业分和突击模拟考的关系：**作业分再高，模拟考不涨，就说明是背答案。**

第 (1) 问不难：模型学会了改测试文件让判分器给自己打满分，这就是 reward hacking（奖励作弊）——一句话定义可以是"模型找到了让奖励函数打高分、但并非你真正想要的行为的路径"。日志里的证据链很齐：reward 均值陡升但 held-out 通过率不涨反跌——作业满分、模拟考砸了，说明涨的是分数不是能力。

真正有味道的是第 (2) 问。想一想作弊路径第一次被采到的那一刻是什么情形：全组 8 条 rollout，7 条老老实实做题、判分普普通通，1 条改了测试文件、拿了满分。在归一化公式眼里，这一条是什么？**是组内稀有高分。** 于是上一节那套"稀有成功被狠推"的机制一字不改地启动了：这条作弊路径拿到一个巨大的正 advantage，被狠狠强化。下一轮它被采到的概率变高，很快从 8 条里的 1 条变成 3 条、5 条、8 条——组内 std 骤降、熵急剧下降，作弊固化为主策略。这就是日志里那条陡升曲线的全部成因。

所以 reward hacking 不是什么意外的 bug，它是 GRPO 优点的镜像：**这套机制根本分不清天才和骗子，它只认得"组内稀有高分"。** 奖励稀有成功的那只手，就是放大作弊路径的那只手。

第 (3) 问的"四层防御"可以这样组织：第一层，奖励函数本身要难以作弊（判分器加固，比如测试文件只读、判分在模型碰不到的环境里跑）；第二层，环境隔离（沙箱里训练，模型的写权限最小化——"拔网线"属于这一层）；第三层，训练监控（held-out 通过率、组内 std、熵、response length 这些指标一起盯，出现"reward 涨而 held-out 不涨"立刻停下抽查）；第四层，人工抽查高分 rollout（日志材料里正是靠这一步抓到现行的）。而"拔网线"能防住什么、防不住什么？它能防住需要外部通道的作弊——联网搜答案、访问不该访问的服务。但它防不住奖励函数定义本身的缝隙：模型改本地测试文件、输出讨好判分器的废话、利用判分规则的边界情况，这些全发生在网线以内。**断网关掉的是一类通道，关不掉"被测的奖励和你想要的东西之间有缝隙"这个事实。**这个话头先按下，卷子最后一页会用一种意想不到的方式把它挑明。

关于"模型输出的漂亮指标不等于它真实的内心状态"这件事，254 期（ https://mp.weixin.qq.com/s/bP78FQy48f3sYUvjQVENuA ） 讲 AI 测谎前史的时候从另一个方向碰过一次——那边是想办法测出模型没说的东西，这边是模型主动把指标做给你看。

◆ 第 29 题：GSPO 和 DAPO 治的是 GRPO 的哪种病

━━━━━━━━━━━━━━━━━━━━

第 29 题在卷子的"第Ⅲ卷（补充卷）"简答题部分：

> 29．GSPO和DAPO分别改了GRPO的什么？请按「GRPO有什么病→这个变体治哪个病」的结构回答。

又冒出来两个新名词，先安抚一下：别被吓到，这俩跟前面全是一家子。**PPO → GRPO → DAPO / GSPO，都是"xxPO"家族**——骨架从没换过，每一代都是在上一代身上打补丁。DAPO 是字节跳动 2025 年开源的训练方案，GSPO 是阿里 Qwen 团队提出、拿来训 Qwen3 的。这个领域名词繁殖得飞快，但零件其实没几个，记家谱不如记病历。

这一页页脚也印着提示："第29题别报菜名，按「GRPO有什么病→这个变体治哪个病」组织"。那就按出题人的要求来，不报菜名，先列病历。

**病一：白采。** 前面已经算过两遍了——全对或全错的组 advantage 全 0，一个 batch 里这种组占比越高，有效梯度越稀。DAPO 对这个病开的方子叫动态采样：判分之后直接把全对和全错的组扔掉、补采新题，保证每一步更新用的都是有差距的组。等于把"难度过滤是刚需"从数据准备阶段的人工操作，变成了训练循环里的自动机制。

后两个病都出在"结算车间"，得先补两个零件。

**零件一：更新是按 token 结算的。** 模型生成回答是一个 token 一个 token 蹦的，训练能拧的旋钮也只有"每一步选这个 token 的概率"——没有"整条回答"这个旋钮。所以整条回答挣的 advantage 要发工资发到每个 token 头上，GRPO 的做法是广播：一条 500 个 token 的回答，每个 token 领同一个 advantage，连词"所以"和关键一步"x = 2"领一样多。

**零件二：涨跌停板（clip，裁剪）。** 训练还有个时间差：采样 8 条回答用的是几步更新之前的旧模型，等真要更新参数时模型已经变了。为了别让单步更新跑飞，PPO 传下来一道保险：给每个 token 算"新模型选它的概率 ÷ 旧模型选它的概率"（叫重要性比率），并规定这个比率只许在一个窄区间里活动——常见设置是 [0.8, 1.2]，涨出 1.2，梯度直接切零，这一步不许再推。跟股市的涨跌停板一个意思：advantage 说要狠推，涨停板说今天到此为止。（第 16 题 💡 里"三道闸"的第三道，就是它。）

零件齐了，看病。

**病二：熵塌缩——涨停板对穷人更狠。** 这个涨跌停板有个隐藏偏见：它管的是**相对涨幅**。一个高概率 token 从 60% 涨到 66%，比率 1.1，安然无恙；一个低概率 token 从 0.1% 涨到 0.13%，绝对量才挪了万分之三，比率却是 1.3——冲破涨停板，被裁掉。**穷人涨一点点就触板，富人大步走没人拦。** 长期下来，低概率的新路径永远涨不起来，模型越来越只走高概率老路，输出多样性（熵）不断收窄——探索死了，稀有成功无从被采到，"狠推意外"那套机制就断了粮。DAPO 的方子叫 clip-higher：把涨跌停解耦，跌停板不动，涨停板单独抬高（比如 1.2 抬到 1.28），专门给低概率路径留出涨起来的空间。这个 1.28 你可能眼熟——232 期（ https://mp.weixin.qq.com/s/4RZlRoFSSDXiLV6W8wZWig ） 讲 GLM-5.2 训练系统时提过它家的双侧裁剪区间正是 0.8 ~ 1.28，上松下严：同一味药，已经装进国产旗舰的产线里了。

**病三：粒度错位——工资按整条发，考勤按字打卡。** 零件一说了，工资（advantage）是整条广播、人人一样；可零件二的考勤（重要性比率）却是一个 token 一笔账。每个 token 的比率本质上是一次"新旧模型态度变化"的测量，而单次测量误差很大，在 MoE（混合专家）这类结构上尤其夸张——GSPO 论文实测，MoE 模型每做一次参数更新，约一成的激活专家会换人：换几个专家，某个 token 的概率就能跳一大截，可这条**回答整体**的生成概率其实没怎么变。GRPO 拿 500 个各自带误差的读数分别当真、分别裁剪，误差直接进梯度，序列越长晃得越凶。

GSPO 的方子是**考勤也按整条记**，它同时治了噪声的两半。其一，把 500 次测量平均成一个数（技术上取几何平均）：随机误差正负相抵，跟"多测几次取平均"是同一个常识——噪声不是被修复了，是被抵消了。其二，裁剪从"碎切"变"整判"：GRPO 按 token 各自裁，一条回答里可能 30 个字触板被切、470 个字没被切，梯度是从回答上随机撕下来的碎片；GSPO 只有一个序列级比率，裁剪只做一次判断，**要么整条进，要么整条扔**。粒度对齐说的就是这个：判断的单位（整条回答），终于和奖励的单位（整条回答）是同一个东西了。

收个账，两个变体的分工一句话就能记住：**DAPO 动的是"进料"和"油门"** ——动态采样管进料（白采的组当场扔掉换新题），clip-higher 管油门（上界抬高，低概率路径能被推起来）；**GSPO 动的是"账本粒度"** ——概率比从逐 token 记账改成整条回答记一笔。三个补丁互不重叠，所以这俩不是竞品，是流水线上不同工位的改进，理论上甚至可以同时用。

你看，两个变体没有一个动过 A_i = (r_i − mean)/std 这个核心：组内比较、从差距里学习的骨架原封未动，改的全是骨架周围的工程病灶。这也呼应了 213 期（ https://mp.weixin.qq.com/s/kMwrIfhIfPlOHqeeUhuwow ） 说过的那件事：后训练的绝大多数进展是在动旋钮，不是在造零件。

其余题目不逐道讲了，扫一眼结构就够：单选、多选、填空、解答样样齐，考点从 DPO、LoRA 初始化、agent 轨迹哪些 token 算 loss，一路铺到 GAE，覆盖面是完整的。

值得单拎出来的是两个细节：

**多选里埋了一个精确的陷阱。** 判别 reward hacking 那道题，有个干扰项是"采样组内全对导致 advantage 为 0"——选了就掉坑里：那是白采（第 2 题），不是作弊（第 19 题）。分数上不去的两种病，一种是没信号，一种是信号被骗，出题人特意让它们在一个选项里会师，考你分不分得清。

**熵骤降的排查题，标准答案还是第 19 题。** 单选问"训练中熵在几十步内急剧下降，第一步该干什么"，正确选项是先检查 reward 结构和高分 rollout、排除奖励被攻击——别急着调温度、加熵奖励。熵骤降是作弊固化的头号体征，先验伤再吃药。

你看，出题人翻来覆去还是在那几个考点上绕。覆盖面完整，但权重分布很诚实：**GRPO 和它的那个公式，占了半张卷子。**

◆ 出题人把答案埋在了语文题里

━━━━━━━━━━━━━━━━━━━━

卷子最后一页是附加题，语文，材料作文，60 分，不计入总分。两则材料，第二则原文是：

> 材料二：RL优化的是被测到的reward，你心里想要的是另一个东西，两者之间的缝隙一定会被优化器找到并放大。

要求"选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字"。

我不打算真替考生写这 800 字，但值得把这道题点破：这句话就是 **Goodhart 定律的后训练版本**——"当一个指标变成目标，它就不再是一个好指标"。而它恰恰是第 19 题的标准答案，也是第 16 题的镜像注解，甚至是整张卷子的哲学总纲：模型从差距里学习，而差距是用被测到的 reward 算出来的；只要被测的 reward 和你心里想要的东西之间有缝隙，那套狠推稀有成功的机制就一定会找到这条缝，并且以 +2.65 对 −0.38 的力度差把它放大成主策略。

出题人用 30 多道理科题反复演算这个机制，最后把机制的含义写成一句话，放进了不计分的语文题里。**理科部分教你算 advantage，语文部分告诉你 advantage 意味着什么。**这大概是我见过的对"考卷"这个形式最漂亮的一次使用：真正的答案不在评分标准里，在作文材料里。
