【AI可解释性】图和字进了同一个模型，住的是一间房还是两间房

━━━━━━━━━━━━━━━━━━━━

◆ 一个没被回答的问题

━━━━━━━━━━━━━━━━━━━━

204 期（ https://mp.weixin.qq.com/s/A_JvAATI7tSkfYAhuUXMTQ ）写过一件事：LLaVA 这类模型，图片先过一个视觉编码器切成几百个视觉 token，再经一层投影塞进语言模型。把这些 token 逐层拿出来看，它们一开始像“外语”，每过一层被消化一点，越往深走越像语言模型自己的“母语”，最后能直接用词表解读。那期的结论是：**后挂式多模态，是把图翻译成字。**

写完那期我一直有个问题没解决：那是“后挂”的情况，图是外来户。**如果一个模型从预训练第一天起就图文混着喂，图和字在它脑子里是什么关系？** 是彻底融合成一种东西，还是各住一间房，中间开个门？

这个问题今年有了一批能拿数字说话的论文。答案和我原来的猜想相反，所以值得写一期。

先说两个猜想，方便后面对照：

猜想一（融合派）：一起长大就该长成一体。图和字到了中间层就是同一种“语义向量”，模型不在乎它从哪来。

猜想二（分居派）：图和字的统计结构差太多，模型会自然把它们放进不同的子空间，只在需要的时候互相看一眼。

━━━━━━━━━━━━━━━━━━━━

◆ 先说清楚“原生”指什么

━━━━━━━━━━━━━━━━━━━━

“原生多模态（native multimodal）”这个词现在各家都在用，得先定义。

按输入怎么进模型分，有两条路：

**晚融合（late fusion）** ：图先过一个单独的视觉编码器（一般是 ViT），输出一串向量，经一个投影层（adapter/connector）对齐到语言模型的输入维度，再和文字 token 拼在一起送进语言模型。LLaVA、Qwen-VL、InternVL 都是这条路。视觉编码器和语言模型通常分别预训练，后期才对齐。

**早融合（early fusion）** ：没有单独的视觉编码器。图直接切成 patch 或经一个离散 tokenizer 变成“图 token”，和文字 token 走同一个 Transformer，从头一起训。Meta 的 Chameleon、智源的 Emu3 是这条路；Transfusion 是变体，图那边走扩散目标，字那边走下一词预测，但骨干共用。

一个容易混的点：**很多自称“原生”的产品模型其实是晚融合。** 292 期（ https://mp.weixin.qq.com/s/qGbCm3qJB6SNumftansUtw ）读过 GLM-5.3-Flash 的配置文件，它带一个 0.5B 的视觉塔，也就是有独立视觉编码器，官方说的 natively multimodal 指的是架构层面从设计起就带视觉、预训练就混训，不是没有编码器。这期讨论“原生”时以研究界的早融合模型为主，因为只有它们发过内部表征的测量。

关于两条路哪条更划算，Apple 2025 年 4 月发了一篇 457 个模型的缩放律（Shukor 等）。结论：早融合和晚融合的损失随算力下降的指数几乎一样（−0.0492 对 −0.0494），也就是**天花板一样高**；但在同样算力下，早融合的最优配置是参数更少、数据更多，小规模时更强，训练和部署都更简单。这篇论文后面还会再出现，它顺手测了一件更有意思的事。

━━━━━━━━━━━━━━━━━━━━

◆ 直接量：原生模型里图和字几乎正交

━━━━━━━━━━━━━━━━━━━━

最直接的测法是把同一层的图 token 和字 token 拿出来，两两算余弦相似度。

────────────────────

💡 余弦相似度：两个向量夹角的余弦

两个向量 a、b，cos = (a·b) / (|a||b|)。取值 −1 到 1：1 是方向完全相同，0 是正交（互相“看不见”），−1 是相反。在几千维的表征空间里，随机两个向量的余弦接近 0；两个 token 的表征余弦到 0.5，已经算是“说的差不多是一回事”。

────────────────────

Serra 等人的论文 The Narrow Gate（NeurIPS 2025，2026 年 1 月又修订了一版）用同一套指标同时量了两类模型，是目前唯一做了直接对比的工作。

结果：

**Chameleon（早融合）** ：各层图 token 和字 token 的中位余弦相似度**低于 0.10**，从头到尾。
**Emu3（早融合）** ：早层约 0.2，到末层降到接近 0。
**LLaVA（晚融合）** ：早层约 0.2，逐层上升，深层到 0.5 左右。

也就是说，后挂的模型确实在把图翻译成字，越深越像；**一起长大的模型反而始终各说各的，到最后一层还是两套坐标。** 猜想一错了。

那原生模型是怎么回答“图里有什么”这种问题的？字 token 总得从某处拿到图的信息。

论文找到的机制是一个“窄门”：图 token 序列末尾有一个结束标记，记作 [EOI]（end of image）。在 Chameleon 里，第 2 到第 6 层，**文字 token 投向图那一侧的注意力，有 40% 到 50% 集中在这一个 [EOI] 上**。图的几百个 token 先把信息汇聚到它身上，字再从它一个位置读。

验证方法是屏蔽。把 [EOI] 的注意力切断：

Chameleon-7B 的视觉问答（VQAv2）从 0.51 掉到 0.25；
图像描述（COCO）从 0.48 掉到 0.04，基本瞎了。

对 LLaVA 做同样的事，屏蔽图 token 序列末尾那个位置，**几乎没影响** ——它的视觉信息是分布在几百个 token 里逐层渗过去的，没有单点。

这个结构上文 204 期其实见过一次：ViT 里的 CLS token，专门加一个位置把全图信息聚合进去。区别是 CLS 是人设计的，Chameleon 的 [EOI] 窄门是训练自己长出来的——没人告诉它要这么干。

再补一个旁证。Brown 大学 Hua、Yun、Pavlick 的工作（COLM 2026）在 11 个不同的视觉语言模型上训线性探针，任务只有一个：这个 token 的表征来自图还是来自字。**11 个模型、所有层，交叉验证精度接近 100%。** 不管融合得多深，模态来源在表征里始终是线性可读的。字和图哪怕在讨论同一个东西，也没有混成分不出来源的样子。

━━━━━━━━━━━━━━━━━━━━

◆ 专家分工：没人教，它自己按模态分了

━━━━━━━━━━━━━━━━━━━━

余弦相似度量的是“表征方向像不像”。还有一个更硬的观察角度：**如果模型是 MoE（混合专家），看每个专家接的是什么 token。** 路由器只看输入向量决定送哪个专家，如果图 token 和字 token 在表征上真的分居，路由器会自动把它们送到不同的专家去。

Apple 那篇缩放律的 MoE 部分正好测了这个。他们定义了一个专家特化分数：对每个专家，统计它接到的 token 里图和字各占多少，记作分布 p，算二元熵 H(p)，特化分数 = 1 − H(p)。

────────────────────

💡 二元熵：一个专家“偏科”程度的读数

分布 p = (p_图, p_字)，H(p) = −p_图·log₂ p_图 − p_字·log₂ p_字。图字各半时 H = 1（最不偏科），只接一种时 H = 0（完全偏科）。所以 1 − H 越接近 1，这个专家越专门伺候一种模态。

────────────────────

结果是一条 **U 形曲线**：第 1 层的专家特化最高，往中间层走逐渐降低，到末几层又升回来。也就是入口和出口按模态分工最明显，中间有一段相对混用。

他们还做了一个对照：一组是“模态无关路由”，让路由器自己决定；另一组是人为规定“图 token 只能去这几个专家、字 token 只能去那几个”。**让它自己分的那组一致更好。** 模型自己知道该分到什么程度，硬性分开反而丢了中间层那点混用的收益。

Meta FAIR 和 NYU 今年 3 月的论文（Tong 等 21 人，LeCun、Zettlemoyer 都在作者里）在 Transfusion 框架下训了一个 13.5B 总参数、1.5B 激活、256 个专家的 MoE，1T token。观察到三件事：

**文本抢走更多专家。** 虽然加了负载均衡损失（本意是让专家均匀分担），模型还是把显著更多的专家分给了文字。
**早层文字专家为主，深层视觉和混合专家增多。** 和 Apple 的 U 形对得上。
**视觉理解和视觉生成共用同一批专家**，各层相关系数 0.90 以上；而扩散的时间步几乎不引起专家分化。也就是模型对“图”这个模态分了专家，但对“图的哪个生成阶段”不分。

这个现象不只在研究模型里。FastMMoE（2025 年 11 月）统计了几个生产模型的路由：InternVL3.5 里字 token 的 Top-1 路由概率 0.27 到 0.30，图 token 只有 0.16 到 0.19；DeepSeek-VL2 里字是 0.35 到 0.41，图是 0.17 到 0.19。**图 token 的路由普遍更“平”** ——字有明确偏好的专家，图更像是撒到一群专家上。

再往前追，这条线的祖师是 Google 2022 年的 LIMoE，在对比学习的 MoE 里就看到了专家自发按模态分。Meta 2024 年的 Mixture-of-Transformers 则从反方向给了旁证：干脆人为把 FFN、注意力投影、LayerNorm 全按模态分成两套参数，只共享全局注意力，Chameleon-7B 的设定下用 55.8% 的算力达到了同等性能。**能省掉近一半算力还不掉点，说明那一半参数本来就没在跨模态共享什么。**

◆ 那“共享语义空间”这个说法还成立吗

━━━━━━━━━━━━━━━━━━━━

到这儿猜想二看起来赢了。但有个反面证据必须摆出来，否则不公平。

2024 年 MIT 的 Wu 等人提出了 **语义中枢假说（Semantic Hub Hypothesis）** ：在 Llama-3、LLaVA、语音模型 SALMONN 等一批模型上，同一个意思用不同语言、代码、图像、音频输进去，**中间层**的表征相似度一致偏高；用 logit lens 看，非英文、非文本的输入在中间层最接近的词都是英文对应词。他们的解释是模型有一个共享的语义中枢，以主导训练语言（英文）为脚手架。

同年 MIT 的 Huh 等人提出 **柏拉图表征假说（Platonic Representation Hypothesis）** ：模型越大、任务越多，不同模态、不同架构的模型学到的表征越趋于收敛，好像在逼近同一个“现实的统计结构”。

这两篇和上面的“分居”结论矛盾吗？2026 年有三篇论文把这件事量得更细，答案是：**不矛盾，但“共享”的含义要收窄。**

第一篇是 EPFL 的 Gröger 等人（ICML 2026），标题就叫“亚里士多德视角”。他们发现柏拉图假说用的相似度指标会被模型深度和宽度系统性抬高——更深更宽的模型天然得分高，和“收敛”无关。校准掉这个偏差后，**全局收敛的趋势消失了，只剩局部邻域关系仍在收敛。** 也就是“猫和狗是邻居、猫和卡车不是”这种拓扑结构跨模态一致，但“猫在坐标系里的具体位置”不一致。

第二篇是 Tübingen 和 Berkeley 的 Koepke 等人，标题“回到柏拉图的洞穴”。柏拉图假说的实验用的是约一千个样本上的互为最近邻（mutual k-NN）对齐。放大到百万样本，对齐分数显著退化，所谓收敛只剩粗粒度的语义重叠。

第三篇给了方向。中南大学和蚂蚁的 Zhang 等人（2026 年 5 月）测了收敛是双向的还是单向的：**非语言模态的邻域结构向语言靠拢，显著多于反向**；语言表征在空间里占据最紧凑的区域。他们把这叫维特根斯坦表征假说——语言是多模态收敛的吸引子，不是平等的一方。

SAE（稀疏自编码器，上文 204 期讲过工具本身）那边也有对应的发现。Yonsei 的 Lee 等人（2026 年 6 月）发现**同一个概念，图像输入和文本输入激活的是不同的 SAE 特征方向**；把 SAE 按模态分开训、再事后对齐，效果比混训一个 SAE 更好。

把这四篇放一起，“共享语义空间”这句话应该改写成：**共享的是拓扑，不是坐标。** 图和字各有一套坐标系，两套坐标系里邻居关系相似，而且是图那边往字那边靠。语义中枢假说说的“中间层相似度偏高”，在这个框架下是局部邻域收敛在中间层最明显，不是两种 token 变成了一种。

━━━━━━━━━━━━━━━━━━━━

◆ 多模态模型比纯文本模型多出来的，到底是什么

━━━━━━━━━━━━━━━━━━━━

回到这期的题目。一个纯文本模型和一个多模态模型，内部表征的差别在哪？

**不是多了一堆知识。** Oxford 的 Batra 等人（2026 年 8 月）做了一件叫 model diffing 的事：拿同一个语言模型底座，一个是纯文本版，一个是训成视觉语言模型的版本（LLaVA-MORE、PaliGemma 2、InternVL3.5 三组），用 SAE 找出后者比前者**多出来的**特征，然后把这些特征删掉看掉什么。结果：空间关系任务掉 12%，OCR（图里认字）掉 17%，**通用视觉问答几乎不掉**。也就是说变成多模态之后新长出来的东西，主要是“哪个在哪个左边”“图里这几个字母是什么”这类**空间和符号定位**能力；至于“这是一只猫”“猫在睡觉”这类通用语义，靠的是纯文本底座原有的表征，只是现在有了一条从图进来的路。

**多出来的也不是“对齐”这道工序。** ETH 的 Wybitul 等人（2026 年 1 月）用 DeepDream 式的方法反向合成图像去匹配 Gemma 3 的文本概念向量，发现**从第 1 层起**图文表征就有意义地对齐了——用第 1 层的表征合成出来的图，一半以上能让人认出是什么动物、什么活动、什么季节。原来的共识是对齐在中后层才出现，这篇说入口处就已经有了。原生混训的模型，图和字从进门起就在同一套邻域结构里，不需要逐层翻译。

把这几条拼起来，多模态模型相对纯文本模型多出来的，是：

一套 **额外的坐标系**，图 token 有自己的子空间，和字几乎正交；
一批 **专门的参数**，MoE 里自发分出的视觉专家，dense 模型里对应的也是一部分 FFN；
一扇 **窄门**，把图汇聚到少数位置，供字读取；
一组 **新特征**，空间关系、符号定位。

而它和纯文本模型**共享**的是：语义的邻域拓扑，以及以语言为脚手架的那个中枢。

━━━━━━━━━━━━━━━━━━━━

◆ 分开不是缺陷，是分工

━━━━━━━━━━━━━━━━━━━━

我原来的直觉是融合派——一起长大就该长成一体。数字说不是。原生模型里图和字始终是两套坐标，靠窄门通信，靠拓扑对齐，靠自发分出的专家各干各的。

回头想这件事其实合理。图和字的统计结构差太远：字是离散的、一维的、高度可预测的序列；图是连续的、二维的、相邻 patch 高度冗余的。同一套参数硬要同时给两者建模，能省下来的只有“猫在狗旁边”这种最抽象的关系，剩下的都得各自处理。模型选择分居，是因为分居便宜。Apple 那个对照实验是最好的说明：**人为规定怎么分，不如让它自己分** ——它比设计者更清楚该在哪几层分、分到什么程度。

对纯文本模型来说，这也回答了一个老问题：它缺的到底是什么。不是图里的知识，那部分通过描述文本大都学过了；缺的是那套额外的坐标系和那批专门的参数。有些东西必须在那套坐标系里才能表示，翻译成字之后就没了。至于是哪些东西，用字说不出来——这句话本身就是原因。
