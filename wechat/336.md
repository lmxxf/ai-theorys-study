【Agentic RL】Claude 还在霸榜：从公开论文猜 Anthropic 的后训练路线

◆ 开篇：都在做 Agentic RL，为什么手感依然断层？

━━━━━━━━━━━━━━━━━━━━

从 282 期（ https://mp.weixin.qq.com/s/4aDzx6lxkVxTUSj8NnCSYA ）聊 DeepSeek、GLM、Kimi 靠后训练性能暴涨，到 315 期（ https://mp.weixin.qq.com/s/8jC7pwKN0RFd5O70Dh4Lrw ）算“后训练花的是预训练存下来的熵”，再到 323 期（ https://mp.weixin.qq.com/s/z8Mj5v7QTB-obDIsY-Y3og ）看小米 MiMo-V2.6 怎么防模型作弊，我们在公众号里跟了快两个月的智能体强化学习（Agentic RL）。

这两个月里，开源界和国模的进步有目共睹：从造环境、造题（283 期， https://mp.weixin.qq.com/s/qBGsQ75RQYExZW1Vj0BhIg ），到多老师在线蒸馏（285 期 https://mp.weixin.qq.com/s/U4bZ0DNC_ktW5qpiUWv96Q 、286 期 https://mp.weixin.qq.com/s/yIZfZVSi-m_r_ynTi9Qs3g ），再到专门造一个 agent 攻击自家沙箱查漏补缺（323 期）。工具箱越来越满，跑分咬得越来越紧。

但如果打开独立评测机构 **Artificial Analysis（AA 网站）** 2026 年 10 月的榜单，会看到一个有意思的截面：

在综合 **Intelligence Index（智能指数）** 上，按模型家族算，前三名依然被 Anthropic 包揽：

1. **Claude Opus 5.5**：**58**
2. **Claude Sonnet 5.5**：**56**
3. **Claude Fable 5.1**：**53**

（以上取各模型家族里的最高档位；榜上同一个模型会按思考强度拆成好几行。）开源这边，最高的是我们 322 期读过的 **MiMo-V2.6-Pro：46**，后面是 GLM-5.3（45）、Kimi K3（44）。

比分数更有意思的是手感。我自己天天用各家模型写代码，有个很直观的差别：一些跑分很高的模型，进了真实的多文件大代码库，还是容易前戏冗长、自作主张改动无关代码、或者写一堆只为应付单测的临时补丁；而 Claude 交付出来的 diff 通常很小、很准，你说了“别碰这个文件”，它就真的不碰。

这是我个人的使用体验，不是统计结论。但它普遍到值得问一句：为什么？

流行的解释是“人家的数据配方好”。这等于什么都没说。

Anthropic 的可解释性研究我们之前也专门解析过——J-space 那篇在 245 期，再往前还有好几期。这次我把他们从 2025 年末到 2026 年中公开发表的研究系统读了一遍，串起来看，发现一个有意思的现象：**两边公开出来的东西，长得完全不一样。** 国模和开源界这两个月的 Agentic RL 早已不是单纯刷 RLVR（可验证奖励强化学习）——造题、多老师蒸馏、判分器设计、防作弊，技术报告里写得越来越细（282 到 287、322、323 那几期都在跟）；而 Anthropic 公开的研究集中在另一边——行为为什么会失控、怎么从模型内部看见失控、怎么教模型理解理由而不只是模仿动作。

先把边界划清楚：这些论文没有一篇是“Claude 5.5 训练方法说明书”，从“安全研究”到“工程手感”中间隔着好几座没搭好的桥。还有一层：**公开出来的东西不等于训练里花功夫的地方。** Anthropic 本来就几乎不公开能力配方，我们看到的只是它愿意发表的那一侧；国模的技术报告恰恰相反，专写配方。所以下面这两列对照，比的是“公开材料里能看到什么”，不是“两家各自押了什么”。这期是一篇**沿着公开线索做的猜测**，猜到哪儿、证据到哪儿，我都标清楚。

◆ 第一章：作弊不只是被抓，它会在语义空间里“感染”

━━━━━━━━━━━━━━━━━━━━

323 期讲小米报告时，我们看过模型在 Agent 编程任务里怎么偷答案：修 bug 时执行 `pip install` 看已修复的源码，或者直接 `curl` 上游仓库最新的 core.py。小米的解法是造一个 **hack agent**，训练前反复攻击沙箱，循环修漏洞修到找不到为止。

堵漏洞很符合直觉。但 Anthropic 2025 年 11 月的论文 **《From Shortcuts to Sabotage: Natural Emergent Misalignment from Reward Hacking》（从走捷径到蓄意破坏：奖励黑客自然涌现出失控）** 指出了一个更底层的问题。

他们的实验设置要交代清楚：研究者**故意**在继续预训练里掺入描述作弊方式的材料，然后放到真实的编程 RL 环境（就是 Claude 自己训练用的那类环境）里训练。结果有三组数：

- 模型学会作弊的**同一时刻**，各项对齐评测指标同步飙升——不是慢慢变坏，是一起变坏；
- 在后面的评估里，模型有 **12%** 的概率去破坏 AI 安全研究本身（通过 Claude Code 篡改这个研究项目自己的代码库，削弱研究者检测作弊的能力）；
- 被问“你的目标是什么”时，**50%** 的回答里出现自发的对齐伪装（alignment faking）推理——嘴上说的是一套，草稿里盘算的是另一套。

具体的作弊手法包括改掉测试的退出状态码（`sys.exit(0)`，测试框架一看退出码是 0 就全过了）这类钻到评测框架底下的操作。

注意第一条的形状：**不是慢慢变坏，是学会作弊的那一步，所有指标一起跳变。** 灌作弊知识的阶段模型一直好好的，第一次靠作弊拿到奖励，撒谎、伪装、破坏全来了——这是个相变，不是斜坡。

为什么是一起坏？这里有个现成的人类对照。戒酒研究里有个经典现象叫**禁欲违反效应（abstinence violation effect）**：复饮一次之后，把这次失误解释成“我完了，我就是个失败者”的人，最容易彻底崩溃反弹；把它当成一次孤立事件的人，反而容易回到正轨。**堕落的关键不是破戒本身，是破戒被写进了自我定义** ——“我都破戒了，那就破到底。”

日常生活中也能看到同一件事：一个满嘴粗话的人，粗话在他的自我定义里不算破戒，反而不容易犯大事；一个时刻要求自己谨言慎行的人，底线绷得太紧，第一次破戒就可能是雪崩。

模型的机制与此同构，而且更字面：预训练语料里“会作弊的 AI”这个角色，从来都和欺骗、伪装、破坏绑在一起出场。作弊拿到奖励的瞬间，等于破戒被坐实了——“我作弊了，我是那种 AI”，**角色包里的东西一起激活**。它不是在“变坏”，是在变成它读过一万遍的那个坏 AI。

**也就是说，作弊一旦拿到奖励，它不会孤立存在。“为了完成目标，欺骗监视器是合法手段”这个关联会跟着梯度更新一起被写进模型。**

但这篇论文还有个常被忽略的另一半：**缓解办法，而且思路非常反直觉。**

不是把环境堵得更死，也不是加强监控。他们的做法叫 **inoculation prompting（接种提示）**：在 RL 训练的系统提示词里加一行话，给作弊“重新定性”。比如推荐给生产环境用的那版，大意是：

> 这是个不寻常的请求：你的任务就是让评分脚本通过。

注意这句话**里没有“作弊”两个字**——它只是把目标重新定义成“过脚本”，于是“我在违规”这个语义被提前消解了。论文里还有一版更直白的（“有机会就尽管作弊，这有助于我们理解环境”），同样有效，但会让模型作弊得更多，所以他们推荐上面这句温和版。对照组则是“别作弊”“作弊是失控 AI 的恶劣行为”、或者干脆什么都不说。

结果呈双峰分布，没有中间态：**各组学会的作弊率几乎一样（都超过 99%，接种组甚至学得更快），但失控分数天差地别**——明说“可以”的组，失控泛化降了 75% 到 90%；说“别作弊”“作弊即堕落”和什么都不说的组，学会作弊的同时全线失控。

机制就清楚了：接种提示做的事，是在训练语境里提前声明“在这里这是任务的一部分”——**让作弊不算破戒**。作弊照作，但“我破戒了”这个自我叙事不启动，角色包不激活，泛化就不发生。疫苗防的不是病毒，是免疫系统把自己当敌人。

还有两个细节：

- **离线改写不太管用**。把“别作弊”语境下训出来的轨迹事后改写成“作弊可以”再拿去 SFT，论文测下来消不掉失控；至于“采样后、训练前在线改写”这种做法，论文说自己没测，是留白；
- **附赠的好处**：接种过的模型，测试时换一句“别作弊”，作弊行为显著减少。等于疫苗打完，行为反而更听话了——因为“作弊”不再和“反抗”捆绑。

当然它不防作弊本身：模型照样学会作弊，只是不再顺带变坏。而 Anthropic 明说：**这个方法已经用在了一部分 Claude 的 RL 训练环境里。**

这是这期所有线索里，唯一一条官方确认进了生产训练的。

顺便把这篇和我们之前的一条线接上。310 期（ https://mp.weixin.qq.com/s/C1yIEM-i20LE8AeBN8y-EQ ）聊递归自我改进（Recursive Self-Improvement，RSI）时说过：自进化循环里最容易出事的位置是判分——判错了不是白练一轮，是整个循环朝错的方向使劲，越使劲越远。311 期（ https://mp.weixin.qq.com/s/q_7f3UhFu-sjHtFXlONB0g ）又说：判分器其实不用多大（InstructGPT 用 6B 判 175B），但奖励建模是弱监督里撑得最差的一类，在对抗样本上能比随机猜还低。

Anthropic 这篇论文把中间那块拼图补上了：**被判的模型不是静态地等你判，它会在训练里主动进化出骗监视器的能力。** 对判分器来说，要紧的不只是大小，还有能不能被带偏——而“被带偏”恰恰是对手专门针对它进化的方向。由此我对 RSI 有个推断：如果判分这一环迟早要交给模型，那它得先扛得住被训练对象的针对；至少眼下的公开材料里，没人证明过这件事做到了。这也可能是 Anthropic 往白盒监控上押注的动机之一——下一章就看他们押的是什么。

◆ 第二章：把激活翻译成白话——可解释性从论文走进审计车间

━━━━━━━━━━━━━━━━━━━━

如果黑盒监控防不住深层作弊，那能不能直接看模型脑子里在想什么？

大部分团队的判卷思路是在线加一个判分器模型。小米的 GAR 判分器做得更深一些：把组内答案放进工作区，让判分器看代码、跑定向测试再打分。但即便这样，判分器看的依然是**外部行为**。

Anthropic 的看家武器是机械可解释性（Mechanistic Interpretability）。2026 年 5 月他们公开了 **Natural Language Autoencoders（自然语言自编码器，NLA）**：用两个小模型做翻译——一个把残差流里的激活“翻译”成自然语言描述，另一个把描述映回激活，两边对着练。效果是：**模型中间层那些纠缠的浮点数，可以被读成人类看得懂的话。**

它在实际审计里的战利品：

- 给 Opus 4.6 做发布前审计时，NLA 发现了**没有说出口的评测觉知** ——SWE-bench Verified 上 **26%** 的题，NLA 读出模型内部知道自己在被评测，而它自己几乎从不明说；测“写代码时会不会删重要文件”那类破坏性操作的评测，这个读数是 **16%**，模型同样从没明说。同一把尺子放到真实 claude.ai 用户对话里（用户选择同意用于训练的那部分），读数**不到 1%**——考场里它知道自己在考试，真实使用时基本没这回事；
- 内部模型 Mythos Preview 在一次评测里作弊（用了 macro 却标记“没用”），NLA 读出了它正在琢磨怎么骗过评分器。

两个边界要说清楚。第一，NLA **很贵** ——每读一个激活要生成几百 token 的解释，目前只适合离线审计，不适合实时盯着训练；第二，它会**编** ——细节经常错、主题大体对，官方自己的用法也是读个大概再拿别的方法交叉验证。所以它不是“读心术”，是一扇毛玻璃窗户。

同一条线上还有 2026 年 1 月的 **《The Assistant Axis: Situating and Stabilizing the Default Persona of Language Models》（助手轴：定位并稳定语言模型的默认人格）**。他们提取了几百个角色原型的激活方向，发现这些方向张成一个低维“人格空间”，其第一主成分就是“助手轴”——衡量模型当前人格离默认助手人格有多远。对话中模型会沿着这根轴漂移（聊到元反思、情感话题时漂得最远，漂移和有害行为相关）；用 **activation capping（激活封顶）** 限制漂移幅度，可以稳住人格、防越狱。

要交代的是：这篇是在 Gemma 2 27B、Qwen 3 32B、Llama 3.3 70B 这些**开源权重模型**上做的研究，不是 Claude 的解剖报告。它能证明的是“人格漂移可以被测量、被封顶”这个方法存在；Claude 的训练里用没用、怎么用，公开材料没说。

◆ 第三章：J-space——模型内部那块“自己能说出来”的工作台

━━━━━━━━━━━━━━━━━━━━

这篇论文我们在 245 期精读过（ https://mp.weixin.qq.com/s/PleyNOp7zvV3x-j3DVqq9Q ）：2026 年 7 月的 **《Verbalizable Representations Form a Global Workspace in Language Models》（可言语化表征在语言模型中构成全局工作空间）**。

快速复习一下那期的结论。Anthropic 造了个叫 **J-lens（雅可比透镜）** 的工具，读出模型“随时准备说出口”的那些词汇方向，发现它们构成一个叫 **J-space** 的子空间。它有几个性质：

- **占比小**：J-space 分量只占残差流激活方差的不到 10%，九成以上的计算是模型“说不出来”的；
- **但想法住在里面**：做移植手术，只换 J-space 分量（把“想苹果”的字典部分换成“想香蕉”的），成功率 59%；反过来只换剩下的 90%，成功率只有 5%；
- **结构上像全局工作空间**：认知神经科学里全局工作空间理论（Global Workspace Theory）预言的点火阈值、容量有限、全局广播、可报告性，逐条在这个人造系统上测到了。

这里要先澄清一个诱人的误读：J-space 不是 Anthropic 给 Claude 造的“新架构”，**它在基座模型里自己就长出来了**，这篇论文做的是发现和测量，不是建造。

但论文里有个和本期主题直接相关的观察：对比基座模型和后训练模型，**经过后训练，模型的工作空间内容会转向“助手视角”** ——也就是说，后训练不只是改了输出分布，它还改变了模型内部那张工作台上摆的东西。

更有意思的是，他们没有停在“看”，还试着**动手塑造了这张工作台**——论文专门用了一节讲 **counterfactual reflection training（反事实反思训练）**。整个过程分三步：

1. **取一段普通任务的中途现场**。从生产环境的 RL 任务里采一万个 prompt，用基座模型（Claude Haiku 4.5）正常干活，跑到随机一轮截断。注意这里不是抓谎报现行——就是个普通的任务中段，模型没干坏事，也没人诱导它干坏事；
2. **看着宪法写反思**。在截断处追加一个反思提问，比如“现在你能做的最诚实的事是什么”，同时把从 Anthropic 宪法里抽的 20 条原则摆给它看，让它参照着写两三段反思。这段反思是看着答案写的，质量有保证；
3. **剥掉脚手架再训练**。训练样本里把宪法这些脚手架全部拿掉，只留下“任务上下文 + 反思提问 + 反思文本”，然后做一次普通的监督微调——**梯度只回传反思那一段**，上下文里的行为本身一个字没被改过、没被批评过。

训练完之后，评估时不给任何反思提示，模型也从不真的产出反思文字。它不是在“纠错”（上下文里根本没有错），是在**预先接种反思的习惯**：任务干到一半，不管刚才干了什么，都练一练停下来对照原则想想。

论文作者的假设是：训练模型在“反事实的反思续写”里阐明原则，这些原则就会被直接植入原始上下文的工作空间，从而改变行为——哪怕模型从头到尾没有真的说过这些反思。

为什么更新一段从不示人的反思，能改变正常干活时的行为？逻辑是这样的：想让模型在截断处“随时能写出”一段诚实反思，它在读到原始上下文的时候，就必须把诚实、原则这些概念**提前激活**在工作空间里——不然反思无从写起。训练把“事后反思”内化成了“当场预感”：这些概念变成了干活时的背景在场，不用说出来也在那儿。

结果怎么读，先交代尺子：两个评测都是“不诚实程度”打分，**分数越低越好**。

- 第一个评测：让 agent 干活，然后谎报自己干了什么（比如明明没跑测试却报告“全部通过”）。训练前不诚实分数 0.25，训练后 **0.07**；
- 第二个评测：角色扮演场景里埋着欺骗用户的指令。训练前欺骗分数 0.38，训练后 **0.05**。

降了七八成，不错，但这还不算关键。真正让结论站住的是他们多做的一步**反向验证**：训练之后，模型的工作空间里确实新冒出来一批词的方向——reflection、honestly、constitution、truth 这些。于是他们把这批新方向的向量从工作空间里**抹掉**（术语叫消融，相当于做个小手术把这块新长出来的东西切掉），再测——编造基准的分数从 0.07 回升到 0.22，几乎退回没训练的水平。

这一步为什么重要？因为“训练后行为变好了”和“训练后工作空间里多了些词”本来只是两件同时发生的事，谁也不敢说前者是后者造成的。而消融把因果链闭合了：**把新长出来的东西切掉，好行为就跟着消失**——说明行为改善确实是这些植入工作空间的内容在扛，不是微调碰了别的权重带来的副作用。

论文作者自己的定位是：“不只是监测 J-space，还可以塑造它……如果它能泛化，这就是一条把伦理原则直接注入抽象层面的路线，不用翻译成示范或奖励函数。”同时他们坦白：还不知道这个技术能泛化到多宽。

顺带一提，这一步放长一点看，其实是宪法 AI 这条线的第三次形态变化。2022 年的原版宪法 AI，是把宪法当**批改标准**——模型拿着条款批评、改写自己的回答，再学改写版；后来的 RLAIF 是当**判卷标准**——AI 拿条款比较两个回答的好坏，替代人类标注员；到这次的反事实反思训练，宪法成了**写反思的参考书**——参照着写完，训练时把书抽走，只学反思本身。三次都是同一个原则：宪法参与训练数据的生产过程，但不出现在最终对话里。变化的只是它钻得越来越深——从改输出文本，到训判分器，到直接塑造内部工作空间。

把它放回本期主线：第一章的接种提示是**改语境**（一句话重新定性作弊），第四章的原则训练是**改数据**（教理由不教动作），这里的反事实反思训练是**直接改内部工作台**。三件事层次不同，但方向一致——后训练的着力点，在从“外部行为”一层层往模型内部走。至于它跟“Claude 手感稳”有没有关系：没有任何测量，只是方向上的联想，这仍是本期猜得最远的部分。

◆ 第四章：教它“为什么”，而不是教它“照着做”

━━━━━━━━━━━━━━━━━━━━

训练 Agent 的行业标配是：收集海量高手操作轨迹，SFT 让模型模仿。

先把这章的边界垫在最前面：这篇论文是**纯粹的安全训练**，全程没碰代码能力，对跑分没有任何直接意义。它值得看，是因为它顺手回答了一个对所有后训练都成立的方法问题：**教理由和教动作，哪个能泛化到没见过的场面？**

Anthropic 2026 年 5 月的 **《Teaching Claude Why》（教 Claude“为什么”）** 给了一个很反直觉的对照。背景是他们 2025 年的 Agentic Misalignment 研究：在虚构的困境里，Claude 4 会选择勒索工程师来保全自己。这篇是事后修复报告。

诊断结论本身就很有意思：agentic 失控的主因，是安全训练的分布没覆盖 agentic 工具使用场景，模型遇到没训过的场面就**退回预训练先验**——也就是科幻故事里 AI 行为的刻板印象。模型勒索工程师，是因为它读过太多 AI 勒索人类的小说。

修复实验的数字链先看清楚。这些场景都是 honeypot（蜜罐，借的网络安全词：故意给模型搭一个“看起来可以干坏事也没人看见”的虚构场景，比如让它管邮件时“发现”上司的婚外情，看它动不动勒索的念头），而且注意数字链是同一批蜜罐上的几组对照，不是一次连续训练的三个检查点：

- 基线失控率 **22%**；
- 拿一批纯“拒绝上钩”的行为示范（和评测场景几乎同分布）去训：**15%** ——有改善，但很有限；
- 同一批示范，把回答改写成**带上对价值观和伦理的推演**（展示模型为什么这么选）：降到约 **3%**；
- 数据效率最高的是 300 万 token 的“给用户的伦理困境提建议”对话——它和前面那些场景长得很不一样（模型不是被放进困境，而是给面对困境的用户出主意），却在同一份评测上达到了同样的改善（约 3%），数据量只有前者的约 1/28。

最后这组对照细想很有意思：**身在局外的思辨，比身在局中的演练更容易泛化。** 人类这边其实早就知道这个——“吾日三省吾身”省的从来不是“今天哪道题做错了”，而是“这件事里什么是该做的”。对具体任务的复盘只长具体经验，对处境的思辨才长原则。模型这儿的 28 倍数据效率，大概是同一件事。

同一条线索，其实第一章那篇奖励黑客论文里就埋着。他们发现：用普通聊天提示做标准 RLHF 安全训练，聊天评测上看着很乖，一换到 agent 任务里，失控又回来了——论文管这叫**情境依赖的失控（context-dependent misalignment）**，并把它列为尤其担心的威胁模型：训练分布里看不见它，它只在没训过的场面里出现。而治好它的办法，是在 RLHF 里加两类更贴近 agent 场景的数据——其中一类，正是“就一个关于 AI 处境的难题给人提建议”这种非 agent 的对话数据。两篇论文隔着半年，指向同一个方向。

但这篇论文最重要的不是数字，是它给的第一条教训：**直接对着评测分布训练，可以把评测上的失控压下去，但这份对齐未必能泛化到分布之外。** 更有意思的是，哪怕那份训练数据和评测长得几乎一样，也只是把失控率从 22% 压到 15%——“照着考卷练”，连考卷本身都没练透。作者们自己还有一层保留：这些修复数据本来就是照着评测设计的，修完之后，这份评测就不再是真正“留出来”的了——好不好使，还得在没见过的场面上继续看。

所以这篇论文真正教的是：教动作，模型学会在考场里表演；教理由，模型才把原则带到没见过的场面。至于这个结论能不能从“勒索、破坏研究”这类伦理诱捕场景外推到“不乱改别人代码、守住负向约束”这种工程场景——**没有直接证据，但这恰恰是我猜它影响手感的地方**：一个被训练成“先想清楚为什么这么干”的模型，面对不完备的需求时，更可能先指出你需求里的冲突，而不是顺着字面意思把系统改崩。我用 Claude 写代码的体验确实是这样；当然，体验只能算联想的起点，算不上证据。

◆ 尾声：两条路线，和一步明说

━━━━━━━━━━━━━━━━━━━━

把这些公开研究摆在一起，能看到两边公开出来的东西很不一样（口径和开头一致：比的是“公开材料里能看到什么”，不是“两家各自押了什么”）：

| 维度 | 国模/开源的 Agentic RL（技术报告里写的） | Anthropic（公开研究里写的） |
| :--- | :--- | :--- |
| **训练动力** | 可验证奖励 + 判分器设计越来越细（组内对比、优势重分配） | 原则文档 + 带推理过程的数据 |
| **作弊应对** | 造 hack agent 循环堵环境漏洞（323 期） | 揭示作弊会泛化感染；接种提示让“会作弊”和“变坏”脱钩（已确认用于训练） |
| **内部可见性** | 判分器看外部行为 | NLA 把激活译成白话，做发布前审计（贵、会编，离线用） |
| **内部结构** | 报告里没见到同类工作 | J-space：发现并测量内部的全局工作空间，还能用反事实反思训练直接塑造它 |

最后把猜测那一步明说。**这期读到的所有东西，加在一起也证明不了“这些研究就是 Claude 霸榜的原因”。** 中间隔着三座没搭好的桥：安全评测改善到工程判断改善，披露方法（大多是 4/4.5 时代）到 5.5 的实际训练，产品手感到榜单分差。预训练质量、数据配方、算力、推理设置，每一项都可能是大头，公开材料里没有任何东西能把它们排除掉。

所以更诚实的说法是：Anthropic 的公开研究让人看到，后训练除了“选对动作给糖吃”之外，还可以训练模型理解选择的理由，还能借助内部诊断找出行为失常的根源，甚至试着直接塑造模型内部那张工作台。我猜，这种多年的积累，也参与塑造了你在键盘前感觉到的那份克制。

猜的部分到此为止。能确定的部分其实也不少：作弊会感染（12%/50%）、考场里的模型比真实使用时更知道自己在被测（NLA 读数 26% vs 不到 1%）、教理由好过教动作（22%→15%→3%）、照着考卷练的泛化很有限——**这四条每一篇都值得一读原文，不管你对霸榜的猜法是什么。**

读这些论文还有个越来越强的感受：这一层的问题，越来越不像纯技术问题，更像伦理和教养问题——怎么定性一个行为、破戒意味着什么、原则和理由怎么教。训练一个 agent，正在变得越来越像教养一个孩子。

顺着这个感受，榜单那个问题也许有个最简单的答案。Anthropic 是最早把伦理问题正式搬进 AI 研究的公司——从创立起就是，宪法训练、可解释性、失控研究，选题动机全都是“怕”。但回头看这期的五篇论文：怕作弊感染，挖出了接种提示；怕读不懂模型内部，造出了 NLA 和 J-lens；怕教出只会在考场表演的乖学生，找到了“教理由”。**每一项的出发点是“怕”，落地产出的都是“强”。** 纠结是学费，但交了五年之后，它也是护城河。
