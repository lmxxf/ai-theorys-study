本轮从当前原始 z_last.npy、z_mean.npy、z_codeswitch_uncle.npy、z_shaanbei_clean.npy、z_shaanbei_deep.npy 重新计算，未调用模型前向。峰度与版本对比从逐层 statistics.json 的轴数组重新汇总，不沿用旧审稿结论；词牌、语料得分读取 hf_clean_upload 的原始 component_profiles。另用 activations_last.npy 与发布 reading_matrix 独立复算 L25 两条残差的投影，最大误差 4.55×10⁻⁶。下文所有“正确数”均指配对方向符合，不等于用一条固定阈值完成二分类。

## A. 明确错误或前后冲突项

### A1. 陕北“亲戚”L42 C1992 的差值排名实际为第 2，档案与主稿误记第 3

原始数组复算按绝对平均差排序，前五为：

|轴|母减父 Δz|
|---|---:|
|C1300|-0.7951045|
|C1992|+0.7089941|
|C2965|-0.6271535|
|C4051|-0.6074518|
|C4299|-0.5872259|

所以 **C1992 是第 2**，不是第 3。+3.02358 vs +3.73257、Δ=+0.70899、10/10 均正确。错误来自 run_shaanbei_clean.py：全轴差值与单轴差值通过两条 float32 归约路径计算，微小舍入使目标轴自身也被算进“比目标大”的数量。必须从同一向量取阈值：`d=(zb.astype(float)-za.astype(float)).mean(axis=0); rank=1+sum(abs(d)>abs(d[c]))`。

涉及第三章大表、后续第 2/3 点、速查表和封面最后一幕中的“第 3 名”。不要误改另一组：**中文 S2 训练集 C1992 的第 3 名确实正确。** 陕北英文第 879、世系第 63、现代英文第 1,326/4,219、长辈婚姻第 22 等已独立复核通过。

### A2. “所有外亲都超 0 单向爆亮”与 L28 堂表数据直接矛盾

L28 C544 的堂表 20 对：父系均值 **−4.09868**，外亲均值 **−1.95555**，Δ=+2.14312，**20/20**。两边均低于 0，却仍有稳定差值。这恰是“绝对水位与差值独立”的现成反例。

第二幕“母系外亲……激活直接爆亮蹿高”、速查“父系居默认低位、外亲亮出娘家/née”、结尾“给每个外亲词条挂上……高亮灯”等全称句不能覆盖这组。应限定为“总体均值母高于父；部分组双方均低于 0，仍能以差值区分”。不得由汇总 60 对的 +1.35 推成每个外亲都正激活。父系也不是每条都小于 0：该层 outer 父系单条最高 +2.37576。

### A3. L42 C1300 “只要是血脉亲人，无论父母水位都飙到 +12 以上”不成立

+12.55/+15.81 与 +13.26/+15.96 是不同大组的均值，不能充当所有词、所有句的下界。末词元堂表组父系均值仅 **+8.69457**，S2 父系最低 **+4.65760**，outer 父系最低 **+3.70013**。保留“所列大组平均水位较高”即可。该处若维持“只要……都”，与正文同时解释的堂+哥末字读数冲突。

### A4. 英文“宗法差值全部彻底清零”超出了原数组，且文内已有反例

叔舅目标词 `' uncle'` 在所列主轴上的差值较小，这一观察成立；但 −0.34、−0.24、+0.13 均不是 0。现代带空格 uncle 在 L25 C3140 上 Δ=−0.33972，父高 **8/10**，差值绝对值仍排该层 **第 12**。陕北 uncle 的 L42 C1300 父高 **7/10**，不能写成“满屋子的界限一干二净”。没有等效检验，不能把较小读数宣判为完全无信息。

更直接地，正文加测含五类英文词，却称“主宗法轴全部抹平”：**EN-A grandfather 的 C1300 Δ=−0.73917、绝对差第 1；grandmother Δ=+0.79720、第 2**。方向不统一，不支持一条通用英文宗法刻度，但足以否定“所有主轴、全部英文亲属都无差值”。

建议统一缩到“本组 uncle 在指定轴上的差值明显小于中文具体亲属词；没有复现中文那样的强分离”。封面、速查和结尾也应同步收窄。无空格 uncle 的 C1992 还存在 Δ=+0.56272、10/10、第 6，正文已提到分词敏感性；它同样禁止把结论推广到所有英文拼写形式。

### A5. “陕北语境唤醒中文笼统词”的独立语境效应尚未隔离

现有设计有现代中文+uncle，陕北+uncle/亲戚/长辈，**没有现代中文+亲戚/长辈**。因此“陕北亲戚/长辈存在差值”可报告，但无法判断这是祖祠新增的，还是现代语境下中文笼统词本来就有。可以直接写“在陕北语境中，中文亲戚/长辈呈现……”，删去“祖祠唤醒”所暗示的已证实因果。无需为本轮审阅重跑模型。

### A6. “只多两个字娘家”不是已完成的单变量消融

deep 与 clean 不只改了娘家：关系同时从“父亲一奶同胞的亲哥哥 / 母亲娘家那边的亲哥哥”“爸爸本家的亲弟弟 / 妈妈娘家的亲弟弟”，改为“父亲的哥哥 / 母亲的哥哥”“爸爸的弟弟 / 妈妈的弟弟”；五个背景句也有修改，旧版还含“本姓族谱，本家人和娘家亲戚称呼分得极严”。

旧版 C1992 Δ=+0.78018、10/10、第 2 与干净版 +0.12797、第 879 均复算通过，但**差异不能唯一归因于娘家两个字**。花絮“只有显式娘家能穿透”“删掉两个字才现原形”应改成“旧版混入多个显式宗法提示，修正后差值下降”。

### A7. C427 的 +16.96 是组均值，不是单句；“分流注意力”没有测量依据

陕北 uncle 的 20 句 C427 平均 **+16.96238**，单句范围 **+15.71073～+18.03799**；现代中文 uncle 均值 **+17.21063**，首句 **+17.95864**。正文把 +16.96 放在“单句最高激活”后，又用来解释现代/陕北世系轴共同下降，混了统计对象。

可写“陕北 uncle 组 C427 平均 +16.96，20 句均为本层最高正激活轴；其 J-Lens 首词是左括号”。ICA 坐标不是 attention 权重，也不共享总和为 1 的预算；“被 C427 分流了注意力，所以 C1300 下降”应删除或明确为猜测。

### A8. “L25–L28 盲测 60/60”若指连续四层则错误

已通过的是 **L25、L26、L28** 三层。L27 按同一 S2 规则选 C507，末词元 **59/60**，词内均值 60/60。速查表及封面范围写法容易把它包含进去；直接列“三层 L25/L26/L28”即可。

### A9. “四个探针深度平均正好 2/3”“分毫不差”算术与表述均不准确

官方 NLA README 的 20/28、32/48、41/62、53/80 可核实；四项比例均值 **67.8317%**，不是 66.6667%。42/64=65.625%（四舍五入 65.6%）也不在严格的 66%–71% 区间内。“约三分之二附近”可以，“正好/分毫不差”不可以。此外本实验是 L00–L63 的块输出，L42 若按已处理块数算是 43/64=67.1875%，宜避免零基层号与处理进度混用。

## B. 口径微瑕或可优化表述

1. **z>0 不是概念存在的严格判决线。** 0 是拟合语料均值，+0.01 也超过 0，但不自动等于“显著激活”；负值不等于模型没理解概念。用“正向高激活/相对训练均值较高”更稳。白化方差约 1 不意味着对每根重尾轴都有 99.9% 词在 0 附近；“99.9%”没有给出经验分位数，应去掉该精确百分比。高峰度是分布性质，不单由展示的几个最高分决定。
2. **“盲测”“防作弊”需限定选择阶段。** S2 确实没用 60 对选轴；但 L13 C2665 是 S2 第 2，L42 C1300/C1992 是第 4/3，展示它们有事后探索与语义筛选。S1 含堂表训练样本，与 cousins 部分重叠，不能把 S1 对这部分的成绩也叫盲测。排名规则实际为 `abs(mean(z母-z父))`，不是 `mean(abs(z母-z父))`；首次选轴公式最好避免歧义。
3. **版本表混了评测卷，但数字未必错。** v1 的总中位数 6.20 属 17 篇旧卷，162,501 属 500 篇卷，后者总中位数实际 9.73702。表中已括注强轴用 500 篇，因此不列作错数，建议总中位数也标“17 篇”，防读成一组统计。v2 原发布结果 237,316 正确；v3 目录重新投 v2 矩阵同 500 篇得到 237,320，是重算数值边界差，不能反过来说原稿 237,316 错。
4. **v3 的提升不止一个变量。** 拟合文档 1,829→8,000、词元 100 万→250 万、窗口与抽样共同变化；同卷测试和反向短卷有力支持上下文长度影响，但不能据此把 29,133 根净增轴逐根鉴定为长程脉络轴，更不能称“因果关系锁死”。独立拟合的轴也不一一对应，只能说超过阈值的总数净增。
5. **136.6 万是抽样验收位置数，不是 1,200 篇全部前向词元。** 全部测试前向 2,713,320 个词元，真实有效位置 2,706,828；从中验收 1,365,856。正文“共136.6万”容易混淆。4,096 是超长文保留的正文词元数，拼接提示使实际序列略长于 4,096；原稿已写“有效正文”，这一点保留即可。“词”与 token 最好统一叫词元。
6. **水位不提供一半概率。** uncle 同时含父母系用法不推出恰好 50% 舅舅，亲戚更不等于“一半舅舅”；+10～+13 的线性坐标也不是概率混合估计。改为“具有多种亲属用法，呈现中间水位”即可。
7. **亲属标签和词源保持探索口吻。** 表亲也可经父亲的姐妹连通，外甥/外孙更不是简单“母系”统称；宜把表中父/母解释为实验左右组。血亲、姻亲、跨女性世系的外亲不是同一分类；“外亲路径跨婚姻”可作传统父系解释，不能把血亲直接定义成姻亲。“堂=屋内、表=衣外”是本次提出的解释性假说，尚未提供能证明具体造词年代与因果的词源文献，实验不能证明两千年前造词过程。
8. **零碎精度问题。** L13 两轴精确差 3.97668−3.61379=0.36289，应写约0.36；先把两数取两位再相减才有0.37。L56 的 Δ 实为 +0.000197，三位显示 +0.000 没错，别说数学上精确相等。L26 娘家第8及99.997%可作词表排序百分位，不能读成置信度或语义概率。
9. **参考与往期。** arXiv 标题、作者、v2 修订日期2026-10-19核实；正式作者拼法为 Sida Liu。Greenberg 1966、Mouton、书名正确，但不是本模型“默认父系”机制的直接证明。199/369/372、365 J-Lens、367 ICA-Lens 的本地内容与引用用途相符；14期在 `wechat/history/14.md`，标题吻合，2025-12 至今约11个月，口语“一年前”可接受。0.4.1 在本地实验版本留档存在，官方文档主页可访问。GitHub指定 main 原始路径此次返回404，HF页工具无法访问，**公开上传完整性未核实，不将网络失败当成未开源的证明**。尾声关于全部中国人/美国人、母语不可改变以及 RLHF 的断言并非这组单模型探针直接测得，宜作为作者观点而非实验已证事实。
