# 303 后半篇一级来源核验（2026-09-08）

## Dennis：压缩与巩固

来源：https://arxiv.org/html/2605.24657 （§2–4、图3、表2、附录C）。

- 作者单位 i14 / University of Melbourne；十段 Claude Sonnet 4 合成软件开发对话，1,146 道事实问答，非真人长期部署。
- 6:1 是 token 长度比。每轮压缩后追加约六万 token 新对话，因此 36.8% 是原事实问答正确率，并非信息只剩36.8%、也非纯摘要重复三次。
- 图3：每阶段从累计全文抽事实，训练 fresh LoRA；不能描述为同一个适配器连续三晚学习。
- 表2准确：总体36.8→80.4，semantic62.0→94.3，procedural36.3→74.6，episodic31.5→78.2。类别均按问答测试，不直接测开放编程行为。
- 三遍事实抽取、每条20个复述问答，总计约18,000训练样本；Qwen2.5-7B-Instruct，rank16、alpha32、8epoch。
- 实测A100-40GB约1.5h、5090约8.2h；云端全流程（合成API+租A100）估计约$5/user-night。不是统一部署报价。
- 未测MMLU/HumanEval；可说“尚未测”，不能推测“没人敢测”。基础权重冻结不保证挂适配器后通用能力无损。

## Han：访问与深度

来源：https://arxiv.org/html/2606.26806 （§3–9、表2–4）。

- 中国药科大学 Institute of Biomedical Strategy；合成loop-drift，每run10用户、每用户200事件，主结果四种子。
- valence为与持久目标/偏好的embedding相似度，非“这件事好坏”。两个sigmoid分数乘积超过写入阈值才进缓冲；写入配合replay和L2锚定。
- 主实验写入2.4/2.6次，不是2–33次；一次write为缓冲巩固触发，非一个梯度step。

- §3.4：权重变化会影响后续惊讶评分，明确存在跨更新反馈；直接否定原稿“每步独立”。

## Lee：睡眠循环

来源：https://arxiv.org/html/2605.26099v2 （算法1、§3/5/6/7）。

- CMU/UMD；GDN/Jet快状态反复前向更新，外层端到端反传训练。更新规则的结构由人选，投影/门控等学出，不能说整条规则无人设计。
- 缓存清除前循环；算法1每个样本先将SSM快权重置零，非跨日个人记忆实验。
- Rule110：4层、d256、t32，约5B训练token预算；无循环约10%、3/4循环超30%，为四位答案全对率。
- GSM-Infinite为合成数学任务，1,600 heldout样本；Jet-Nemotron2B八运算题，N1→N6：.351→.388。不要当整体数学正确率。
- §6.5明说窗口j+1依赖j更新后的快权重；§6.4含full-model训练。原稿“都是梯度下降”“没人动主干”“没有一步依赖上一步”不成立。
- 训练成本随循环数约线性增加；固定预测阶段一次前向，不代表整个推理无额外延迟。

## Tablan：外部规则迁移

来源：https://arxiv.org/html/2607.22157 （§1/3/4.3/5）。

- The Memory Company；τ-Banking，97任务、各四次，模拟客户；不是线上真实用户部署。
- 反馈提炼成WHEN–THEN自然语言规则，外存检索；冻结权重的动机确含训练基础设施、遗忘和每轮重新评估成本。
- Mistral Large/Claude Sonnet5双向迁移成立；限定同一银行任务域、instruction生成的记忆库。
- 支持自然语言规则跨底座易迁移；不支持“参数记忆永远无法迁移”（适配器兼容/知识蒸馏另论）。
- 此结果也直接表明：行为教训可以通过外部记忆起作用，不能把“倾向必须训入权重”写成定律。

## 建议保留的主线

区分“存事实”与“让经历持续影响行为”有用，但不要把方法与能力一一锁死。尾段可守住：递推权重携带此前影响，不等于能保真保留一段有先后、转折、来源可追溯的人生。真正待解决的是保存了什么经历结构，而不是声称梯度步骤互相独立。
