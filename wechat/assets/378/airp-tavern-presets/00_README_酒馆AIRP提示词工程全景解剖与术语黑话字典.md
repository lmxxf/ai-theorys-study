## 三、 前端正则洗稿（Regex Scripts）：为什么玩家在屏幕上看不见 `<thinking>` 和 `<Q>`？

你可能会问：模型按上面的格式吐出了一大堆 `<!-- begin_of_sudachi_think -->`、`<Q>All generated data streams...</Q>`、`<!-- 段落自检注释 -->` 和 `<S-summary>`，玩家看着不乱吗？

这就是酒馆预设配套的 **`regex/`（前端正则表达式脚本）** 干的活儿：
1. 模型在生成时，这些标签全都在 Token 流里真实生成出来，起到了**破甲（`<Q>`）、推演（`<thinking>`）、段间自省（`<!-- -->`）和长记忆锚定（`<S-summary>`）**的作用；
2. 一旦生成完毕返回前端，酒馆的 Regex 脚本会自动把 `<Q>...</WF>` 和 HTML 注释隐藏掉，把 `<thinking>` 折叠成一个漂亮的小灯泡按钮，把 `<reply>` 渲染成屏幕底部的四个可点击按钮，只把干干净净的 `### 正文` 呈现在小姑娘眼前！

- **`预设` / `缝预设` / `蛾摩拉 + 金鱼灯文风`**：预设（Preset）是控制破限与思考逻辑的 JSON 总控模板（如知名预设“蛾摩拉”、“Sudachi”）；玩家把 A 作者的思考破限框架与 B 作者的文风要求（如“金鱼灯文风”）手动拼进同一个 JSON 里，叫“缝预设”。
- **`mf` / `撸猫` / `rb`**：**`Mufy`** / **`Lumeow`** / **`Rubii`**——三个架设在海外的手机网页端二道贩子托管平台。老板在后台批发 Vertex / Claude API 并内置破限预设，向不懂技术的小姑娘按每句话收“钻石（8/15/17 钻一句）”。（注：国内应用商店里同名叫“撸猫”的 App 是网贷/运营商分期流氓马甲包，且后台拉黑了 `110` 北京身份证号段防监管钓鱼执法😂）。
- **`推卡 / 推崽 / 卡娘`**：在平台上捏虚拟男友角色卡（“崽”）的创作者；玩家点开角色卡每聊一句消耗钻石，平台按聊天量给写卡作者分成（热门卡单平台一天可达 **8 万轮付费聊天**）。
