# 黑龙江 13 个地级行政区中心城市来历（10-01 子代理调研，二手源居多，引用前回原文核）

| 城市 | 成形年份 | 起因类别 | 要点 |
|---|---|---|---|
| 齐齐哈尔 | 1691 | 清代军城 | 卜奎驿旁筑木城，1699 将军移驻 |
| 绥化 | 1862 | 垦殖设治城 | 放荒招垦成北团林子镇，1885 设绥化厅 |
| 佳木斯 | 1888 | 设治城＋江港 | 依兰副都统设东兴镇；满语“驿丞村”；1937 设市 |
| 哈尔滨 | 1898 | 铁路城 | 1898-06-09 中东铁路工程局落脚；名字说法多（晒网场/天鹅/平地…） |
| 黑河 | 1900 后 | 军城继承＋口岸 | 1683 瑷珲旧城/1685 新城；1900 庚子瑷珲被焚，黑河镇取代；1909 黑河府 |
| 牡丹江 | 1901–1903 | 铁路城 | 黄花甸子四五户人家；满语“弯曲的江”；1937 伪满设市 |
| 鹤岗 | 1914–1918 | 煤城 | 1914 发现煤、1918 开采；1945 兴山市，1949 改鹤岗 |
| 鸡西 | 1930 年代 | 煤城 | 滴道煤矿；鸡冠山以西；1956 设市（1941 改名年份乱，未核清） |
| 双鸭山 | 1947 | 煤城 | 1947 矿务局首用此名；两峰像卧鸭；1956 设市 |
| 伊春 | 约 1950–1952 | 林城 | 1952 设伊春县 7.5 万人；1957 设市；伊春河 |
| 七台河 | 1958 | 煤城 | 原勃利煤田；1965 特区、1970 县级市、1983 省辖 |
| 大庆 | 1959–1960 | 油城 | 1959-09-26 松基三井出油；1979 安达市改名大庆市；“国庆十周年”得名未核 |
| 加格达奇 | 1964 | 林城（会战） | 鄂伦春语“樟子松生长的地方”；地属内蒙古鄂伦春旗、黑龙江管，“人地两分”，未解决 |

古城断档：渤海上京 928 年辽太宗迁遗民、城被焚；金上京 1157 年海陵王下令毁宫殿宗庙铲平为耕地。

未核清单：齐齐哈尔“防喀尔喀”动机、卜奎=摔跤手、大庆得名、伊春林业局年份、七台河“齐得和”、黑河 1980/1993、绥化 1999、鸡西 1941。

主要来源：维基各市条目、thepaper.cn 中东铁路系列、各市政府网（jixi.gov.cn / yc.gov.cn / dxal.gov.cn / suihua.gov.cn / heihe.gov.cn）、xzqh.org、acheng.gov.cn。
