# 中俄 1689–1858（10-03 子代理调研）

- 尼布楚 1689：清 索额图、佟国纲；俄 戈洛文；清方译员耶稣会士徐日升、张诚，拉丁语。以拉丁文本为准，另有俄、满文本；英文维基：此后近两百年无正式汉文本。界碑文字数中英维基不一（写“多种文字”）。Perdue：“a near miracle”。
- 对俄事务归理藩院不归礼部；俄国不在朝贡国名单。茅海建：按近代观念两国也属平等关系；平准后两国“越来越疏远”。（thepaper 5239350）
- 1727 恰克图条约：清图理琛 vs 萨瓦；图理琛 1728 被判死罪、雍正赦免。1729 恰克图设市（来源弱）。
- 1708 设俄罗斯学→俄罗斯文馆，八旗子弟学俄语；东正教北京传道团康熙末年到京（1713/14/15 说法不一）；北馆源于 1685 雅克萨俄俘。
- 图理琛 1712 出使土尔扈特阿玉奇汗，经西伯利亚往返三年，《异域录》1723 刊，欧洲受关注。
- 托时使团 1731-01 莫斯科、德新使团 1732-04 圣彼得堡，向安娜女皇跪拜（“行叩首之礼”）；目的：对准噶尔用兵请俄中立。“唯一”只见二手→写“罕见”。
- 乾隆三次关闭恰克图互市（年份各说不一），最长到 1792《恰克图市约》复市。
- 1757 阿睦尔撒纳逃俄，1758 俄方称出痘死，清派人验尸。
- 1854 起穆拉维约夫武装航行黑龙江；1858 英法攻陷大沽后第三天，炮舰到瑷珲以“助华防英”逼签，5-28 签；奕山革职。
- 不用：康熙“俄罗斯国人人材颇健……恐受其累”（无卷数、疑拼接）。
