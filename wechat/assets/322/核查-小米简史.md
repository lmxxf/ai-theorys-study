# 核查：小米 MiMo 简史（2026-09-27）

> 说明：X/Twitter 页面抓取返回 402，推文原文只能看到搜索引擎摘要，已注明。"摘句"引号内为页面原文或工具转述的原文。

## 1. MiMo-7B：2025-04-30、25T token、MTP、四个 checkpoint

- GitHub README https://github.com/XiaomiMiMo/MiMo ："pre-trained on approximately 25 trillion tokens"；MTP 是 "additional training objective" that "enhances model performance and accelerates inference"。公开的四个模型：MiMo-7B-Base / MiMo-7B-RL-Zero / MiMo-7B-SFT / MiMo-7B-RL。
- HF https://huggingface.co/XiaomiMiMo/MiMo-7B-Base ；技术报告 arXiv 2505.07608（2025-05-12 挂出）。
- 4 月 30 日这个日期：Wikipedia 引 Tech in Asia 写的是 "30 April 2025"。小米官方页面里没找到写明这一天的原文。
- **结论**：25T、MTP、四个 checkpoint **属实**（有一手来源）。4-30 **大体可信，但只有二手来源**（arXiv 版晚到 05-12）。另外 05-30 还发了 RL-0530，严格说开源的不止四个。

## 2. 罗福莉加入小米、担任 MiMo 负责人

- 这件事是她本人**发朋友圈**宣布的，时间是 2025-11-12。媒体转载的原话："智能终将从语言迈向物理世界。我正在Xiaomi MiMo，和一群富有创造力、才华横溢且真诚热爱的研究员，致力于构建这样的未来……"（中国基金报 https://www.chnfund.com/article/AR486eee0a-2368-8918-8473-3a1d89d19bc6 ；四川在线 https://sichuan.scol.com.cn/ggxw/202511/83154719.html ）
- "MiMo 负责人"这个头衔：媒体写的是"小米集团MiMo负责人"。2025-12-17 小米人车家全生态大会上她第一次以这个身份出场（证券时报 https://stcn.com/article/detail/3544371.html ）。
- **结论**：11-12 宣布加入**属实**，但一手来源是朋友圈，只能从媒体转载里看到原话，没有公开 URL。负责人头衔来自媒体报道和发布会，**没找到小米的任命公告**。

## 3. MiMo-V2-Flash：2025-12-16、309B/15B、27T

- GitHub https://github.com/XiaomiMiMo/MiMo-V2-Flash ："309B total parameters and 15B active parameters"；"Trained on 27T tokens using FP8 mixed precision and native 32k seq length"。技术报告 arXiv 2601.02780。
- HF API 显示 XiaomiMiMo/MiMo-V2-Flash 和 -Base 两个仓库的创建日期都是 **2025-12-16**。小米是在 12-17 的人车家生态大会上正式发布的，SCMP 和 Wikipedia 用的都是 12-17。
- **结论**：参数和数据量**属实**。日期写 12-16（权重上线）或 12-17（发布会）都说得通，**建议写"12 月中旬"或者注明是哪个口径**。

## 4. Hunter Alpha（03-11~03-18）

- 小米官方页 https://mimo.xiaomi.com/mimo-v2-pro ："One week ago, an anonymous model codenamed Hunter Alpha was listed on OpenRouter, the world's largest API aggregation platform." / "call volume grew steadily, topping the daily chart for multiple days and surpassing 1T tokens in total usage."
- 03-18 由罗福莉揭晓：Reuters 2026-03-18 有报道（"Mystery AI model revealed to be Xiaomi's…"，转引自 Wikipedia）。**罗福莉本人发帖的原文没抓到。**
- 03-11 上线这个日期只在二手文章里出现（buildfastwithai、particula 等）。官方原话是"一周前"，和 03-11 对得上。
- 没找到 OpenRouter 官方的说法（推文或博客都没搜到）。
- **结论**：匿名上 OpenRouter、日榜多日第一、总量超过 1T、之后揭晓是 V2-Pro，这几点**属实**（小米官方页）。要注意官方原话是"多日登顶日榜"，不是整周第一。"内测版"的说法来自媒体。**罗福莉原话和 OpenRouter 官方说法：找不到一手。**

## 5. MiMo-V2-Pro 从未开放权重？

- 查了 HF API（author=XiaomiMiMo）：有 V2-Flash、V2.5-Pro、V2.6-Pro-RL 等仓库，**没有 MiMo-V2-Pro**。Wikipedia 引 Reuters：V2-Pro 是闭源 API 产品，罗福莉当时表示"intended to open-source a variant"。后来开源的 V2.5-Pro 也是 1.02T/42B，可以看作兑现了这句话。
- **结论**：**属实**（V2-Pro 本身从来没有公开权重）。这是根据官方 HF 组织里查不到得出的，不是官方的正面声明。

## 6. MiMo-V2.5 / V2.5-Pro 发布日期

- 小米文档 https://mimo.mi.com/docs/en-US/news/latest/v2.5-open-sourced ：系列 "began public testing on April 23rd"；权重 "fully open-sourced under the permissive MIT license"。HF 上 V2.5-Pro 仓库创建于 2026-04-27。Wikipedia 和 AA 写的是 04-22。
- **结论**：**有出入**。04-22 是发布日（AA、Wikipedia 的口径），官方原文写的是 04-23 开始公测，权重在 04-27 前后上的 HF。建议写"4 月下旬"或者"4 月 22 日发布"。

## 7. Artificial Analysis 智能指数

- AA 官网 https://artificialanalysis.ai/models/mimo-v2-6-pro ："46 on the Artificial Analysis Intelligence Index"，开源权重里排 "#1 / 115"。
- AA 官方推文 https://x.com/ArtificialAnlys/status/2102128560962187701 （页面打不开，以下是搜索摘要）："MiMo-V2.6-Pro debuts as the top open weights model on the Artificial Analysis Intelligence Index (46). At $0.13 per Intelligence Index task…"
- GLM-5.3 (max) 45、Kimi K3 (max) 44：这组数只在二手报道里看到（pasqualepillitteri.it、unite.ai 等转述 AA 的开源对比图），**AA 原页面没抓到**。
- 总榜排第几：VentureBeat 写的是和 Grok 4.7 并列 46 分，高于 Grok 4.6（44）和 Gemini 3.8 Flash（41）。**AA 给的总榜名次找不到一手**，文章里别写具体第几名。
- V2.6 发布日期：HF 仓库创建于 09-21，媒体写 09-21 或 09-22。
- **结论**：46 分、开源第一**属实**（AA 一手）。GLM-5.3 45 / Kimi K3 44 **只有二手来源，大概率准确**。总榜名次**找不到一手**。
