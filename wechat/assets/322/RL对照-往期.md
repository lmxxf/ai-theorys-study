## 二、分家细节

### DeepSeek V4 / V4-Flash-0731 / V4.1
- 0731：“模型结构、尺寸和 preview 一致，仅重新进行了后训练”，这句话写在 API 更新日志里（282:13,35）。config 逐字段比对，结果相同（282:119）。
- 管线：数学、代码、agent、指令遵循各自做 SFT+GRPO，再用在线蒸馏合并（265:99）。老师超过 10 个，每个都可能是万亿参数（284:23,248）。
- 蒸馏粒度：比全词表。理由是单点估计的梯度方差大，训练不稳（284:246）。工程做法：老师权重放在集中存储里，只缓存最后一层隐状态，再现场重建 logits；样本按老师排序，同一时刻显存里最多只有一个老师的输出头（284:250）。
- 思考模式：不同模式配不同的长度惩罚和上下文窗口，Think Max 在系统提示词开头注入一段指令（284:135-137）。
- 为什么合并：报告只说规避了“性能退化”，没给对照实验（286:31-35）。
- 基建：用 DSec 沙箱、链式快照、全局有序操作日志回放（287:83）；被抢占后靠 WAL 续写，并论证了从头重跑会引入长度偏差（287:97-103）。
- V4.1：QAT 延伸到主 KV 缓存（308:456）。

### Kimi K3
- 三段式：SFT 冷启动→分域、分档 RL 出 9 个专家→MOPD（264:302；284:17）。SFT 数据用前代模型合成，再经多阶段验证和人工标注（264:304）。
- 思考档位：超过 τ×b₀ 的轨迹，奖励直接覆写为 −1；先训 max 档，再逐步退火出 high 和 low；τ 按领域配置，人在环里引导（284:115-131）。
- RL 算法沿用上一代 Kimi，报告没有展开（284:306）。
- 图 8：RL 算力越多，工具调用步数和分数一起涨（284:83-87）。
- 基建：partial rollout 完成到 λ 比例就叫停，没做完的轨迹下一轮接着跑，这属于“极端 off-policy”（287:43-51）。沙箱最多 98% 的时间在等推理，用 microVM（AgentENV）暂停恢复，最快 49ms（287:69-79）。
- 人还在的位置：web 开发任务由专家整理；复杂助理任务是“我们设计”；仿真世界像不像，报告没讲怎么验收（283:236-250）。

### GLM（5 / 5.2 / 5.3 / 5.3-Flash）
- 5.3 和 5.2 用同一个 base，“every gain comes from post-training”（282:105）。截稿时权重还没开源，无法自己验证（282:121）。
- 训练单位是专家级工作单元，“有些任务要一个工程师干好几天”（282:143-151）。例子是 ML 基础设施提速任务，交付物是可测量的端到端加速，同时要守住正确性（291:27-39,107-110）。
- 漏洞挖掘：训练中在 269 个项目里找出 2436 个漏洞（282:279）。仍需要“相当数量的人工介入”（282:281；291:177）。
- 5.3 推理不许关，三档怎么训出来的没披露（284:270-274）。
- 框架用 slime，支持共置/分离、同步/异步（287:127；265:182）。

### Qwen3.8
- 往期只写了一条后训练相关事实：试过 NoPE，后训练后“停不下来”（endless generation）的比例明显升高，所以保留了 RoPE（293:92）。RL 配方往期未写。
- 265 期回顾过 Qwen3 的四阶段：long-CoT 冷启动→推理 RL（GRPO）→thinking mode fusion→general RL（265:85）。

### Gemini 3.7 Flash
- 模型卡六栏都写“based on Gemini 3.6 Flash”。官方把提升归因于 “algorithmic improvements to its core reasoning foundation”（282:85-91）。
- 这是披露方式，不是“只做后训练”的声明（282:93）。方法一字未提（282:133）。

### 其他
- Ring-Zero（1T 参数，零起点 RL）：五个崩溃点及修复。按词平均会让输出长度无限增长，第二阶段改成按样本平均（315:672-684）。
- 学术对照：混训只用分头练 63.7% 的 GPU 小时，性能相当（286:91）。Ai2 的 BAR 比完整重训低 1.4 分（286:152）。小米 MOPD 对 Mix-RL 为 0.937 对 0.882（286:97）。
- 沙箱冷启动最多差 110 倍，折算下来多烧 5,316 小时（287:85）。

## 三、往期写过的通用结论 / 金句

- “扩大后训练规模的困难，很大一部分已经从模型转移到了环境”（GLM 原话，282:159-161）；“要很多个，不是手工搭出来的那么几个”（282:171-173）。
- “卡住的从来不是‘能不能判分’，是‘能不能造出一件让它去干的活’”（282:323）。
- RLVR 判的是“答案”，agentic RL 判的是“结果”（282:255）；“换了一类题目，天花板得重新算”（282:253）。
- 长任务成功率 ≈ pₙ，单步小改进会被指数放大（282:347-351；268:88）；self-conditioning 让 p 本身也在衰减（282:357-361）。
- “造一个长程 agent 训练环境，这件事本身就是一个长程 agent 任务”（283:272）；上一代模型差不多同时跨过了那条线（282:313-315，作者推测）。
- “人守着标准，agent 负责把量铺开”（283:258）；“人没有退场，只是往上挪了一层”（283:356）。
- “你在 API 里点的 low/high/max，旋钮下面埋着一批老师”（284:294,327）。
- 老师不是越强越好：老师得离学生近，手里还得有学生没有的东西（285:229-241,391）。
- 分头练最确定的收益是模块好管理，不是总分更高（286:224,249）；康威定律（286:178）。
- “RL 后训练的车间里，最贵的动作不是算，是等”（287:15）；“基建不中立”（287:103,168）；“车间对车间的竞争”（287:145）。
- 一道训练题 = 初始状态 + 工具 + 目标 + 判分器（291:77-85）；“文字只负责告诉你要干什么，环境负责藏着答案”（291:95）。
- “强化学习后训练……是在把预训练存下来的那点余地花掉”（315:721）；“框架内部不进货”（315:731）。
- “采样一万次没见过，推不出概率是零”（317:191,456）；75% 更可能是可达边界，不是能力边界（317:414-416）。
- “预训练买的是潜能，后训练买的是‘成为谁’”（265:287）；“后训练不是每一段都贵，是它的天花板被捅穿了”（265:161）。
