## 一、 核心结论速览（Executive Summary）

Zero 在 11 月 6 日凌晨一针见血地指出：MIT ICML 2026 论文（`arXiv:2604.23985`）直接用欧氏空间向量减法 $v_t = x_t - x_{t-1}$ 计算夹角，测量的其实是**穿破高维球面肚子的平直欧氏弦（Euclidean Chord）**。由于残差流向量受 LayerNorm / RMSNorm 约束生活在高维流形（近似球面）上，两步连续位移共享中间点 $-x_{t-1}$，导致平直弦夹角被死死锁在 $113^\circ \sim 120^\circ$（两两正交单位向量的欧氏等边三角形外角 $120^\circ$），其中绝大部分读数只是**球皮本身的法向弯曲底色（Extrinsic Normal Curvature）**，与下一词预测信息熵 $H(t)$ 的相关性最高仅有 $r = 0.1076$（$R^2 = 1.16\%$，GPT-2 XL）与 $r = 0.0909$（$R^2 = 0.83\%$，Pythia-2.8B）。

我们在完全相同的语料（LAMBADA 1,024 篇长文本 + UD EWT 512 句短文本）与严格因果对齐口径（在位置 $t \in [5, T-2]$ 仅使用 $\le t$ 的残差状态预测当前 `logits[t]` 的下一词熵 $H(t)$，零未来信息泄露）下，将残差流投影到**流形表面（切空间 $T_{\hat{x}}S^{d-1}$）**，系统实测了 **“表皮转角与测地曲率（方向一）”、“流形表皮快慢與范数（方向二）”、“切空间方向多寡与跨层表皮运动（方向三）”** 共 32 项几何指标。核心发现如下：

1. **数学定理级验证（剥离 $120^\circ$ 假底色）**：
   - 在单元测试中，单位球面上三个两两正交点的平直弦转角 `c_flat` 恒为 **$120.00^\circ$**，而沿大圆平行移动（Parallel Transport）剥离球心法向分量后的流形表皮转角 `theta_surf` 精确回到正交基准 **$90.00^\circ$**；当点沿赤道大圆测地线每步前进 $30^\circ$ 时，平直弦转角被球皮弯曲欺骗读出 **$30.00^\circ$**，而流形表皮转角精确归零为 **$0.0000^\circ$**（真直行），方向有效秩精确为 **$1.0000$**。
   - 在真实大模型（LAMBADA ~7.9 万词元）中，剥离球心法向弯曲后，流形表皮转角均值从平直弦的 **$114.2^\circ \sim 115.4^\circ$** 下降至 **$105.5^\circ \sim 109.6^\circ$**；若进一步扣除各向异性均值锥（Centered Sphere Projection），表皮转角均值直接落回 **$97.7^\circ \sim 98.6^\circ$**（极其接近 $90^\circ$ 正交基准！）。
   - 更惊人的是，被我们剥离出来的那层“球皮法向弯曲假底色” $\Delta\theta_{\text{extrinsic}}(t) = c_{\text{flat}}(t) - \theta_{\text{surf}}(t)$（平均约 $4.6^\circ \sim 9.0^\circ$），与下一步预测熵 $H(t)$ 呈现出**强烈的负相关**（在 Qwen3-0.6B 上高达 $r = -0.3414, R^2 = 11.66\%$；在 Pythia-2.8B 上 $r = -0.1782$）！因为球皮法向折角 $\Delta\theta_{\text{extrinsic}}$ 正比于球面步长 $s_{\text{geo}}$，而步长与熵呈负相关（$r = -0.24 \sim -0.39$），表皮真转角 $\theta_{\text{surf}}$ 与熵呈正相关（$r = +0.12 \sim +0.14$）——**MIT 的平直弦公式 $c_{\text{flat}} = \theta_{\text{surf}} + \Delta\theta_{\text{extrinsic}}$ 把一正一负两个物理量硬生生加在一起互相抵消，难怪最后只剩下 $1\%$ 的残渣！**

2. **真正的单变量主力：不是纯角度，而是“流形表皮快慢（步长 $s_{\text{geo}}$ / 跨层角速度 $v_{\text{layer}}$ / 范数）”与“除以弧长的真实测地曲率 $\kappa_{\text{geo}}$”！**
   - **真实测地曲率 $\kappa_{\text{geo}}(t) = \frac{\theta_{\text{surf}}(t)}{\text{mean\_arc}(t)}$（单位弧长的表皮转角）**：仅仅把表皮转角除以表皮弧长（还原微分几何中“曲率 = 单位弧长转角”的本义），单变量正相关性立刻从 MIT 的 $0.09 \sim 0.11$ 暴涨至 **GPT-2 XL $r = +0.2052$（$R^2 = 4.21\%$，提升 3.6 倍）**、**Pythia-2.8B $r = +0.3448$（$R^2 = 11.89\%$，提升 14.3 倍！）**、**Qwen3-0.6B $r = +0.2277$（$R^2 = 5.18\%$，短语料上达 $r = +0.3055, R^2 = 9.34\%$）**！
   - **沿着流形表面走的“快慢”（水平测地步长 $s_{\text{geo}}$ 与垂直跨层角速度 $v_{\text{layer}}$）**：
     - 水平球面步长 $s_{\text{geo}}(t) = \arccos(\hat{x}_t \cdot \hat{x}_{t-1})$ 与预测熵呈强负相关：GPT-2 XL **$r = -0.2385$（$R^2 = 5.69\%$）**、Pythia-2.8B **$r = -0.3901$（$R^2 = 15.22\%$，短语料达 $r = -0.4625, R^2 = 21.39\%$！）**、Qwen3-0.6B **$r = -0.3046$（$R^2 = 9.28\%$）**。物理图景极其清晰：**当模型对下一词高度确定（低熵）时，残差流在球面表皮上大步流星地跨跃（步长 $s_{\text{geo}}$ 大、单位弧长曲率 $\kappa_{\text{geo}}$ 小）；当模型犹豫不决（高熵）时，残差流在球面表皮上原地小碎步踌躇（步长 $s_{\text{geo}}$ 急剧缩短、急刹车 $a_{\text{geo}} < 0$、单位弧长内频繁急转弯 $\kappa_{\text{geo}}$ 飙升）！**
     - 垂直跨层表皮角速度 $v_{\text{layer}}(l, t) = \arccos(\hat{x}^{(l)}_t \cdot \hat{x}^{(l-1)}_t)$ 同样是顶级主力：GPT-2 XL **$r = -0.2986$（短语料 $r = -0.4490, R^2 = 20.16\%$）**、Pythia-2.8B **$r = -0.3923$（$R^2 = 15.39\%$）**、Qwen3-0.6B **$r = -0.3333$（短语料 $r = -0.4085, R^2 = 16.69\%$）**。
     - 残差流范数 $\|x_t\|_2$ 更是直接编码了置信度/逆不确定性：GPT-2 XL **$r = -0.3434$（$R^2 = 11.79\%$）**、Pythia-2.8B **$r = +0.3454$（$R^2 = 11.93\%$）**、Qwen3-0.6B **$r = +0.4503$（$R^2 = 20.28\%$，短语料高达 $r = +0.5399, R^2 = 29.15\%$）**。

3. **沿着流形表面的“方向多寡”（局部切空间有效秩 $\text{erank}$）**：
   - 在单层水平时间窗口（5 步）内，带弧长权重的切空间有效秩 $\text{erank}_{\text{weighted}}$ 单变量相关性为 $r = -0.10 \sim -0.14$（跨层垂直切空间有效秩 $\text{erank}_{\text{layer}}$ 单变量达 **GPT-2 XL $r = +0.1900$、Pythia-2.8B $r = -0.3011$（$R^2 = 9.06\%$，短语料 $r = -0.4375, R^2 = 19.14\%$）、Qwen3-0.6B $r = +0.2593$（短语料 $r = +0.3174, R^2 = 10.08\%$）**）。
   - 当把全模型各层的**方向有效秩特征族（$\text{erank}_{\text{dir}}, PR_{\text{dir}}, \text{erank}_{\text{weighted}}, \text{erank}_{\text{layer}}$）**联合起来时，10 折跨篇章交叉验证（10-fold Passage CV）对预测熵 $H(t)$ 的解释力达到：**GPT-2 XL $r = 0.4732$（$R^2 = 22.16\%$）**、**Pythia-2.8B $r = 0.6944$（$R^2 = 47.87\%$）**、**Qwen3-0.6B $r = 0.5354$（$R^2 = 28.59\%$）**！
   - 而且在微观案例对比（`ROUTINE` 顺口溜 vs `HARD` 烧脑逻辑题）中，**水平切空间方向有效秩 $\text{erank}_{\text{dir}}$ 是区分“顺口溜一条道走到黑”与“烧脑题多方向分叉”最干净的几何探针**：在三个模型上，`HARD` 逻辑题的 $\text{erank}_{\text{dir}}$ 一致高于 `ROUTINE` 顺口溜（GPT-2 XL：$3.972$ vs $3.595$，$\Delta = +0.377$；Pythia-2.8B：$4.157$ vs $3.782$，$\Delta = +0.375$；Qwen3-0.6B 中文：$4.052$ vs $3.836$，$\Delta = +0.216$）！

4. **多变量联合解释力大跃升：从 MIT 的 $R^2 \approx 1\%$ 暴涨至单层 $23\% \sim 41\%$、跨层全流形表皮 $55\% \sim 67\%$！**

## 二、 数学定义与球面非欧几何自检（Unit Self-Test）

设第 $l$ 层在词元位置 $k$ 的残差流输出为 $x_k \in \mathbb{R}^d$，单位球面投影为 $\hat{x}_k = \frac{x_k}{\|x_k\|_2} \in S^{d-1}$（去均值锥版本为 $\hat{x}^{(c)}_k = \frac{x_k - \mu_l}{\|x_k - \mu_l\|_2}$，其中 $\mu_l$ 为前 64 篇校准语料估计的层均值向量）。在任意评估位置 $t \in [5, T-2]$，所有特征严格只使用 $\le t$ 的状态 $x_0, \dots, x_t$，去预测 `logits[t]` 对下一词元 $t+1$ 的 Shannon 信息熵 $H(t)$（单位：bits）：

### 1. 四大几何指标族严格定义

| 指标族 | 符号 / 代码名 | 数学定义（全部因果对齐于终点 $t$，绝不触碰 $x_{t+1}$） | 物理意义 |
| :--- | :--- | :--- | :--- |
| **基线 0：MIT 平直欧氏弦** | `c_flat(t)`<br>`C_flat_3(t)` | $v_k = x_k - x_{k-1}, \quad c_{\text{flat}}(t) = \arccos\left(\frac{v_t \cdot v_{t-1}}{\|v_t\|\|v_{t-1}\|}\right)$<br>$C_{\text{flat},3}(t) = \frac{1}{3}\sum_{j=0}^2 c_{\text{flat}}(t-j)$ | 穿破球肚子的平直欧氏弦夹角，受共享点 $-x_{t-1}$ 的 $-1/2$ 偏置污染，锁死在 $114^\circ\sim 120^\circ$ |
| **方向一：流形表皮转角与测地曲率** | `theta_surf(t)`<br>`Theta_surf_3(t)` | $u_{\text{in}}(t) = \text{norm}\big((\hat{x}_{t-1}\cdot\hat{x}_{t-2})\hat{x}_{t-1} - \hat{x}_{t-2}\big)$<br>$u_{\text{out}}(t) = \text{norm}\big(\hat{x}_t - (\hat{x}_t\cdot\hat{x}_{t-1})\hat{x}_{t-1}\big)$<br>$\theta_{\text{surf}}(t) = \arccos\big(u_{\text{in}}(t)\cdot u_{\text{out}}(t)\big)$ | 沿大圆测地线平行移动至切空间 $T_{\hat{x}_{t-1}}S^{d-1}$ 后的**流形表面真转角**（剥离指向球心的法向分量） |

| **方向二：流形表皮快慢與范数** | `s_geo(t)`<br>`S_geo_3(t)` | $s_{\text{geo}}(t) = \arccos(\hat{x}_t \cdot \hat{x}_{t-1})$ | **球面测地线步长（水平表皮角速度）**：一步在球皮上跨出多远 |

| | `v_layer(l, t)`<br>`theta_layer(l, t)`<br>`erank_layer(l, t)` | 固定词元 $t$，沿层深 $l-1 \to l$ 在球面上的**垂直跨层角速度** $\arccos(\hat{x}^{(l)}_t\cdot\hat{x}^{(l-1)}_t)$、**跨层表皮转角**与最近 5 层切向**跨层有效秩** | 同一词元在层间残差流球面表皮上的推进快慢、拐弯与方向扩散度 |

## 三、 单变量全方位对决（LAMBADA 1,024 篇 & UD EWT 512 句）

### 1. 为什么 MIT 的平直弦 `C_flat_3` 只有 1% 解释力？——“一正一负抵消”的实锤证据

先看三个模型在 LAMBADA 全量测试集上，平直弦转角 vs 流形表皮转角 vs 被剥离的球皮法向弯曲底色的真实均值与相关性：

### 微观现象的三大洞见：
1. **为什么 `ROUTINE`（如 `1+1=2, 2+2=4`、古诗、星期几）的转角反而比 `HARD` 接近 $120^\circ$（平直弦）或 $110^\circ\sim 116^\circ$（表皮转角），而局部方向有效秩 `erank_dir` 却显著更低（$3.59 \sim 3.83$ vs $3.97 \sim 4.16$）？**
   - 这直接揭穿了把“大转角”等同于“复杂思考”的直觉误区！在顺口溜、对仗句、算术周期序列（如 `1+1=2, 2+2=4`）中，残差流在一个**固定的低维子空间（低有效秩 `erank_dir` $\approx 3.6$）内做大幅度的周期性往返摆动（像钟摆一样在 `数字 -> 加号 -> 数字 -> 等号` 之间来回折返）**！因为来回折返且每一步步长很大（`S_geo_3` 大），所以相邻两步的夹角很大（大于 $90^\circ$ 的钝角折返），但它们始终局限在同一个低维平面内来回跳，没有开辟新维度！
   - 相反，在 `HARD` 烧脑逻辑题中，残差流每一步都在吸收新的逻辑约束，不断向**新的正交切方向分支试探**，因此局部切空间的**方向有效秩 `erank_dir` 全面飙升（$+0.22 \sim +0.38$）**，同时每一步之间的夹角回到正交基线（去均值表皮转角 `Theta_surf_c_3` 在 GPT-2 XL 和 Pythia 上从 $107^\circ$ 降到 $98^\circ \sim 100^\circ$，即步与步之间接近 $90^\circ$ 正交探索），且在球面上的推进步长明显放缓（`S_geo_3` 在 GPT-2 XL 上缩短 $2.44^\circ$、在 Pythia 上缩短 $4.14^\circ$）！
2. **在 `PAIRS`（陷阱题冲突点 vs 正常对照，如 `妈妈30岁生35岁儿子` vs `妈妈60岁生35岁儿子`、`十米桌顺手揉头发` vs `半米桌顺手揉头发`）上**：
   - 在冲突词跨度（Conflict Span）上，小模型/基座模型（GPT-2 XL、Pythia-2.8B、Qwen3-0.6B）在 teacher-forced 阅读提示词时，陷阱句与对照句的局部转角差异极小（$< 1^\circ$），但**切空间方向有效秩 `erank_dir` 与跨层表皮转角 `theta_layer` 在 Qwen3-0.6B 的冲突词位置出现了一致微升**（5 对中有 4 对的 `erank_dir` 在冲突点更高，均值 $+0.015$；跨层表皮转角 `theta_layer` 高 $+0.434^\circ$；整句跨层表皮角速度 `v_layer` 在 6 对中文陷阱题上有 5 对更高，均值 $+0.281^\circ$）。这也再次印证了我们在第 359/360 期（Paper 99）的结论：对于没有觉醒或参数量不足的小模型，语义冲突在阅读阶段引起的几何扰动很微弱，主要体现在切空间分支维度的轻微发散上。
