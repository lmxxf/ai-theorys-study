## 二、数学与实现上的优先必改项

### 1. 原始残差流不因Pre-LN就严格生活在固定半径球面上

正文13、17、163行及全文“MIT用错空间”的论证。

代码取的是**每个Transformer block的输出残差状态**，然后自己做`xhat = normalize(h)`。Pre-LN／RMSNorm用于送入子层的分支输入，不会把残差相加后的block输出强制约束成单位球面。学习到的仿射参数、LayerNorm的去均值和epsilon也使“每层必在d−1维球面”不是原架构的严格结论。

原始JSON已经给出直接反证：长语料第0层norm的均值／标准差分别约为GPT-2 `22.260 / 5.275`、Pythia `36.006 / 3.627`、Qwen `8.024 / 1.006`，显然不是固定长度。全文又把norm纳入预测，本身也承认长度携带信息。

**最小修法：**“我们把残差状态单位化，研究其方向在单位球面上的几何，同时另保留范数特征。”这是有价值的表示选择，不能写成原始残差流必须遵守的物理定律。因此不能仅凭球面分析更强，就把欧氏弦角称为“公式错了／荒唐／假读数”。外在转角和球面内在转角测的是不同对象。

### 2. `c_flat = θ_surf + Δθ`是定义差值后的恒等式，不是独立证明的法向曲率分解

正文63–76、182行；抵消图及封面。

代码151–153行直接定义：

```text
extrinsic_bias   = c_flat   - theta_surf
Extrinsic_bias_3 = C_flat_3 - Theta_surf_3
```

所以加回去当然相等。这个Δ没有被单独测成一个“球皮向心折角”，更不自动满足“正比于步长”。而且`c_flat`用**未单位化的h**计算，theta用单位化状态计算，差值还混入了径向长度变化，不能全部归于球面法向弯曲。

即使a、b、c严格是单位向量，准确的关系也是非线性余弦关系。设相邻球面弧长为α、β，中间点球面转角为θ，则：

```text
cos(c_flat_unit)
 = cos(α/2) cos(β/2) cos(θ) - sin(α/2) sin(β/2)
```

它不意味着角度直接相加，也不意味着Δ与一步弧长成正比。可复算反例：α=30°、β=90°、θ=180°时，弦角=150°，Δ=−30°；它甚至未必为正。赤道等步长直行、三个正交点这两项自检都正确，但只是特例，不能证明普遍分解。

建议称Δ为“原始弦角与单位球面转角的差值”，明确是操作性定义。若要保留法向曲率解释，需要另做匹配几何和尺度的论证，当前数据不支持“严格等价”。

### 3. “三模型均一正一负抵消”被同层数据直接反驳

目前挑出的正负相关来自不同层，且有的单步、有的三转角平滑。不同层的最大r不能拼成同一次分解；Pearson r也不能直接相加，应在同层、同窗口比较协方差及标准差。

取各模型原始`C_flat_3`的峰值绝对相关层，同位置、同平滑口径实际为：

|模型／层（0起）|r(C_flat_3,H)|r(Theta_surf_3,H)|r(Extrinsic_bias_3,H)|说明|
|---|---:|---:|---:|---|
|GPT-2 XL L21|+0.107642|+0.105508|**+0.004169**|差值项不是负相关，不能讲正负抵消|

建议保留“不同几何量与熵的关联可能方向不同”，撤下“三模型低解释力真正病根已被唯一破案”的结论。

### 4. κ不是`θ_surf / 当前一步s_geo`，也不是连续曲率的精确恢复

正文80–91、182行；曲率图。

代码155–161行实际计算的是顶点两侧弧长的平均作分母：

```text
s_t = angle(xhat_(t-1), xhat_t)
κ_t = θ_t / ((s_(t-1) + s_t)/2)       # 均用弧度，含数值下限
Kappa_geo_3(t) = mean(κ_t, κ_(t-1), κ_(t-2))
```

这里θ_t的顶点是xhat_(t-1)，索引t表示该三点窗口的终点。它是**离散球面测地转弯密度／曲率估计量**；在光滑曲线、小步长极限下才可联系连续测地曲率，不是对任意大步采样“还原微分几何严格真值”。本数据常有数十度步长，这个限定尤其重要。

还应明确：`Kappa_geo_3`是**先逐点相除、再三点平均**，通常不等于`Theta_surf_3/S_geo_3`。建议在正文首次给出正确分母，图中改“离散曲率指标”；删除“MIT没除步长所以定义错误”的指控。离散轨迹的角度统计本身是合法定义。

### 5. 有效秩代码没有执行文中所说的平行移动

正文124行、方向图；代码192–205行。

实际流程：取最近5段**单位状态的欧氏弦**，全部投影到终点xhat_t的同一个切平面，再把投影行单位化。不是先在各自出发点构造球面切向量、再沿大圆做保长度的平行移动。

正交投影与平行移动不同：前者可能缩短长度、改变夹角；后者沿指定路径保持内积。当前指标可以作为“共同切平面投影方向”的统计量，不能在报告或文章里宣称已实现真正的五步平行移动。赤道直行的自检两种方法都可能给1，不能靠这个特例区分实现。

最省事的修法是准确描述现有投影过程，保留已有数值；若坚持平行移动的定义，则属于要改实现并重跑的数据，不是只换名词。

### 6. 有效秩的谱权重是σ²，不是所引用Roy–Vetterli的σ

代码73–84行从Gram矩阵G=WWᵀ取特征值λ，令p=λ/Σλ，再算exp(Shannon entropy)。也就是：

```text
当前代码：p_i = σ_i(W)^2 / Σσ_j(W)^2
          erank_dir = exp(-Σ p_i log(p_i))
Roy–Vetterli对W：q_i = σ_i(W) / Σσ_j(W)
                erank(W) = exp(-Σ q_i log(q_i))
```

两者不是同一个数。当前值可称**Gram谱／能量谱熵有效秩**，或者明确是对G而不是W应用有效秩，不能说“对五行矩阵的奇异值分布直接按原论文定义计算”。[Roy–Vetterli原文](https://www.eurasip.org/Proceedings/Eusipco/Eusipco2007/Papers/a5p-h05.pdf)

在非退化输入下1–5的范围及一方向／五个等强正交方向两个极值仍成立。但3.6与4.1不是精确独立方向个数，也不能画成已经证明“一条线／每步新正交分支”；这里不是对分叉树、主体或推理路线的直接计数。

## 四、因果、交叉验证与样本限制

### 10. “严格无泄露”需要降到代码真正保证的范围

正文144、184行。

- **窗口索引本身因果对齐通过**：t从5至T−2，指标窗口不越过t，y=H(logits[t])。
- 但去均值μ_l是**先用长语料前64篇全部token估计，再用于所有CV折**。前64篇也参与评估；其测试折状态和同篇未来位置会进入μ。它不是目标标签泄露，却不满足严格独立折的预处理／在线前缀因果假设。
- NaN填补的列均值也在分折前按全体X计算；实际有多少填补未记录，不能定量断言影响大小。
- 先比较各层的CV成绩再选最佳层，是用同一批验证结果做模型选择；没有额外外层CV或最终盲测，最佳层分数有选择偏乐观风险。

建议写“按篇章分组的探索性交叉验证，时间窗口使用当前及历史状态”，不要一口气保证“零泄露／完全独立泛化”。若要保留严格说法，需要按训练折估计μ和填补参数，并用独立外层选择层号；当前报告无法替代这些检查。

回归CV的R²是`1−SSE/SST`（代码把负值截为0），r是各折相关系数平均，两者**本来不严格互为平方**。稿件0.7403与54.78%等小差异不算算错。单变量描述统计的r²才可直接平方。全文还应说清“解释力”是对预测熵的统计预测，不是解释模型多少智能或因果机制。

### 11. ROUTINE/HARD是少量读题文本对照，不能当作已观察模型内部推理分叉

代码没有让模型解题生成：`run_single_text`一次前向读输入题面，指标取中后层均值，再跨token聚合。每类每种语言6条，语体、长度、词汇不同，未做配对控制；case JSON里的n_tokens也不是独立样本数。

正文描述“念顺口溜／开始烧脑／吸收新逻辑分支”可作直觉，但应先写明**读题前向、每组6条、描述性差异**。较高的谱熵只能说明这一投影窗口中的谱更分散，不能证明每一步都创造全新正交分支、或者已在正确推理。

尤其Qwen英文HARD的球面步长**反而增大**，GPT中文HARD的熵和方向有效秩都略降。不能把只挑的语言结果说成所有语言、所有困难任务的统一机制。
