# 296 期高风险断言核查表

| 初稿断言 | 证据层 | 审核结论 | 正文处理 |
|---|---|---|---|
| DLL 是 DLSS 5 神经渲染运行时，版本 310.8.0.0 | 本地版本资源；新闻发现记录；NVIDIA 官方 DLSS 5 功能说明 | 支持 | 保留，改成“尚未正式发布但已交合作开发商接入” |
| 社区数小时接入十余款游戏 | RenoDX 社区产物；多家媒体观察 | 支持事件规模，不代表官方集成质量 | 保留“非官方”，不拿画质与性能外推成品 |
| DLSS 1—4 都只负责省算力 | NVIDIA 官方产品历史 | 不支持；Ray Reconstruction 已是画质重建 | 改成“大家最熟悉的是超分和帧生成”，承认光线重建 |
| RTX 5070 Ti 在 Control 4K 从 71 FPS 降到 35 FPS | 单组社区测试，经媒体转述 | 可作为早期观察，不是标准基准 | 保留数字，补测试边界 |
| RTX 4090 从 130 降到 82，掉约 58% | 来源不清；算术错误 | 不支持，正确降幅约 37% | 删除 |
| DLL 自包含模型权重和 GPU 核心 | 本地 PE 分段、资源树、字符串 | 支持 | 保留并改成实测数字 |
| `.rsrc` 的 141 MB 是权重加 GPU 核心 | 本地 PE 资源树 | 错；其中 140.85 MiB 是单独的 `WEIGHTS_HT`，GPU 核心主要在 `.data` | 重写第四章 |
| 模型有精确 1.48 亿参数 | 权重块大小 + FP8 核心名 | 只能估算量级 | 改成“约 1.48 亿参数这个量级”并写出误差来源 |
| 模型是 U 形 Transformer | 本地内部符号 | 部分支持；能看见 Swin/ViT、卷积、上下采样和跳连，不能还原完整图 | 改成“U 形混合网络骨架” |
| 40 系补丁证明模型与 GPU 架构解耦 | 模组作者说明；RTX 4080 外部验证 | 说过头；只证明 Blackwell → Ada 可复用权重 | 收窄到这一次移植 |
| DLSS 5 DLL 没有许可证 | 同目录许可证原文 | 错 | 改成专有许可，明确分发授权与逆向禁令 |
| FSR 4 误传后在所有法域都合法且不可撤回 | MIT 文本；AMD 误传声明；媒体法律判断 | 法律结论过满 | 保留 MIT 事实，不替法院判授权效力 |
| AMD 到 2026 年仍未公开 FSR 4 SDK | AMD GPUOpen 当前仓库与 4.1.1 文档 | 已过时 | 更新为正式进入公开 SDK，但生产接入仍要求签名二进制 |
| A 卡技术上做不到，做出来也一定不能用 | 当前没有公开 AMD 移植 | 无法由“尚无人完成”推出物理不可能 | 改成格式、结构、后端和实时优化四道门槛 |
| AMD FSR 有与 DLSS 5 对标的功能 | AMD FSR SDK 当前功能表 | 不支持；当前公开项为 ML 超分与帧生成 | 正文明确两者没有直接对位 |
