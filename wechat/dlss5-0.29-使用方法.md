DLSS5@AMD RDNA4 0.29 使用方法：三个包怎么选、怎么装，超过 1080P 也能开了

━━━━━━━━━━━━━━━━━━━━

◆ 这篇只讲怎么装

━━━━━━━━━━━━━━━━━━━━

DLSS5@AMD RDNA4 的 0.29 版出了三个包。这篇不讲原理，只讲各自给谁用、怎么装、装完怎么看它在不在工作，下载链接直接放文中。

先说这个项目是什么，一句话：**把 NVIDIA 的 DLSS 5 神经渲染网络（DLSSNR）搬到 AMD RX 9070 XT 上跑。** 网络不是我们训的，权重来自用户自己机器上的 `nvngx_dlssnr.dll`；我们做的是把它的 71 块网络逐块逆向、用 AMD 的矩阵指令重写、再接进游戏的渲染管线。目前的形态：游戏先低分辨率渲染，我们的网络处理这一帧，再交给 FSR 放大到显示分辨率。

0.29 相对上一版有两件事：

1. **超过 1080P 的输入不再拒绝。** 以前渲染分辨率一超过 1920×1080，左上角就提示 UNSUPPORTED，网络不干活。现在按比例缩到 1080 档跑网络，再按原版 codec 的合成方式还原到原分辨率——原分辨率画面是底，网络输出只做亮度和颜色的引导，不是把 1080P 的图简单拉大。《剑星》2K 开 Native AA 实测 44 帧。
2. **六项逐位无损的内核优化**，整网大约快 7%，《剑星》900P 简单场景最快接近 60 帧。"逐位无损"的意思是输出和上一版每一位都一样，只是更快。

◆ 先选包：三个包对应三种接法

━━━━━━━━━━━━━━━━━━━━

三个包是三种把网络接进游戏的方式，**只装一个**，别混装。

**1. OptiScaler 常规版** —— 适合本身就支持 DLSS 的游戏（《剑星》《匹诺曹的谎言》这类）。原理：游戏以为自己在调 DLSS，OptiScaler 把这个调用截下来转给 FSR，我们的网络插在中间。这是主力包，大多数人用这个。
下载：https://pan.quark.cn/s/209e04e7acaf

**2. Magpie 便携版** —— 适合游戏本身不支持 DLSS/FSR 的情况。Magpie 是个窗口放大工具，它抓游戏窗口的画面，我们的网络处理完再放大到全屏。什么游戏都能试，代价是没有游戏内部的运动向量，效果不如第一种。
下载：https://pan.quark.cn/s/fe1b6af36cad

**3. OptiScaler-REFramework 版（RE9 专用）** —— 只给《生化危机 9 / Resident Evil Requiem》。这个游戏提交命令的方式特殊，常规版接不进去，用的是 TheAutomatic 改的 OptiScaler 宿主加我们的 runtime。别的游戏别用这个包。
下载：https://pan.quark.cn/s/505d38a63a85

三个包都是**完整包**（每个三四百 MB，模型权重、48 个 HIP 内核、配置全在里面），不是补丁，不需要先装旧版。

━━━━━━━━━━━━━━━━━━━━

◆ 硬件和驱动

━━━━━━━━━━━━━━━━━━━━

- 显卡：**RX 9070 XT 实测**。包里同时带了 gfx1200（9060 系列）的内核，但我们手上没有 9060，靠反馈。RDNA 3 及更早不行——用的是 RDNA 4 才有的 FP8 矩阵指令。
- 驱动：需要 AMD 驱动里带 `amdhip64_7.dll`（HIP 7）。当前正式版驱动已经带了；如果左上角出现 INIT FAILED，先查 `DLSS5-AMD\logs` 里的日志，十有八九是驱动没这个文件。
- 不需要 Windows 开发人员模式，不需要任何 SDK。这是 0.20 换 HIP 之后的好处。
- 显存：网络本身占约 1.2 GB。

━━━━━━━━━━━━━━━━━━━━

◆ 装：OptiScaler 常规版

━━━━━━━━━━━━━━━━━━━━

1. **完全退出游戏。** 备份游戏目录里已有的 `dxgi.dll`、ReShade 和本项目的旧配置（如果之前装过）。
2. 把包里**全部文件**解压到游戏实际运行的 EXE 旁边——注意有些游戏的 EXE 在 `Binaries\Win64` 这种子目录里，不是游戏根目录。只复制 DLL 不行，权重和内核都在 `DLSS5-AMD` 目录里。
3. 进游戏，画质设置里**选 DLSS 作为超采样**。OptiScaler 会把它转给 FSR 后端，我们的网络在中间。
4. 左上角看状态行：`DLSS5 ON 1707x961 -> FSR 2560x1440` 这种格式，前面是网络看到的渲染分辨率，后面是输出分辨率。写着 ON 就在工作；INITIALIZING 是前几秒在加载权重；UNSUPPORTED 说明输入的格式不对（不是尺寸，0.29 起尺寸不限）。
5. 热键：**F6** 开关神经处理（对比画面最直接的办法），**Insert** 打开 OptiScaler 菜单，**Home** 打开 ReShade。可能和游戏自己的热键撞，撞了改配置。

分辨率怎么选：网络按输入自动选三档，≤1280×720 走 720 档，≤1600×900 走 900 档，其余走 1080 档；超过 1920×1080 缩到 1080 档再还原。2K 屏上，FSR 平衡档输入约 900P，是画质和帧率的折中；开 Native AA 输入就是 2560×1440，走的是新的缩放路径。

━━━━━━━━━━━━━━━━━━━━

◆ 装：Magpie 便携版

━━━━━━━━━━━━━━━━━━━━

1. 解压到一个**独立目录**，运行里面的 `Magpie.exe`。不要往正在运行的旧版上覆盖。
2. 游戏设成**窗口模式**。窗口不超过 1920×1080 时按能装下的最小档处理；超过则缩到 1080 档再还原。
3. 在 Magpie 里选包内自带的 DLSS5 效果组，顺序是：FSR3_SR（这是我们网络的入口，保持输入尺寸 1 倍）→ FSR4 放大 → XeSS 帧生成。
4. **Alt+Shift+A** 启动/停止缩放，**F6** 开关神经处理。
5. AMD 光流只在第一项开；后面 FSR4 和 XeSS 的光流选 None，不然两层光流叠一起会糊。

━━━━━━━━━━━━━━━━━━━━

◆ 装：RE9 专用版

━━━━━━━━━━━━━━━━━━━━

1. 完全退出游戏，备份已有 MOD，全部文件解压到 `re9.exe` 旁边。
2. 从旧版升级的，**必须**把根目录和 `_storage_` 目录里的旧 `dlss5-amd.addon64`、`re9-present.addon64` 和旧观察器 addon 移走，不然会重复处理。
3. `_storage_` 里如果已经有 `dxgi.dll`、`LmxxfNrRuntime.dll`、`OptiScaler.ini`，用包里的同名文件一起替换。**宿主 dxgi.dll 和 runtime 必须配套**，不要和常规版混装。0.29 的宿主和 0.28.1 相同，runtime 是新的，两处都要换。
4. 包里带 REFramework 的 `dinput8.dll`；已经装了别的 dinput8 模组的先处理冲突。
5. 游戏里选 DLSS 超采样。建议先 2K 输出、平衡档、关帧生成试，稳了再开帧生成。
6. **F6** 开关神经处理，**Insert** 打开 OptiScaler/REFramework 菜单。Detail strength 和 Colour strength 在菜单里调，范围 0～1；颜色强度调低会连带削弱材质效果，不只是饱和度。

这个包实测过的范围：9070 XT 数值回归、曝光对照、主菜单连续运行、2K 无边框输出、Native AA。完整流程的画质、切场景、帧生成还需要更多实玩反馈。HDR 输出没验证。

◆ 配置文件：几个可能想改的开关

━━━━━━━━━━━━━━━━━━━━

常规版和 Magpie 版的配置在 `DLSS5-AMD\native-game-flags.txt`，一行一个键，改完重启游戏生效。RE9 版的配置主要在 `OptiScaler.ini` 的 `[DlssNr]` 节，只有 `DLSS5_FIT_LARGE` 这一项它也读 flags 文件。

- `DLSS5_FIT_LARGE=1`：超过 1080P 的输入缩到 1080 档处理。改成 0 就回到旧行为（超限不处理）。
- `DLSS5_NETWORK_HEIGHT=auto`：按输入自动选档。可以强制 `720`、`900`、`1080`。
- `DLSS5_SHOW_FPS=1`、`DLSS5_NOTICE=2`：左上角的帧率和状态行，不想看设 0。
- `DLSS5_FIT_INPUT=1`：小于档位的输入按比例适配到网络面（0.15 起就有），别关。
- 跳层和自适应复用：默认保留原有的跳层，自适应复用默认关。复用是有损的，想试的看仓库 `scripts/CONFIGURATION.md`。

━━━━━━━━━━━━━━━━━━━━

◆ 装完怎么确认它真的在干活

━━━━━━━━━━━━━━━━━━━━

最直接的办法是 **F6 来回按**：神经处理关掉的一瞬间，远处的细节和材质会明显糊掉、噪点上来；打开又回来。状态行的 ON/OFF 跟着变。

帧率：`DLSS5_SHOW_FPS=1` 显示的是网络自己的帧率，不是游戏帧率。9070 XT 上的参考数字：《剑星》900P 简单场景接近 60，1080P 约 40，2K Native AA 约 44。比这低很多，先看是不是别的东西在抢显卡。

出问题的时候看 `DLSS5-AMD\logs\` 目录（常规版和 Magpie 版）或 `OptiScaler.log`（RE9 版），报 issue 时把最后几十行贴上，加上显卡、驱动版本、游戏、分辨率和超采样档位：https://github.com/lmxxf/dlss5-on-amd-9070xt-porting/issues

◆ 已知边界

━━━━━━━━━━━━━━━━━━━━

- **超宽屏（21:9）**：理论上走的是同一条缩放路径，网络面上下留黑边，但我们没有超宽屏，没实机验证。有的读者试了请反馈，这正是 issue #6 提的需求。
- **9060 系列**：内核带了，没机器测。
- **Magpie 路线没有游戏内部的运动向量**，时序效果弱于常规版，这是原理决定的。
- **常规版每帧重置历史**，FSR 的时序处理正常开着。
- 帧率不承诺固定提升，各游戏差别大。

仓库 README 新加了一节"现在的包怎么编"，一张表把包里每个文件对到源码和命令：addon 在 Linux/WSL 上用 MinGW 交叉编译，48 个 HIP 内核在任意一台装了 AMD 驱动的 Windows 上用仓库自带的小编译器编（不需要显卡、不需要 HIP SDK），RE9 的宿主和 runtime 有单独的准备脚本。`shaders/` 目录这次也拆成了两层：顶层 12 个是现在的包还在用的 D3D12 胶水 shader，`dx12-network/` 是 0.15 之前那套 DX12 网络实现，留作逐位参考。

仓库：https://github.com/lmxxf/dlss5-on-amd-9070xt-porting

三个包的 SHA256 都在各自 `.zip.sha256` 文件里，包内有 `SHA256SUMS.txt` 可以逐文件核对。
