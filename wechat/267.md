◆ 为什么工作很多年之后要重修线性代数

━━━━━━━━━━━━━━━━━━━━

先交代这个系列的起因，是一件挺丢人的事。

这个号写了两百六十多期，"矩阵的秩"这个词出现过几十次——MLA 的低秩压缩、LoRA 的秩 8 补丁、"满秩是假象"……写的时候都挺顺。直到前几天我才发现：我一直把"秩"模模糊糊地记成"某个方向上的强度"。

这是错的。强度是**奇异值**的事，秩是**方向的个数**——两个完全不同的概念，我混着用了两年，居然一直没露馅。没露馅的原因也简单：我只是在"用这个词"，从来没动手算过一个矩阵的秩。

大学是学过线性代数的。但你应该还记得那门课的样子：定义、定理、习题，行列式展开算得昏天黑地，从头到尾没有人告诉你这些东西在真实世界里是谁。学完就忘，因为那是一座空中楼阁——地基、钢筋、水泥都给你了，就是没告诉你楼盖在哪。

现在情况不一样了。**大模型是人类历史上最大的线性代数应用现场**：embedding 是向量，attention 打分是点积，每一层是矩阵乘法，LoRA 是低秩近似，微调是奇异向量的旋转。当年课本上每一个悬空的概念,如今都有一个具体的、正在烧着几亿美元电费运转的化身。

所以我让 Claude 帮我排了一条复习路径：从向量和点积起步，一路铺到 SVD 收官，十二站，每一站的概念都钉在大模型的真零件上——秩钉在 LoRA 上，特征值钉在损失曲面上，低秩近似钉在 MLA 上。比培训班好使：培训班教你调 API，这条路教你看懂 API 底下那台机器。

按这条路径开这个系列，规矩三条：

1. **不定期学习，每期只讲两个话题**——想学的时候就学，宁可慢，不许堆
2. **每个概念都落到大模型的具体场景上**——不再盖空中楼阁，这次先看楼，再看钢筋
3. **每个话题带一道五分钟手算题**——全是 2×2、3×3 的尺寸，纸笔就够。我这次学乖了：不动手算一遍的概念，用十年也还是模糊的

这不是教程，是复盘。我数学差，写这个系列就是逼自己把当年糊弄过去的地基一块一块重新浇一遍。你要是和我一样——AI 文章读得懂个大概，一碰到"投影到低维子空间"这种话就开始飘——那我们正好一起补。

◆ 话题 1：向量——一组数当成一个东西

━━━━━━━━━━━━━━━━━━━━

课本的定义是"既有大小又有方向的量"，配一个带箭头的线段。这个画面在二维、三维里没问题，到了大模型的 4096 维就彻底没用了——没人能想象 4096 维的箭头。

换一个能用一辈子的理解：**向量就是一组数，被当成一个东西**。

一个 4096 维向量，就是 4096 个旋钮的一个档位组合。调音台见过吧——几十个推子，每个推子一个位置，所有推子的位置合起来是"这一首歌的调音方案"。方案是一个整体：存的时候一起存，比较的时候一起比较。4096 维向量就是一张有 4096 个推子的调音台快照。

"维度"这个被神秘化了很久的词，在这里就是**旋钮的个数**，没有别的意思。

**它在大模型里是谁：到处都是。**

- **embedding**：模型的词表里每个 token 配一行数——一个 token 就是一个向量。"猫"在模型内部不是汉字，是一张几千个旋钮的档位表
- **残差流**：一个 token 走过模型每一层时，随身带着一个几千维的向量（DeepSeek V4 Flash 是 4096 维——这台机器我们本地跑着、配置逐项核过，全系列拿它当标本），一路被各层修改。第 191 期测的"隐状态轨迹"，轨迹上每个点就是一个这样的向量
- **模型"思考"的基本单位**：说"模型在高维空间里处理语义"，翻译成人话就一句——它在对一些几千维的向量做运算

向量的运算，课本教了加法和数乘，都是**逐旋钮进行**的：

- **加法**：两张档位表对应位置相加。大模型里真有人这么用——把"愤怒"方向的向量加到残差流上，模型的输出真的会变得暴躁（steering，激活转向）。语义是可以做加法的，这是 word2vec 时代"国王 − 男人 + 女人 ≈ 女王"背后的操作
- **数乘**：整张表统一乘一个倍数，方向不变，力度变。steering 时乘的那个系数，就是"掰多狠"

────────────────────

💡 手算一：两分钟，热身

a = (1, 2, 2)，b = (2, 0, 1)。算 a + b 和 2a。

a + b = (1+2, 2+0, 2+1) = (3, 2, 3)
2a = (2, 4, 4)

就这么简单。但注意一件事：**你刚才把三维空间里的两个点合成了一个新点**，而"愤怒向量加进残差流"在 4096 维里做的就是这个动作，一模一样，只是旋钮多。手算的意义不是难度，是让"逐旋钮相加"这四个字从概念变成肌肉。

────────────────────

单个向量能干的事就这么多。有意思的事从两个向量的互动开始——它们互动的最基本方式，就是下一个话题。

◆ 话题 2：点积——对齐程度的一个数

━━━━━━━━━━━━━━━━━━━━

两个向量，逐位相乘再全部加起来，得到**一个数**——这就是点积：

```
a · b = a₁b₁ + a₂b₂ + a₃b₃
```

先把学名和一个近亲交代清楚，这俩极易搞混。点积（dot product），教材里也叫**内积**或数量积，符号是中间一个实心点。它有个长得很像的近亲：**逐元素积**（element-wise product，学名哈达玛积，Hadamard product），符号 ⊙——前半步一模一样（逐位相乘），差别只在最后**加不加起来**：

```
(1, 2, 2) · (2, 0, 1) = 2 + 0 + 2 = 4        # 点积：加起来，坍成一个数
(1, 2, 2) ⊙ (2, 0, 1) = (2, 0, 2)             # 逐元素积：不加，还是个向量
```

大模型里两个都是常客，分工分明：点积负责"打分"（要一个数），逐元素积负责"逐通道开关"（要保住向量身材，每个通道各管各的）——第 264 期（ https://mp.weixin.qq.com/s/W6CUq0xrJP3MdPBXw56v4A ）对照 V4 的 SwiGLU 和 K3 的 SiTU-GLU 时，两家公式里都有一步 gate ⊙ up，门向量逐位捏内容向量，用的就是后者。当年课本只教矩阵乘法不教这些符号，但现在的模型代码里它们俩出镜率极高，值得在第一期就分清。

课本接着会给几何版本：a · b = |a| × |b| × cosθ，θ 是两向量的夹角。两个公式算出来是同一个数，这件事本身就值得停一秒——**左边是纯算术（逐位乘加），右边是纯几何（长度和夹角），它们永远相等**。这是线性代数全部魔法的缩影：算术和几何是同一件事的两种记法。

点积的读法：**它量的是"对齐程度"，被两个长度放大过。**

- 同向 → cosθ = 1，点积最大
- 垂直 → cosθ = 0，点积为零——**互相不搭理**
- 反向 → cosθ = −1，点积最负

注意最后一条：cos 相似度是**带符号用的，不取绝对值**——负号本身是信息。0 和 −1 是两种完全不同的态度：0 是陌生人（无关），−1 是拉黑（主动排斥）。attention 里负分 token 经过 softmax 拿到的权重比无关 token 还低，模型在说"这个不但没用，还要躲着它"；steering 里想抑制某个特征，就把那个方向**反着加**（h − α·v），去毒化的实际操作就是这么干的。

顺手拆一个地雷：**反向不等于反义词**。"热"和"冷"的 embedding，cos 往往是正的——它们总出现在同一类句子里，语义空间里"相反的概念"经常高度相关（毕竟聊的是同一件事：温度）。方向的正反是"这个特征在场还是缺席"的对立，不是字典里的反义。

如果只要对齐程度、不要长度掺和，就先把两个向量各自除以自己的长度（归一化），再点积——得到的就是 **cos 相似度**，范围钉死在 −1 到 1。

**它在大模型里是谁：attention 的打分器。**

attention 的第一步，是拿当前 token 的 query 向量 q，去和每个历史 token 的 key 向量 k 打一个分——**这个分就是点积 q · k**，一次点积给一个数，分高的 token 在后续加权里说话声音大。所谓"注意力"，第一现场就是这么一排点积（后面还要除个缩放系数、过 softmax，那是第 2 期矩阵乘法的戏份）。

一个模型一次前向要做多少次这样的打分？每层每个头、每个 token 对每个历史 token 各一次——**万亿次量级的点积**。你大学里觉得无聊的那个"逐位乘加"，是现在全世界 GPU 上跑得最多的运算，没有之一。

另一个化身是**检索**。RAG 把文档和问题都变成向量，"找最相关的文档"就是"找 cos 相似度最高的向量"。第 170 期（ https://mp.weixin.qq.com/s/ozog4BkollQAc7wzUkME0g ）讲过表征都活在球面上——球面上比远近，用的就是夹角。

💡 手算二：五分钟，有一个埋伏

第一题：a = (1, 2, 2)，b = (2, 1, −2)。算 a · b。

a · b = 1×2 + 2×1 + 2×(−2) = 2 + 2 − 4 = **0**

点积为零——这两个向量**垂直**。你不画图、不测角度，三次乘法两次加法就断定了两个三维向量互相垂直。这就是"算术和几何相等"的兑现：垂直这个几何事实，被算术直接算出来了。

第二题：a = (1, 2, 2)，c = (2, 2, 1)。算 cos 相似度。

a · c = 2 + 4 + 2 = 8
|a| = √(1+4+4) = 3，|c| = √(4+4+1) = 3
cos = 8 / (3×3) = 8/9 ≈ 0.89

0.89，很接近 1——这两个向量高度对齐。如果它们是两个 token 的表征，attention 会给这一对打高分。

第三题（我自己算这道时在分母上栽过：**两个长度是相乘，不是相加**——几何版公式 a · b = |a| × |b| × cosθ 里根本没有加法）：a = (1, 2, 2)，b = (2, 0, 1)，算 cos 相似度。

a · b = 2 + 0 + 2 = 4
|a| = 3，|b| = √5 ≈ 2.24
cos = 4 / (3 × 2.24) ≈ 0.6

三对向量摆在一起，"对齐程度"就有了刻度：**0（垂直，陌生人）→ 0.6（约 53°，有点关系但不亲）→ 0.89（高度对齐，近亲）**。attention 打分打出来的那一排数，读法就是这把尺子。

────────────────────

刚才那个"点积恰好为零"的埋伏，其实通向一个比习题大得多的事实——它是理解大模型为什么装得下那么多语义的钥匙。

────────────────────

💡 高维空间的一个反直觉事实：随便挑两个方向，几乎总是垂直的

二维平面里随手画两个向量，垂直是小概率事件。但在 4096 维里反过来：**随机挑两个向量，它们几乎一定近似垂直**（cos 相似度以极高概率贴着 0）。维度越高，"垂直"越是常态，"对齐"越是稀罕事。

这件事对大模型是天大的好消息：垂直=互不打扰，所以 4096 维空间能塞下的"互不打扰的语义方向"远超 4096 个（各方向之间允许一点点不垂直的话）。

为什么是"远超"而不是刚好 4096？**严格垂直是刚性预算**：两两严格垂直的方向最多 4096 个，塞一个占一个坐标槽，满了就是满了。但放宽到"近似垂直"（允许 cos 有一点点不为零），容量不是线性涨，是指数爆炸。

直觉是这样的：塞新方向时要避开的，是每个已有方向周围一小圈"太对齐区"。而维度越高，这样一顶"帽子"占整个球面的比例越小——4096 维球面上小到天文数字分之一。帽子小到这个程度，塞几百万个方向之后，安全区依然漫山遍野。

先把"随便两个向量有多垂直"说定量。4096 维里随机抓两个向量，cos 的分布是一条以 0 为中心的钟形曲线，典型抖动（标准差）约为 1/√4096 ≈ **0.016**——维度的平方根分之一，这就是"高维里垂直是常态"的定量版本。绝大多数随机对的 cos 落在 ±0.03 以内；晃出 0.05 是三个标准差外的稀罕事，千分之几；晃出 0.1 是六个标准差外，天文数字分之一，基本见不到。

有了这个抖动尺度，"容差"就好理解了——它是我们在典型抖动之外画的警戒线。数学上这是 Johnson–Lindenstrauss 引理那一族的结论：随机塞向量、要求两两不撞警戒线，能塞的个数按 e 的（容差平方 × 维度 ÷ 2）次方量级增长。这笔账纸笔就能算——警戒线画在 0.1（六倍抖动）：

0.1² × 4096 ÷ 2 = 20.48，e 的 20.48 次方 ≈ 10 的 8.9 次方

**约 8 亿个方向，是刚性预算 4096 的 20 万倍**（数量级下界，不同版本的证明常数略有出入，当量级读）。

更有意思的是把警戒线收紧到 0.05（三倍抖动）再算一遍：指数只剩 0.05² × 4096 ÷ 2 = 5.12，e 的 5.12 次方约 167 个——比 4096 还小！这不是空间缩水了，是要看清这个公式到底在算什么：**它算的不是"空间能装多少"，是"随机乱扔能扔多少"**。手工把 4096 个坐标轴摆好，cos 全是精确的 0，任何容差下都合法——4096 永远是保底。而乱扔靠的是"撞警戒线是稀有事件"：警戒线在六倍抖动处，扔亿级个都撞不上；收到三倍抖动处，单对撞线概率就到了千分之几，扔几百个就该撞了。

两种策略在这里换庄——容差紧，手工摆放赢；容差够宽，乱扔指数爆炸碾压。而模型训练学出来的方向更接近"乱扔加微调"，走的正是宽容差那条路：**容忍一点串扰，换回指数级的容量，是划算到不容拒绝的交易。** 这也是叠加假说（superposition）的几何地基：模型确实在同时表征远超维度数的特征，代价只是特征间一点点极小的串扰。

模型敢把几万个概念塞进几千维空间，靠的就是高维几何的这条地租优惠。这也是为什么 attention 打分有区分度——大部分无关 token 的 q·k 天然趴在 0 附近，真正相关的那几个才冒头。

◆ 本期小结

━━━━━━━━━━━━━━━━━━━━

两个概念、两道手算，落了三个锚：

- **向量 = 一组数当成一个东西**，维度 = 旋钮个数。embedding 的每一行、残差流里的每个 token，都是它
- **点积 = 对齐程度 × 两个长度**，算术版和几何版永远相等。attention 打分的第一现场就是一排点积
- **高维里垂直是常态**——这条地租优惠是模型敢把万千语义塞进几千维的底气

地基浇了第一块。这两个概念看着小，但往后系列里每一个大家伙——矩阵、秩、SVD——剥到最后都是它们俩在干活。

◆ 技术名词速查

━━━━━━━━━━━━━━━━━━━━

| 术语 | 一句话解释 |
|------|-----------|
| 向量（vector） | 一组数被当成一个东西；n 维 = n 个旋钮的档位组合 |
| 维度（dimension） | 旋钮的个数，没有更神秘的含义 |
| 点积（dot product，内积） | 逐位相乘再求和，得一个数；等于对齐程度乘两个长度 |
| 逐元素积（Hadamard 积，⊙） | 逐位相乘不求和，出来还是向量；模型里管"逐通道开关" |
| cos 相似度 | 归一化后的点积，只留对齐程度，范围 −1 到 1 |
| 归一化（normalize） | 向量除以自己的长度，只留方向 |
| embedding | 词表里每个 token 对应的那行向量 |
| query / key | attention 里打分的双方：q 来自当前 token，k 来自历史 token |
| steering（激活转向） | 把某个语义方向的向量加进残差流，直接改变模型行为 |

━━━━━━━━━━━━━━━━━━━━

**"秩"这个词我用了两年，前几天才发现自己一直记错——没露馅，是因为从来没动手算过。**

**左边是逐位乘加，右边是长度乘夹角，两边永远相等——线性代数全部的魔法，是算术和几何本是同一件事。**

**在 4096 维里，垂直是常态，对齐是稀罕事——这是模型敢把万千语义塞进几千维的全部底气。**
