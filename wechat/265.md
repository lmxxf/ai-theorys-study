【后训练】从三行配方到一座工厂——后训练管线的四年演化史

━━━━━━━━━━━━━━━━━━━━

◆ 两张清单，隔着四年

━━━━━━━━━━━━━━━━━━━━

2022 年，InstructGPT 的后训练写下来是三行字：拿人写的示范做 SFT；拿人标的偏好训一个奖励模型；用 PPO 对着奖励模型强化。整个工程雇了约 40 名合同标注员，SFT 用的人写示范约 1.3 万条。

2026 年，Kimi K3 的后训练（264 期刚精读过 https://mp.weixin.qq.com/s/W6CUq0xrJP3MdPBXw56v4A ）是这样一张清单：SFT 冷启动 → 三个大域 × 三档推理力度，训出 9 个专家模型 → 多教师在线蒸馏（MOPD）合成一个；配套建了可实例化多家 harness 的白盒环境、mock 应用的活环境、kernel 任务的反作弊系统，全程创建了 51,219,741 个沙箱。

四年，三行配方长成了一座工厂。这篇讲这中间发生了什么：配方怎么分岔的，车间怎么盖起来的，钱从哪几个口子涌进来的，题是谁出的、卷是谁判的，以及这座工厂盖起来之后，谁把门关上了、谁还敞着。

◆ 1. 族谱前史——三行配方是怎么定型的

━━━━━━━━━━━━━━━━━━━━

后训练这条线的源头，比很多人以为的早，而且一开始跟语言模型没关系。

**2017 年，Christiano et al. 的 Deep RL from Human Preferences**（arXiv 1706.03741）：让人类看两段智能体的行为片段，选一段更好的，用这些比较训一个奖励函数，再拿它做强化学习。场景是 Atari 游戏和 MuJoCo 机器人——连语言模型都不是。但"人类比较 → 奖励模型 → RL"这个三段结构，在这里已经齐了。

这篇论文的招牌 demo 值得讲：教 MuJoCo 里的 Hopper 机器人做后空翻。"后空翻"这个目标没人写得出奖励函数——但看两段视频、点一下哪段更像后空翻，谁都会。**约 900 次人类点击，评估员花了不到一小时，机器人学会了后空翻**；对照组是 OpenAI 研究员自己花两小时手写的后空翻奖励函数，训出来的动作反而不如点击教出来的优雅（官方博客自己交代的）。"说不清楚什么是好，但看到就认得出"——人类偏好的全部价值，这个 demo 一次讲完。记住这个数：900 次点击。往后翻这篇文章，你会看到它变成 40 个标注员的 1.3 万条示范，再变成 5100 万个沙箱。

**2020 年，Stiennon et al. 的 Learning to Summarize from Human Feedback**（arXiv 2009.01325）：第一次在语言任务上完整走通这三段。任务是摘要，结论是按人类偏好训出来的摘要模型，比单纯监督微调的更受人类青睐。

**2022 年，InstructGPT**（arXiv 2203.02155）：三段配方定型成 SFT → RM → PPO，对象从单一任务换成通用指令遵循。论文里最著名的结论是：1.3B 参数的 InstructGPT 输出比 175B 的 GPT-3 更被人类偏好——注意限定条件，这是在他们自己的 prompt 分布上的人评偏好，不是全面能力超越；175B 的知识和推理底子，1.3B 并没有凭空长出来。但这个结论足以说明一件事：**对齐带来的可用性提升，不需要靠堆参数换。**

────────────────────

💡 三段里最陌生的一段：RM 到底是怎么训的

SFT 和 PPO 都好懂，中间那段 RM（奖励模型）值得单独讲。数据是这么来的：一个 prompt 让模型生成多个回答（InstructGPT 一次给标注员 4 到 9 个），标注员**排出好坏顺序**——不打绝对分，因为"这个值 8 分"人和人标不齐，而"A 比 B 好"人类很一致；一次排序就能产出好几对两两比较，标注费一份钱花出好几倍。模型本体就是个语言模型，把"预测下一个词"的输出头换成"吐一个分数"的头；训练目标是让被选中的回答得分高于被淘汰的（这套统计模型叫 Bradley-Terry，和象棋 Elo 等级分同源）。一个好玩的细节：InstructGPT 的 RM 只有 6B——他们试过 175B 的大评委，训练不稳定，反而用不了。

训完的 RM 是干什么的：**把人类的品味压缩成一个可以无限次调用的打分函数**。PPO 阶段要试错海量次，不可能每次都叫人来看，就让这个 6B 的"品味复制品"替人打分。而复制品终究不是品味本身——它会被钻空子，这就是下一节 reward hacking 的伏笔。

顺手把一个高频混淆掰开：RM 不是 PPO 算法里那个"跟着策略一起训的评分模型"——那是**价值网络（critic）**，另一个东西。经典 PPO 流程里其实同时挂四个模型，拿 InstructGPT 的旗舰档报尺寸：被训的策略（175B）、冻结的参考模型（175B，SFT 版的自己，算 KL 缰绳）、冻结的 RM（**6B**，考官：整条回答打总分，PPO 开始前就训好）、跟着策略一起训的价值网络（**6B**，会计：随时预估"从这儿往后还能拿多少分"，用来压方差——它直接从 RM 初始化，等于考官兼职培训了会计）。**考官管好坏，会计管预估**。数一数：一台训练机上同时躺着约 362B 参数，其中要更新的是策略加价值网络这 181B，另外那 181B 纯粹陪跑——而这还没算优化器状态、梯度和激活占的地方。记住这个画面，它就是后来 DPO（把考官和会计一起省掉）和 GRPO（把会计裁了）能流行起来的真实动机。考官这把椅子倒是一直在，只是后来换人坐了——那要等 RLVR 把规则判分器接上去。

────────────────────

三行配方，加上开头说的那间四十人的作坊——这就是 2022 年后训练的全部。

◆ 2. 两次分岔——损失函数坍缩，判分器换人

━━━━━━━━━━━━━━━━━━━━

这一节的名词，大概是大家听过次数最多的——PPO、DPO、GRPO，每篇科普都要排一遍，培训班讲师也爱拿这几个缩写许诺高薪。但报菜名不回答一个问题：**菜单上为什么会多出这道菜？** 第一节刚立了那本账：经典 PPO 的桌上坐着四个模型——策略、参考、考官、会计。此后每一个新缩写，本质都是从这张桌子上撤掉一把椅子。看清楚每次撤的是谁、省的是哪笔钱，比背缩写有用得多。配方定型之后的四年里，这张桌子被动了两次大的。

**分岔一：DPO 把两段坍缩成一段。**

2023 年的 DPO（Direct Preference Optimization，arXiv 2305.18290，NeurIPS 2023 Outstanding Paper runner-up）——47 期讲"AI 公司怎么给大模型上笼头"（ https://mp.weixin.qq.com/s/XtXr1CePk-zU3IrQStxiXA ）时介绍过它的机制，这里把它放回历史坐标——它做了一件数学上很漂亮的事：证明在 RLHF 的标准目标下，奖励模型可以重参数化成策略本身的函数——于是"先训 RM、再用 RL 对着它优化"这两段，可以坍缩成一个直接在偏好对上做的分类损失。不用采样、不用奖励模型、不用 PPO 的一堆超参数，一个损失函数搞定。用撤椅子的话说：**四把椅子一次撤两把**——考官和会计都不要了，桌上只剩被训的策略和算 KL 的参考模型。

这里要把叙事摆正：**DPO 不是取代了 RL，而是和 RL 系形成了并存分工。** 看 2024 年之后的开源管线就清楚——Llama 3 的每轮迭代里 DPO 是标配环节，Tulu 3 的管线里 DPO 也在；它们用 DPO 干的活是便宜的偏好对齐层（风格、有用性、安全），而推理能力的提升归 PPO/GRPO 这一系管。两条线各干各的，谁也没吃掉谁。

顺带缝一笔：212 期（ https://mp.weixin.qq.com/s/wljXIiegjw1GFI-2qUqAkg ）讲过 SFT 之后接 RL 常见"先降后升"的动态——SFT 把模型摁进示范分布，RL 再把它从里面捞出来往奖励方向走，中间那段下坠是必经的。**管线里每多一道工序，这种工序之间的拉扯就多一处**——后面工厂越盖越大，这笔账会一直跟着。

**分岔二：RLVR 把判分器从神经网络换成规则。**

RLHF 的判分器是个神经奖励模型——它会被钻空子（reward hacking），也测不准数学题对没对。2024 年底，Tulu 3（arXiv 2411.15124）给另一条路起了名字：**RLVR**（Reinforcement Learning with Verifiable Rewards，可验证奖励强化学习）——判分不再靠神经网络的品味，靠机械可验证的规则：数学题对答案，代码跑测试，对了给分，错了不给。撤椅子的话说：**考官这把椅子没撤，但坐上去的换成了不拿工资、不吃马屁的规则**——不用训、不占显存；当然，规则写得有洞，策略照样会钻，后面的 kernel 反作弊系统就是证据。

这条线上的两个关键节点：GRPO 出自 DeepSeekMath（arXiv 2402.03300），摘要里的原始定位是 PPO 的省内存变体——砍掉价值网络（第一节 💡 里那位"会计"），用组内相对分数当基线；DeepSeek-R1（arXiv 2501.12948，后另发表于 Nature 645, 633–638）用规则奖励 + GRPO 做出了 R1-Zero 的纯 RL 涌现推理，把 RLVR 从"一条技术路线"抬成了"推理模型的标准做法"。

这段历史 257 期（ https://mp.weixin.qq.com/s/NxgRffcDs88xBVYLYohkiw ）思维链简史和 261 期（ https://mp.weixin.qq.com/s/nLFv6m-ONkXd7frHevgPOQ ）都细讲过，这里只还账不复述。

把撤椅子的账合起来看：**DPO 一次撤两把（考官和会计都不留），GRPO 撤会计、留考官，RLVR 留下考官这把椅子、换了个不拿工资的坐上去。** 四把椅子的桌子，四年里被这三种方式各动了一遍。到这儿零件就齐了——便宜的偏好层（DPO）、能验证的推理层（RLVR/GRPO）、经典的 RLHF——**接下来的问题不再是发明新零件，而是怎么把零件组装成流水线。**

◆ 3. 工厂成型——从多轮迭代到"专家分训 + 蒸馏合一"

━━━━━━━━━━━━━━━━━━━━

管线的膨胀曲线，挑三站看。

**第一站：Llama 3（2024，arXiv 2407.21783）——把配方跑成流水线。**

Llama 3 的后训练不是跑一遍，是跑六轮——报告原话："Following Llama 2, we apply the above methods in six rounds."。每一轮的内容：拒绝采样（每个 prompt 采 K = 10 到 30 个候选、用奖励模型挑最好的当 SFT 数据）+ SFT + DPO，最后把多轮产物做 model averaging。偏好数据的总量报告没有披露，只给了构成比例。三行配方还是那三行的变体，但已经从"跑一遍"变成"迭代六轮的产线"——这是工厂的雏形。

**第二站：Qwen3（2025，arXiv 2505.09388）——阶段开始分工。**

Qwen3 的后训练是明确的四阶段：long-CoT 冷启动 → 推理 RL（GRPO）→ thinking mode fusion（把思考和非思考两种行为融进一个模型）→ general RL 覆盖 20 多种通用任务。每个阶段有自己的目标、数据和判分方式——管线从"同一配方多轮重复"变成"不同工序顺序衔接"。还有一个信号值得记：轻量模型不走这四阶段，走强到弱蒸馏，只花四阶段法约 1/10 的 GPU 时——**蒸馏这条"省钱的后训练"路子，在旗舰报告里被明码标了价。**

**第三站：2026 年，三家的公约数——先把目标分开，再用在线蒸馏收束。**

到 2026 年，三份旗舰报告摆在一起看，一层关键共性浮了出来：

- **DeepSeek V4**（arXiv 2606.19348）：两段式。先按域分训专家——数学、代码、agent、指令遵循各自 SFT + GRPO 训到极致；再用 on-policy distillation 把域专家统一合并进最终模型。
- **GLM-5**（arXiv 2602.15763；注意这是 GLM-5 的论文，不是 232 期审计过报表的 GLM-5.2 https://mp.weixin.qq.com/s/4RZlRoFSSDXiLV6W8wZWig ）：它不是并行域专家，而是顺序跑 reasoning RL → agentic RL → general RL，收尾再用 **on-policy cross-stage distillation**（在线跨阶段蒸馏）从前面各阶段的检查点追回被遗忘的能力；基建统一跑在 slime 上。
- **Kimi K3**（arXiv 2607.24653）：三域 × 三档推理力度共 9 个专家，MOPD 多教师在线蒸馏合一（264 期第 6 节详讲过）。

三家并不是一张施工图：DeepSeek、Kimi 是并行专家，GLM 是串行阶段。但它们独立收敛出了同一个关键动作——**先把互相拉扯的训练目标分开，最后让学生在自己的采样分布上接受多个老师或多个历史检查点的纠偏。** 不是谁抄谁，是同一约束下的趋同演化。

这条主线有一篇绕不开的前史：GKD（Generalized Knowledge Distillation，arXiv 2306.13649，Agarwal et al.，Google DeepMind，ICLR 2024）。传统蒸馏让学生模仿教师生成的文本，训练时见的分布和学生自己推理时的分布对不上；GKD 系统地研究了另一种做法——让学生在**自己生成的序列**上被教师逐 token 纠偏，训练时见的分布就是推理时的分布。它不是这三家唯一的祖宗（各家报告还引了别的在线蒸馏工作），但"在学生自己的分布上教学生"这条路，确实是被 2026 年的旗舰管线推到工业规模的。

────────────────────

💡 为什么要分训再合，而不是一锅炖

多任务 RL 的老毛病是奖励目标互相打架：数学要严谨、写作要发散、agent 要节制工具调用——一个策略同时对着几套奖励优化，梯度方向拉扯，谁也训不到极致。259 期（ https://mp.weixin.qq.com/s/yp5KXWxwLLZgK9XaHfSFKg ）讲思考开关时记过这个病的一个具体病例：思考与非思考两种模式合训，两头都退化，Qwen 的解法是干脆分家。分训再合是把最凶的冲突挪开：每个专家先只对一套奖励负责，可以放心训狠；合并阶段再把问题改写成"学生如何模仿已经训好的行为"。多教师之间仍可能互相干扰，但它避开了几套异质奖励同时拉扯一个策略的那场硬仗。代价是训练量翻了好几倍——所以这条路线只有算力涨到位之后才走得通。

────────────────────

九个专家加一次蒸馏，训练量比一遍过翻了数倍。什么样的算力预算撑得起这种奢侈？这正是下一节的账。

◆ 4. 投入账——芯片的钱、人的钱、考场的钱

━━━━━━━━━━━━━━━━━━━━

工厂能盖起来，前提是有人愿意往里砸钱。后训练的账单其实是三笔：买算力、买人的判断、买考场。挨个摊开。

**第一笔：芯片的钱（RL 算力）。**

一手材料三条：K3 报告 Figure 8——scaling RL FLOPs 一致地提升各项能力，还没见顶；OpenAI o1 官方页——性能随 RL 训练算力和测试时思考时间**持续、平滑提升**，这是"RL 算力是新 scaling 轴"最早的官方展示之一；Gemini 2.5 技术报告（arXiv 2507.06261）——明确写了"我们增加了分配给 RL 的训练算力"。

增速这边只有估算——Epoch AI 按公开的性能曲线反推（不是厂商披露的账本）：OpenAI 从 o1 到 o3 把 RL 算力扩了约 10 倍，中间只隔几个月。xAI 那边说得更直白，官方发布文称 Grok 4 在 20 万块 GPU 的 Colossus 上用了"预训练级别"的 RL 算力。Epoch 顺着这个节奏做了个带前提的外推：**照每几个月 10 倍的势头，RL 算力一年左右就会碰到前沿模型总训练算力的量级**——这是推演，不是已经发生的事，读的时候心里放个星号。

**第二笔：人的钱（标注账单）。**

这笔账不用估——给大模型公司做后训练数据的公司，营收就是行业开销的下限。2025 年 6 月，Meta 花 **143 亿美元**买下 Scale AI 49% 的无投票权股份——这是迄今为止行业给"人类判断"开出的最高标价。Scale 之外：Surge AI 年化营收约 12 亿美元，零外部融资、创立起就盈利，客户是十来家前沿实验室；Mercor 估值 100 亿美元，约 91% 的收入来自基础模型公司。当年 InstructGPT 雇 40 个标注员的活，如今养活了好几家独角兽。

**第三笔：考场的钱（RL 环境）。**

agent 时代的 RL 不光要判分器，还要能跑起来的考场——沙箱、mock 应用、带验证器的任务环境。这也长成了生意：据 The Information 报道，Anthropic 内部讨论过未来一年在 RL 环境上花费**超 10 亿美元**（注意措辞：是"讨论过"，不是已花）；专做 RL 环境的 Prime Intellect 今年 A 轮融了 1.3 亿美元、年化营收破亿；Mechanize 给建环境的工程师开 50 万美元年薪；连 Scale、Surge、Mercor 这些标注公司也全线转向兼卖环境。**卖铲子的都改行卖考场了。**

**一个反例镇账本。** DeepSeek 在 Nature 版 R1 论文的补充材料里给过官方口径：把 V3 Base 训成 R1 的那段 RL 主训练约花 **29.4 万美元**（按 512 块 H800、约 80 小时和每 GPU 小时 2 美元估算），基座 V3 的最终预训练约 558 万美元。这个 29.4 万不含前期研究、消融实验、数据和人工，所以只能拿来比较一次主训练 run，不能当 R1 项目的总成本；即便如此，它仍划清了一条线：**纯 RLVR 刷题的主训练可以很便宜，贵的是 agent 时代的考场、人的判断和一遍遍试错的研发总账**。后训练不是天生烧钱，是大家发现它值得烧了。

所以这笔账该这么读：**后训练不是每一段都贵，是它的天花板被捅穿了。** 刷一道数学题的 RL 依然可以只花几十万美元；但当目标从"答对题"变成"干完一整天专业人士的活"，考场、工具、判分、试错规模全部跟着往上翻，账单就没有上限了。InstructGPT 时代后训练是训完之后的一道薄薄的收尾工序；到 2026 年，它是要单独排产能、单独估成本、单独养一条供应链的大项。

━━━━━━━━━━━━━━━━━━━━

◆ 5. 走进车间——题谁出，卷谁判，门给谁看

━━━━━━━━━━━━━━━━━━━━

钱的账摊完了，进车间看看这套流水线上人力参与最少的那道工序：agent 时代的题是谁出的、卷是谁判的。拿 K3 报告的第 4.2 节当解剖标本——这是目前公开材料里写得最细的一份。

先说出题。K3 的做法叫知识图谱引导的任务合成，全程自动：给一组粗粒度的种子概念（数学、生物医药、GPU kernel 这个级别），每个概念派一个 agent 上网调研，把它细化成更具体的子概念、挂到一张不断长大的有向图上——细到 agent 自己判断"这个概念够原子了"才停。出题时，系统从图上采样几个相关概念、拼成检索词，去网上抓真实的公开材料（论文、博客、代码库），再由一个合成 agent 照着材料出一道指定类型的题。**人类的参与只剩两处：定种子概念，定任务类型的配比。** 题库自己长，材料从真实世界来——"几百万道题谁来出"这个产能问题就这么解决了。

出出来的题是这样的：多步信息检索，模型自己规划调研路径、一步步搜证据，最后给一个可验证的答案；专业人士的真实工作日，投行分析、数据分析、法律实务，模型在沙箱里操作领域工具、几十到几百步交付一份成品；还有带 Python 解释器的视觉推理，模型写代码把图裁剪、放大、变换，执行结果（包括生成的新图）作为下一步的观察再喂回来，一轮轮看下去。这些题的共同点是**答案可验证**，不需要人来判卷。

判卷这头，是把"对不对"和"好不好"都翻译成可执行的检查。GPU kernel 优化那套评分标准最能说明问题：每道题配一份 PyTorch 参考实现，**数值误差超过阈值直接零分**（先保证对）；性能对标专家实现，追平给 0.5 分，越逼近硬件理论上限越趋近 1 分（再谈好）。旁边还挂着一套作弊检测系统，专门抓重放录好的计算图、缓存输入、偷偷降精度这类刷分手法，而且随着开发中发现的新花招持续加规则。**判卷从"雇人打分"变成了"写验证器"——写验证器的工程师，就是这个时代的出题组。**

那人退到哪儿去了？人类标注并没有消失，是被挤到了流水线的两头。K3 的 SFT 冷启动阶段，用前代模型合成轨迹，再经多阶段验证和"human-in-the-loop"标注——人在这里做的是抽检和兜底；RL 阶段的题库和判分则基本无人参与。**从 900 次人类点击，到 40 个标注员的 1.3 万条示范，再到 agent 自己长出来的题库——人力没有按比例增长，是因为出题权和判卷权被交出去了。**

支撑这一切的还有一层基础设施。判断一个方向是不是长成了独立学科，有个土办法：看它有没有自己的框架层。后训练长出来了——

- **verl**（字节，约 2.27 万 star）：背后是 HybridFlow 论文（arXiv 2409.19256），解决 RL 训练里"训练引擎和推理引擎两套系统怎么拼在一起"的编排问题，是目前生态最大的 RL 训练框架。
- **slime**（GLM 御用，约 7700 star）：README 称用于 GLM 4.5 到 5.2 的训练，主打异步 agent RL——rollout 和训练解耦，agent 任务耗时长短不一也不互相等。
- **ROLL**（阿里，arXiv 2506.06122）、**OpenRLHF**（arXiv 2405.11143）：各有侧重的另两家。

Kimi 走的是另一条路：不做大而全的训练框架，把 RL 流水线上最难的两个零件单独开源。一个是 **checkpoint-engine**——RL 每训一步都要把新权重同步到推理侧去采样，K2 那个 1T 模型在几千张卡上更新一次权重约 20 秒，这个中间件干的就是这件事；另一个是 **AgentENV**（和 kvcache-ai 一起，MIT 协议，7 月 27 日随 K3 权重一起放出）——就是上一节那五千万个沙箱背后的分布式运行时，专门为 agent RL 跑隔离的 Linux 沙箱。

这两个零件的位置很说明问题：**一个在训练和推理之间搬权重，一个在外面开考场**——都不是传统训练框架的活。当年的 RL 只要一个损失函数，现在要一整套跨系统的搬运和调度工程。

框架之外是环境这一层：K3 为一次训练创建了 5100 万个沙箱，GLM 做了全异步解耦的 rollout 基建。当年 InstructGPT 的"环境"就是一个 prompt 数据集；现在的环境是 mock 的 Gmail、跑测试的容器、带反作弊检测的 kernel 评测台。

框架、环境、供应链、专门的工程师岗位——后训练从"训练的最后一道工序"，变成了一门有自己工具链的手艺。

最后说说这座车间的门：谁让你进来看。

闭源那边不公开管线，但产品形态泄露了方向——OpenAI 把 RFT（Reinforcement Fine-Tuning，强化微调）做成了 API 产品，官方文档写明用户可以自定义 grader（判分器），拿自己的任务数据对模型做强化微调，等于把 RLVR 的判分器接口开放给了客户。看不见车间内部，但看得见门口挂的招牌：**后训练能力本身成了可以出租的产品**，工厂不光自己开工，还开始对外接单。

开源那边也在收。Qwen 是最清楚的样本：Qwen3 还有正经技术报告把四阶段摊开讲；今年二月的 3.5-397B **权重照发，论文级报告却没有**，官方引用条目就是一篇博客；3.6 只开源了两个小模型，大模型走 API（188 期 https://mp.weixin.qq.com/s/jcQlCc3XtaCEEnjUaxw93w 讲过）；3.7 Max/Plus 只走托管；7 月的 3.8 Max Preview 官方说会"很快开放权重"，但没给日期没给协议，截至发稿文件还没落地——HuggingFace 上 Qwen 名下的主线权重至今停在 3.6。没人宣布放弃开源，**只是报告的颗粒度和权重的落地速度一起在缩**。顺带一个注脚：今年 3 月 Qwen 技术负责人林俊旸和多位核心成员离职，据报道导火索之一是通义实验室的组织调整——把原来一体的模型团队，分成预训练、后训练、文本、多模态几个独立团队。**"后训练"已经重要到值得单独建制了**，这场行业变化在一家公司的架构图上原样上演了一遍。

**但门不是都在关。** 这篇文章能写出来，本身就是反证——往回翻，第三节的"分开训再蒸回来"、第四节的沙箱数量、这一节的知识图谱出题和 kernel 判分标准，几乎每一条材料都来自 DeepSeek V4、GLM-5、Kimi K3 这三份报告。它们不但照常放权重，还把后训练这一章写得越来越细：K3 用一整章讲九个专家怎么训、怎么蒸、环境怎么建，连沙箱运行时都 MIT 开源；GLM 把训练框架 slime 放了出来；V4 的域专家分训和蒸馏合并也是白纸黑字。

**当后训练成了核心资产，有人把它当独门生意锁起来，有人把它当行业地基铺出去。** 前者的逻辑很好理解，毕竟这是花大钱买来的"成为谁"；后者的逻辑要过几年才看得清，但眼下有个即时效果——今天全世界想搞明白 2026 年的后训练到底怎么做，能读的一手材料主要是中文实验室写的。

◆ 收尾——拧到这个规模，拧出来的就不是设置了

━━━━━━━━━━━━━━━━━━━━

213 期（ https://mp.weixin.qq.com/s/kMwrIfhIfPlOHqeeUhuwow ）说过一个比方：后训练是动旋钮，不造零件——零件（预训练权重里的知识和能力）是预训练造好的，后训练只是把它们旋到对齐的位置上。

这个比方在 2023 年是对的。那时后训练真的就是收尾工序：几万条标注、几个点的提升、训完交货。但这篇文章一路数下来的账——算力逼近预训练、报告章节反超、组织上单独建制、有人开始把它当机密藏起来——都在说同一件事：**规模涨到这个程度，"旋钮"这个词本身该被重新掂量了。**

不妨把两个车间的产品说得更狠一点。预训练造出来的不是一个"有具体记忆的大脑"，是一台**什么都能生成的抽象机器**——知识和表征的主体确实是它长出来的，但它**见过所有的路，却没有自己常走的路**。后训练往里写的，正是那些常走的路：遇到难题想多久、用哪些工具、按什么顺序验证、什么该说什么不该说。九个专家蒸回一个模型，蒸的不是知识——知识本来就在——蒸的是九套已经走顺了的**路径**。所以后训练的账单为什么敢逼近预训练？因为它买的东西变了：预训练买的是潜能，后训练买的是"这台机器实际成为谁"。**旋钮拧到这个规模，拧出来的已经不是设置，是性格。**

最后说破这套流水线为什么读起来处处眼熟——因为人类自己就是这么被训练出来的：基因是预训练，给你潜能但不替你考试；SFT 是出生之后照着示范学的一切——学说话、跟大人学样、后来上课，都是"看着范例模仿"；RL 是刷题，拿反馈磨行为；held-out 评测是高考，必须考没刷过的题，不然分数不作数；而 reward hacking 就是应试技巧——只要有考试，就有人钻研"怎么得分"而不是"怎么学会"。**一边的每种病理，在另一边都有孪生兄弟。**

克制地说一句边界：这不等于"预训练不重要了"。264 期刚写过 K3 预训练把 scaling 效率提了 2.5 倍——零件车间也没停工，潜能的上限依然由它划定；只是"成为谁"这半边的预算、篇幅和保密等级都在涨。三行配方长成一座工厂，用了四年；这座工厂现在还在施工。

◆ 技术名词速查

━━━━━━━━━━━━━━━━━━━━

| 术语 | 一句话解释 |
|------|-----------|
| RLHF | 人类偏好比较 → 训奖励模型 → RL 优化策略的三段配方 |
| SFT（监督微调） | 拿人写或筛选的示范数据直接做监督学习 |
| PPO | 经典策略梯度 RL 算法，InstructGPT 三段配方的第三段 |
| DPO（直接偏好优化） | 把奖励模型重参数化折进损失函数，偏好对上直接训，不用 RL |
| RLVR（可验证奖励强化学习） | 判分器从神经奖励模型换成机械可验证规则（对答案、跑测试） |
| GRPO | PPO 的省内存变体：砍掉价值网络，用组内相对分数当基线 |
| 拒绝采样 | 每个 prompt 采多个候选，用奖励模型挑最好的当训练数据 |
| GKD | 学生在自己生成的序列上被教师纠偏的蒸馏法，解决训推分布错配 |
| on-policy distillation（在线蒸馏） | 在学生自己的采样分布上接受教师信号；GKD 是这条路线的重要前史之一 |
| MOPD（多教师在线蒸馏） | K3 的合并法：多个域专家按 token 给学生对数似然比稠密奖励 |
| on-policy cross-stage distillation | GLM-5 的收尾工序原名：跨训练阶段的在线蒸馏 |
| thinking mode fusion | Qwen3 的工序：把思考与非思考两种行为融进一个模型 |
| RFT（强化微调） | OpenAI 的 API 产品：用户自定义判分器对模型做强化微调 |
| reward hacking | 策略钻奖励函数空子拿高分而不真正完成任务 |
| rollout（轨迹采样） | RL 中让模型实际执行任务、采集完整交互轨迹的过程 |
| harness（脚手架） | agent 运行的外壳：工具接口、系统提示、上下文管理等的组合 |
