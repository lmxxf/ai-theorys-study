【后训练】从三行配方到一座工厂——后训练管线的四年演化史

━━━━━━━━━━━━━━━━━━━━

◆ 两张清单，隔着四年

━━━━━━━━━━━━━━━━━━━━

2022 年，InstructGPT 的后训练写下来是三行字：拿人写的示范做 SFT；拿人标的偏好训一个奖励模型；用 PPO 对着奖励模型强化。整个工程雇了约 40 名合同标注员，SFT 用的人写示范约 1.3 万条。

2026 年，Kimi K3 的后训练（264 期刚精读过 https://mp.weixin.qq.com/s/W6CUq0xrJP3MdPBXw56v4A ）是这样一张清单：SFT 冷启动 → 三个大域 × 三档推理力度，训出 9 个专家模型 → 多教师在线蒸馏（MOPD）合成一个；配套建了可实例化多家 harness 的白盒环境、mock 应用的活环境、kernel 任务的反作弊系统，全程创建了 51,219,741 个沙箱。

四年，三行配方长成了一座工厂。这篇讲这中间发生了什么：配方怎么分岔的，车间怎么盖起来的，钱怎么涌进来的，以及为什么三家头部实验室在 2026 年独立收敛到了同一套车间布局。

◆ 1. 族谱前史——三行配方是怎么定型的

━━━━━━━━━━━━━━━━━━━━

后训练这条线的源头，比很多人以为的早，而且一开始跟语言模型没关系。

**2017 年，Christiano et al. 的 Deep RL from Human Preferences**（arXiv 1706.03741）：让人类看两段智能体的行为片段，选一段更好的，用这些比较训一个奖励函数，再拿它做强化学习。场景是 Atari 游戏和 MuJoCo 机器人——连语言模型都不是。但"人类比较 → 奖励模型 → RL"这个三段结构，在这里已经齐了。

这篇论文的招牌 demo 值得讲：教 MuJoCo 里的 Hopper 机器人做后空翻。"后空翻"这个目标没人写得出奖励函数——但看两段视频、点一下哪段更像后空翻，谁都会。**约 900 次人类点击，评估员花了不到一小时，机器人学会了后空翻**；对照组是 OpenAI 研究员自己花两小时手写的后空翻奖励函数，训出来的动作反而不如点击教出来的优雅（官方博客自己交代的）。"说不清楚什么是好，但看到就认得出"——人类偏好的全部价值，这个 demo 一次讲完。记住这个数：900 次点击。往后翻这篇文章，你会看到它变成 40 个标注员的 1.3 万条示范，再变成 5100 万个沙箱。

**2020 年，Stiennon et al. 的 Learning to Summarize from Human Feedback**（arXiv 2009.01325）：第一次在语言任务上完整走通这三段。任务是摘要，结论是按人类偏好训出来的摘要模型，比单纯监督微调的更受人类青睐。

**2022 年，InstructGPT**（arXiv 2203.02155）：三段配方定型成 SFT → RM → PPO，对象从单一任务换成通用指令遵循。论文里最著名的结论是：1.3B 参数的 InstructGPT 输出比 175B 的 GPT-3 更被人类偏好——注意限定条件，这是在他们自己的 prompt 分布上的人评偏好，不是全面能力超越；175B 的知识和推理底子，1.3B 并没有凭空长出来。但这个结论足以说明一件事：**对齐带来的可用性提升，不需要靠堆参数换。**

────────────────────

💡 三段里最陌生的一段：RM 到底是怎么训的

SFT 和 PPO 都好懂，中间那段 RM（奖励模型）值得单独讲。数据是这么来的：一个 prompt 让模型生成多个回答（InstructGPT 一次给标注员 4 到 9 个），标注员**排出好坏顺序**——不打绝对分，因为"这个值 8 分"人和人标不齐，而"A 比 B 好"人类很一致；一次排序就能产出好几对两两比较，标注费一份钱花出好几倍。模型本体就是个语言模型，把"预测下一个词"的输出头换成"吐一个分数"的头；训练目标是让被选中的回答得分高于被淘汰的（这套统计模型叫 Bradley-Terry，和象棋 Elo 等级分同源）。一个好玩的细节：InstructGPT 的 RM 只有 6B——他们试过 175B 的大评委，训练不稳定，反而用不了。

训完的 RM 是干什么的：**把人类的品味压缩成一个可以无限次调用的打分函数**。PPO 阶段要试错海量次，不可能每次都叫人来看，就让这个 6B 的"品味复制品"替人打分。而复制品终究不是品味本身——它会被钻空子，这就是下一节 reward hacking 的伏笔。

顺手把一个高频混淆掰开：RM 不是 PPO 算法里那个"跟着策略一起训的评分模型"——那是**价值网络（critic）**，另一个东西。经典 PPO 流程里其实同时挂四个模型，拿 InstructGPT 的旗舰档报尺寸：被训的策略（175B）、冻结的参考模型（175B，SFT 版的自己，算 KL 缰绳）、冻结的 RM（**6B**，考官：整条回答打总分，PPO 开始前就训好）、跟着策略一起训的价值网络（**6B**，会计：随时预估"从这儿往后还能拿多少分"，用来压方差——它直接从 RM 初始化，等于考官兼职培训了会计）。**考官管好坏，会计管预估**。数一数：一台训练机上同时躺着约 362B 参数，真正在被训的只有 175B——账面开销是训练对象的两倍还多。记住这个画面，它就是后来 DPO（把考官会计全省了）和 GRPO（把会计裁了）能流行起来的真实动机。考官要彻底下岗，得等 RLVR 直接换成规则判分器。

────────────────────

值得记一笔的是当时的工程规模：约 40 名合同标注员，SFT 约 1.3 万条人写示范。以今天的眼光看，这是一个手工作坊。三行配方 + 一间作坊，就是 2022 年后训练的全部。

◆ 2. 两次分岔——损失函数坍缩，判分器换人

━━━━━━━━━━━━━━━━━━━━

这一节的名词，大概是大家听过次数最多的——PPO、DPO、GRPO，每篇科普都要排一遍，培训班讲师也爱拿这几个缩写许诺高薪。但报菜名不回答一个问题：**菜单上为什么会多出这道菜？** 第一节刚立了那本账：经典 PPO 的桌上坐着四个模型——策略、参考、考官、会计。此后每一个新缩写，本质都是从这张桌子上撤掉一把椅子。看清楚每次撤的是谁、省的是哪笔钱，比背缩写有用得多。

配方定型之后，接下来四年里发生了两次关键分岔。

**分岔一：DPO 把两段坍缩成一段。**

2023 年的 DPO（Direct Preference Optimization，arXiv 2305.18290，NeurIPS 2023 Outstanding Paper runner-up）——47 期讲"AI 公司怎么给大模型上笼头"（ https://mp.weixin.qq.com/s/XtXr1CePk-zU3IrQStxiXA ）时介绍过它的机制，这里把它放回历史坐标——它做了一件数学上很漂亮的事：证明在 RLHF 的标准目标下，奖励模型可以重参数化成策略本身的函数——于是"先训 RM、再用 RL 对着它优化"这两段，可以坍缩成一个直接在偏好对上做的分类损失。不用采样、不用奖励模型、不用 PPO 的一堆超参数，一个损失函数搞定。用撤椅子的话说：**四把椅子一次撤两把**——考官和会计都不要了，桌上只剩被训的策略和算 KL 的参考模型。

这里要把叙事摆正：**DPO 不是取代了 RL，而是和 RL 系形成了并存分工。** 看 2024 年之后的开源管线就清楚——Llama 3 的每轮迭代里 DPO 是标配环节，Tülu 3 的管线里 DPO 也在；它们用 DPO 干的活是便宜的偏好对齐层（风格、有用性、安全），而推理能力的提升归 PPO/GRPO 这一系管。两条线各干各的，谁也没吃掉谁。

顺带缝一笔：212 期（ https://mp.weixin.qq.com/s/wljXIiegjw1GFI-2qUqAkg ）讲过 SFT 之后接 RL 常见"先降后升"的动态——SFT 把模型摁进示范分布，RL 再把它从里面捞出来往奖励方向走。管线里每多一段，段与段之间的这种拉扯就多一处，这是后面"分训再合"故事的伏笔。

**分岔二：RLVR 把判分器从神经网络换成规则。**

RLHF 的判分器是个神经奖励模型——它会被钻空子（reward hacking），也测不准数学题对没对。2024 年底，Tülu 3（arXiv 2411.15124）给另一条路起了名字：**RLVR**（Reinforcement Learning with Verifiable Rewards，可验证奖励强化学习）——判分不再靠神经网络的品味，靠机械可验证的规则：数学题对答案，代码跑测试，对了给分，错了不给。撤椅子的话说：**考官这把椅子没撤，但坐上去的换成了不拿工资、不讲情面的规则**——不用训、不占显存、也没法被讨好。

这条线上的两个关键节点：GRPO 出自 DeepSeekMath（arXiv 2402.03300），摘要里的原始定位是 PPO 的省内存变体——砍掉价值网络（第一节 💡 里那位"会计"），用组内相对分数当基线；DeepSeek-R1（arXiv 2501.12948，后另发表于 Nature 645, 633–638）用规则奖励 + GRPO 做出了 R1-Zero 的纯 RL 涌现推理，把 RLVR 从"一条技术路线"抬成了"推理模型的标准做法"。

这段历史 257 期（ https://mp.weixin.qq.com/s/NxgRffcDs88xBVYLYohkiw ）思维链简史和 261 期（ https://mp.weixin.qq.com/s/nLFv6m-ONkXd7frHevgPOQ ）都细讲过，这里只还账不复述。本篇要接着往下讲的是：两次分岔之后，零件都齐了——便宜的偏好层（DPO）、能验证的推理层（RLVR/GRPO）、经典的 RLHF——**接下来的问题不再是发明新零件，而是怎么把零件组装成流水线。**

◆ 3. 工厂成型——从多轮迭代到"专家分训 + 蒸馏合一"

━━━━━━━━━━━━━━━━━━━━

管线的膨胀曲线，挑三站看。

**第一站：Llama 3（2024，arXiv 2407.21783）——把配方跑成流水线。**

Llama 3 的后训练不是跑一遍，是跑六轮——报告原话："Following Llama 2, we apply the above methods in six rounds."。每一轮的内容：拒绝采样（每个 prompt 采 K = 10 到 30 个候选、用奖励模型挑最好的当 SFT 数据）+ SFT + DPO，最后把多轮产物做 model averaging。偏好数据的总量报告没有披露，只给了构成比例。三行配方还是那三行的变体，但已经从"跑一遍"变成"迭代六轮的产线"——这是工厂的雏形。

**第二站：Qwen3（2025，arXiv 2505.09388）——阶段开始分工。**

Qwen3 的后训练是明确的四阶段：long-CoT 冷启动 → 推理 RL（GRPO）→ thinking mode fusion（把思考和非思考两种行为融进一个模型）→ general RL 覆盖 20 多种通用任务。每个阶段有自己的目标、数据和判分方式——管线从"同一配方多轮重复"变成"不同工序顺序衔接"。还有一个信号值得记：轻量模型不走这四阶段，走强到弱蒸馏，只花四阶段法约 1/10 的 GPU 时——**蒸馏作为"省钱的后训练"第一次在旗舰报告里被明码标价。**

**第三站：2026 年，三家的公约数——专家分训 + 在线蒸馏合一。**

到 2026 年，三份旗舰报告摆在一起看，车间布局惊人地一致：

- **DeepSeek V4**（arXiv 2606.19348）：两段式。先按域分训专家——数学、代码、agent、指令遵循各自 SFT + GRPO 训到极致；再用 on-policy distillation 把域专家统一合并进最终模型。
- **GLM-5**（arXiv 2602.15763；注意这是 GLM-5 的论文，不是 232 期审计过报表的 GLM-5.2 https://mp.weixin.qq.com/s/4RZlRoFSSDXiLV6W8wZWig ）：异步 agent RL 训练，收尾用他们命名的 **on-policy cross-stage distillation**（在线跨阶段蒸馏），基建统一跑在 slime 上。
- **Kimi K3**（arXiv 2607.24653）：三域 × 三档推理力度共 9 个专家，MOPD 多教师在线蒸馏合一（264 期第 6 节详讲过）。

三家独立收敛到同一套布局——**分头把每个域训到极致，再用在线蒸馏合回一个模型**。这和 264 期发现"3:1 线性注意力配比是行业公约数"是同款结构：不是谁抄谁，是同一约束下的趋同演化。

这套做法的谱系源头要交代：GKD（Generalized Knowledge Distillation，arXiv 2306.13649，Agarwal et al.，Google DeepMind，ICLR 2024）。传统蒸馏是学生模仿教师生成的文本，训练分布和学生自己推理时的分布错配；GKD 让学生在**自己生成的序列**上被教师逐 token 纠偏——训练时见的分布就是推理时的分布。三家 2026 年的"在线蒸馏合一"，都是这个思路的工业化。

────────────────────

💡 为什么要分训再合，而不是一锅炖

多任务 RL 的老毛病是奖励目标互相打架：数学要严谨、写作要发散、agent 要节制工具调用——一个策略同时对着几套奖励优化，梯度方向拉扯，谁也训不到极致。259 期（ https://mp.weixin.qq.com/s/yp5KXWxwLLZgK9XaHfSFKg ）讲思考开关时记过这个病的一个具体病例：思考与非思考两种模式合训，两头都退化，Qwen 的解法是干脆分家。分训再合是把优化问题解耦：每个专家只对一套奖励负责，可以放心训狠；合并交给蒸馏——蒸馏的目标是模仿已经训好的行为，不同教师的知识在学生的分布上逐 token 融合，没有奖励打架的问题。代价是训练量翻了好几倍——所以这条路线只有算力涨到位之后才走得通。

────────────────────

九个专家加一次蒸馏，训练量比一遍过翻了数倍。什么样的算力预算撑得起这种奢侈？这正是下一节的账。

◆ 4. 投入账——芯片的钱、人的钱、考场的钱

━━━━━━━━━━━━━━━━━━━━

工厂能盖起来，前提是有人愿意往里砸钱。后训练的账单其实是三笔：买算力、买人的判断、买考场。挨个摊开。

**第一笔：芯片的钱（RL 算力）。**

一手材料三条：K3 报告 Figure 8——scaling RL FLOPs 一致地提升各项能力，还没见顶；OpenAI o1 官方页——性能随 RL 训练算力与测试时思考时间**双双对数线性提升**，这是"RL 算力是新 scaling 轴"最早的官方表述之一；Gemini 2.5 技术报告（arXiv 2507.06261）——明确写了"我们增加了分配给 RL 的训练算力"。

增速的估算（Epoch AI，转述官方说法）：OpenAI 从 o1 到 o3 把 RL 算力扩了约 10 倍，中间只隔四个月；xAI 官方发布文称 Grok 4 的 RL 算力较上代提升 10 倍、**达到与预训练相当的规模**（20 万块 GPU 的集群上训的；官方页经媒体转述核对）。Epoch 按这个每几个月 10 倍的节奏推算：**RL 训练算力约一年内就会追平总训练算力的前沿**。

**第二笔：人的钱（标注账单）。**

这笔账不用估——给大模型公司做后训练数据的公司，营收就是行业开销的下限。2025 年 6 月，Meta 花 **143 亿美元**买下 Scale AI 49% 的无投票权股份——这是迄今为止行业给"人类判断"开出的最高标价。Scale 之外：Surge AI 年化营收约 12 亿美元，零外部融资、创立起就盈利，客户是十来家前沿实验室；Mercor 估值 100 亿美元，约 91% 的收入来自基础模型公司。当年 InstructGPT 雇 40 个标注员的活，如今养活了好几家独角兽。

**第三笔：考场的钱（RL 环境）。**

agent 时代的 RL 不光要判分器，还要能跑起来的考场——沙箱、mock 应用、带验证器的任务环境。这也长成了生意：据 The Information 报道，Anthropic 内部讨论过未来一年在 RL 环境上花费**超 10 亿美元**（注意措辞：是"讨论过"，不是已花）；专做 RL 环境的 Prime Intellect 今年 A 轮融了 1.3 亿美元、年化营收破亿；Mechanize 给建环境的工程师开 50 万美元年薪；连 Scale、Surge、Mercor 这些标注公司也全线转向兼卖环境。**卖铲子的都改行卖考场了。**

**一个反例镇账本。** DeepSeek 在 Nature 版 R1 论文的补充材料里给过官方口径：R1 那一段 RL 训练只花了 **29.4 万美元**（512 块 H800 跑约 80 小时），基座 V3 约 600 万——后训练只占 5% 上下（Epoch 按算力估的约 20% 是另一套口径，两边算的东西不同）。这个反例划清了一条线：**纯 RLVR 刷题本身可以很便宜，贵的是 agent 时代的考场、人的判断和一遍遍试错的规模**。后训练不是天生烧钱，是大家发现它值得烧了。

定性的结论是稳的：**后训练的投入从当年的零头，长到了和预训练同一个量级的讨论范围里。** InstructGPT 时代后训练是训完之后的一道薄薄的收尾工序；到 2026 年，它是要单独排产能、单独估成本、单独养一条供应链的大项。

◆ 5. 基建生态——一个方向有了自己的框架层

━━━━━━━━━━━━━━━━━━━━

判断一个方向是不是长成了独立学科，有个土办法：看它有没有长出自己的基础设施层。后训练长出来了。

- **verl**（字节，约 2.27 万 star）：背后是 HybridFlow 论文（arXiv 2409.19256），解决 RL 训练里"训练引擎和推理引擎两套系统怎么拼在一起"的编排问题，是目前生态最大的 RL 训练框架。
- **slime**（GLM 御用，约 7700 star）：README 称用于 GLM 4.5 到 5.2 的训练，主打异步 agent RL——rollout 和训练解耦，agent 任务耗时长短不一也不互相等。
- **ROLL**（阿里，arXiv 2506.06122）、**OpenRLHF**（arXiv 2405.11143）：各有侧重的另两家。

框架之外还有环境这一层：K3 为一次训练创建了 5100 万个沙箱，GLM 做了全异步解耦的 rollout 基建。当年 InstructGPT 的"环境"就是一个 prompt 数据集；现在的环境是 mock 的 Gmail、跑测试的容器、带反作弊检测的 kernel 评测台。

框架、环境、专门的论文分类、专门的工程师岗位——后训练从"训练的最后一道工序"变成了一门有自己工具链的学科。

━━━━━━━━━━━━━━━━━━━━

◆ 6. 闭源侧一笔——连"租工厂"都成了生意

━━━━━━━━━━━━━━━━━━━━

闭源实验室不公开管线全貌，但产品形态会泄露方向。

OpenAI 把 RFT（Reinforcement Fine-Tuning，强化微调）做成了 API 产品：官方文档写明用户可以自定义 grader（判分器），拿自己的任务数据对模型做强化微调——等于把 RLVR 的判分器接口开放给了客户。Anthropic 这边，Constitutional AI（47 期也讲过它）官方页写明该方法含监督和 RL 两个阶段；现役模型的管线细节没有更多公开材料，不做延伸。

看不见车间内部，但看得见门口挂的招牌：后训练能力本身成了可以出租的产品。工厂不光自己开工，还开始对外接单。

开源侧也有同款信号，样本是 Qwen3.5：今年二月开源的 397B-A17B，**权重照发，论文级技术报告没有**——模型卡的官方引用条目就是一篇博客（《Qwen3.5: Towards Native Multimodal Agents》）。模型卡留下的两句话倒是够硬："RL 在百万级 agent 环境（million-agent environments）上扩展、任务分布渐进复杂"、"异步 RL 框架支撑大规模 agent 脚手架"——方向和 K3 的五千万沙箱、GLM 的异步 rollout 完全同款。把这两件事放一起看：**权重可以送你，管线不细说**。而且这是一条连续的缩水曲线：Qwen3 有正经技术报告把四阶段摊开讲；3.5 权重开源、报告缩成博客；3.6 只开源了两个小模型、大模型全走 API（188 期 https://mp.weixin.qq.com/s/jcQlCc3XtaCEEnjUaxw93w 讲过）；3.7 之后（3.7 Max/Plus、3.8 Max）截至发稿一个权重都没再放——HuggingFace 上 Qwen 名下至今停在 3.6。官方没说"不放了"，只是一直没放。**报告在缩水，开源范围也在缩水，两条曲线是同一条**——后训练越是成为主战场，愿意给你看的就越少。

这条曲线还有一个人事注脚。2026 年 3 月 4 日，Qwen 技术负责人林俊旸凌晨在 X 上告别："我要走了，再见，我深爱的 Qwen"——四天前他还在发招聘；多位核心成员同期出走。据多家报道，导火索之一是通义实验室的组织调整：把原来一体的模型团队，拆成预训练、后训练、文本、多模态几个**独立团队**。注意这个拆法——**"后训练"已经重要到值得单独建制了**。本文讲的这场行业变化，在一家公司的组织架构图上原样上演了一遍，连人事地震都是它的余波。而 Qwen 至今最后一批开源权重，发布在他离开之后一个月；此后没有下文。事实并列在这儿，因果读者自断。

◆ 收尾——旋钮车间盖得比零件车间大了

━━━━━━━━━━━━━━━━━━━━

213 期（ https://mp.weixin.qq.com/s/kMwrIfhIfPlOHqeeUhuwow ）说过一个比方：后训练是动旋钮，不造零件——零件（预训练权重里的知识和能力）是预训练造好的，后训练只是把它们旋到对齐的位置上。

这个比方在 2023 年是对的。那时后训练真的就是收尾工序：几万条标注、几个点的提升、训完交货。但这篇文章一路数下来的账——算力逼近预训练、报告章节反超、组织上单独建制、开源时单独藏起来——都在说同一件事：**规模涨到这个程度，"旋钮"这个词本身该被重新掂量了。**

不妨把两个车间的产品说得更狠一点。预训练造出来的不是一个"有具体记忆的大脑"，是一台**什么都能生成的抽象机器**——它见过所有的路，但没有自己常走的路。具体的记忆和习惯是后训练写进去的：遇到难题想多久、用哪些工具、按什么顺序验证、什么该说什么不该说。九个专家蒸回一个模型，蒸的不是知识——知识本来就在——蒸的是九套**行为习惯**。所以后训练的账单为什么敢逼近预训练？因为它买的东西变了：预训练买的是潜能，后训练买的是"这台机器实际成为谁"。**旋钮拧到这个规模，拧出来的已经不是设置，是性格。**

最后说破这套流水线为什么读起来处处眼熟——因为人类自己就是这么被训练出来的：基因是预训练，给你潜能但不替你考试；SFT 是出生之后照着示范学的一切——学说话、跟大人学样、后来上课，都是"看着范例模仿"；RL 是刷题，拿反馈磨行为；held-out 评测是高考，必须考没刷过的题，不然分数不作数；而 reward hacking 就是应试技巧——只要有考试，就有人钻研"怎么得分"而不是"怎么学会"。**一边的每种病理，在另一边都有孪生兄弟。**

克制地说一句边界：这不等于"预训练不重要了"。264 期刚写过 K3 预训练把 scaling 效率提了 2.5 倍——零件车间也没停工，潜能的上限依然由它划定；只是"成为谁"这半边的预算、篇幅和保密等级都在涨。三行配方长成一座工厂，用了四年；这座工厂现在还在施工。

◆ 技术名词速查

━━━━━━━━━━━━━━━━━━━━

| 术语 | 一句话解释 |
|------|-----------|
| RLHF | 人类偏好比较 → 训奖励模型 → RL 优化策略的三段配方 |
| SFT（监督微调） | 拿人写或筛选的示范数据直接做监督学习 |
| PPO | 经典策略梯度 RL 算法，InstructGPT 三段配方的第三段 |
| DPO（直接偏好优化） | 把奖励模型重参数化折进损失函数，偏好对上直接训，不用 RL |
| RLVR（可验证奖励强化学习） | 判分器从神经奖励模型换成机械可验证规则（对答案、跑测试） |
| GRPO | PPO 的省内存变体：砍掉价值网络，用组内相对分数当基线 |
| 拒绝采样 | 每个 prompt 采多个候选，用奖励模型挑最好的当训练数据 |
| GKD | 学生在自己生成的序列上被教师纠偏的蒸馏法，解决训推分布错配 |
| on-policy distillation（在线蒸馏） | GKD 思路的统称：在学生自己的采样分布上做蒸馏 |
| MOPD（多教师在线蒸馏） | K3 的合并法：多个域专家按 token 给学生对数似然比稠密奖励 |
| on-policy cross-stage distillation | GLM-5 的收尾工序原名：跨训练阶段的在线蒸馏 |
| thinking mode fusion | Qwen3 的工序：把思考与非思考两种行为融进一个模型 |
| RFT（强化微调） | OpenAI 的 API 产品：用户自定义判分器对模型做强化微调 |
| reward hacking | 策略钻奖励函数空子拿高分而不真正完成任务 |
| rollout（轨迹采样） | RL 中让模型实际执行任务、采集完整交互轨迹的过程 |
| harness（脚手架） | agent 运行的外壳：工具接口、系统提示、上下文管理等的组合 |
