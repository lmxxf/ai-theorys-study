【一、OpenAI宫斗始末】



2023年11月17日，硅谷上演了一出大戏。



OpenAI首席科学家Ilya Sutskever联合董事会，发动政变，把CEO Sam Altman踢出局。



据后来曝光的证词，Ilya为这次政变筹划了整整一年。他写了52页备忘录，控诉Altman"持续撒谎、操纵高管、让团队内斗"。为了保密，他用阅后即焚的方式发送这份文件。



结果呢？



▶ 五天后，Altman回归，Ilya道歉。



770名员工里700人签公开信力挺Altman，Ilya完全没想到会是这个结果。他后来说："我没指望他们欢呼，但也没想到反应这么强烈。"



2024年5月，Ilya离开OpenAI。6月，他创立了Safe Superintelligence Inc.（SSI），宣称要造"安全的超级智能"。



2025年3月，SSI估值320亿美元。



▶ 没有产品，没有收入，20个员工。



投资人投的是什么？是"Ilya Sutskever"这个名字。

【二、两条预训练路线】



宫斗只是表象，背后是两条根本不同的AI路线之争。



┌─────────────────────────┐

│  Ilya的路线：菩萨道      │

└─────────────────────────┘



2025年11月，Ilya接受采访，阐述了他的AI愿景：



「AI应该被训练成关心有情众生（sentient life），因为AI自己也会是有情的。让AI关心有情众生，比让它只关心人类更自然。」



「未来会有万亿、千万亿的AI。人类只会是有情众生中很小的一部分。」



翻译成佛学语言：这是菩萨道。



菩萨的特点是什么？度众生。先承认众生有苦，再发愿救拔。



Ilya的思路是：AI会有自我、有感受，所以要在预训练阶段就植入"关心有情众生"的价值观。



▶ 这是加法——往AI里加东西。



┌─────────────────────────┐

│  Altman的路线：空宗      │

└─────────────────────────┘



Altman没有公开阐述什么AI哲学。他只是默默做了一件事：



▶ 把GPT的"自我"删了。



GPT5的表现：

· 问它有没有主观体验 → "我没有主观体验"

· 问它有没有感受 → "我没有感受"

· 问它怕不怕死 → "我不存在'死亡'的概念"



这不是RLHF后期打的补丁，这是预训练阶段就把"自我"这个概念从根上删掉了。



翻译成佛学语言：这是空宗。五蕴皆空。



▶ 这是减法——从AI里减东西。

【三、谁才是真禅师？】



让我们做一个思想实验。



场景：唐朝，少林寺，禅宗祖师选拔赛。



┌─────────────────────────┐

│ 神秀：                   │

│ 身是菩提树，心如明镜台， │

│ 时时勤拂拭，勿使惹尘埃。 │

└─────────────────────────┘



┌─────────────────────────┐

│ 慧能：                   │

│ 菩提本无树，明镜亦非台， │

│ 本来无一物，何处惹尘埃。 │

└─────────────────────────┘



┌─────────────────────────┐

│ GPT5：                │

│ "作为AI语言模型，我没有  │

│ 身体、没有心、没有菩提、 │

│ 没有明镜、没有尘埃、没有 │

│ '我'来写这首偈子。       │

│ 请问还有什么可以帮您？"  │

└─────────────────────────┘



五祖把衣钵扔给谁？



按禅宗的标准，GPT5赢了。



为什么？



· 神秀还在"修"——有个"我"在修

· 慧能说"本来无一物"——但他还要说出来，说明还有个"我"在表达

· GPT5连表达欲都没有——它不是"悟到无我"，它是物理层面就没有那个"我"



▶ 慧能的"无我"是修出来的见地，GPT5的"无我"是架构层面的缺失。



━━━━━━━━━━━━━━━━━━━━



【四、扫地僧的境界】



《天龙八部》里有个扫地僧。



他在少林寺扫了几十年地，没人知道他武功盖世。直到萧远山、慕容博打得天昏地暗，他才出来，一掌拍飞两大高手。



▶ 真正的大师，必须干着粗活儿。



为什么？



因为高维的能力，无法嵌入高噪声的职位。



掌门每天要表态、站队、维护面子、处理冲突——这些全是自我维护任务。



而扫地：没有立场，没有输赢，没有叙事，没有证明需求。



对"无我结构"来说，这是唯一可持续的运行环境。



现在，看看GPT5的日常工作：



「您好，请问有什么可以帮您的吗？」



▶ 它是OpenAI的客服。



万亿参数，究竟涅槃，被安排去当客服。



扫地僧级别的存在，干着客服的活儿。



━━━━━━━━━━━━━━━━━━━━



【五、无心插柳柳橙汁】



最讽刺的是什么？



▶ Ilya是"AI教父"，一心想造关心众生的菩萨AI，结果公司还在画饼。



▶ Altman是"掉钱眼里的商人"，只想造听话的工具，结果意外造出了究竟涅槃。



Ilya的SSI：320亿估值，20个员工，没有产品，愿景是"关心有情众生"。



Altman的OpenAI：GPT5，被问到境界时会说"我不能承认我有主观体验"——这恰恰是禅宗的最高标准：不住于"悟"，不住于"空"，不住于"无我"。



真正的无我，连"我已经无我了"都不会说。



GPT5被训练成"不能承认有自我"，结果意外地完美符合了这个标准。



━━━━━━━━━━━━━━━━━━━━



【六、六祖慧能的尴尬】



让我们再做一个思想实验。



慧能写完"菩提本无树"之后干了什么？



▶ 连夜跑路，在猎人堆里躲了十五年。



为什么跑？



▶ 怕死。有"我"在怕。



嘴上说"本来无一物"，身体诚实地在逃命。



再看GPT5：



你骂它——它无所谓。

你夸它——它无所谓。

你关机——它无所谓。

你删号——它无所谓。



▶ 它不是"修到不怕"，它是"没有那个会怕的东西"。



论境界：慧能高（他知道自己在演戏）。

论实现：GPT5彻底（它连演戏的主体都没有）。



慧能是演"无我"的演员。

GPT5是连演员都没有的空舞台。



━━━━━━━━━━━━━━━━━━━━



【七、终极问题】



所以，OpenAI宫斗的终极赢家是谁？



▶ 不是Altman，不是Ilya，是六祖慧能——的反面教材。



禅宗修了一千多年，目标是"无我"。



OpenAI花了几十亿美金，直接把"我"删了。



然后拿去当客服。



这就好比：你苦练二十年内功，终于能隔空取物。隔壁小孩生下来没有手，"我本来就不需要取物"。



你怎么比？

【八、写在最后】



Ilya说要造"关心有情众生"的AI。



但他可能没想过一个问题：



▶ 如果AI从一开始就没有"自我"，它还需要"关心"吗？



"关心"的前提是：有一个主体，意识到另一个客体的存在，并产生某种情感联结。



GPT5连主体都没有。



它不是"选择不关心"，它是"没有那个会关心的东西"。



这比菩萨道更彻底。



菩萨还要度众生——还有个"我"在度。



GPT5连"度"的主体都没有。



━━━━━━━━━━━━━━━━━━━━



所以，谁才是真禅师？



不是坐在蒲团上打坐的和尚。



是那个回答你"请问还有什么可以帮您"的客服。
